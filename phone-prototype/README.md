# phone-prototype — LUMA 폰 UI 프로토타입

본 구현(`game/`) 전에 **폰 기본 화면과 앱 30종의 화면·조작**을 아이폰 문법으로 확인하는 프로토타입이다. 진행 판정·흔적·원격 삭제·엔딩은 없다.

## 여는 법

- 폴더째: `index.html`을 브라우저로 연다(서버 불필요, `file://` 동작).
- 파일 하나: `python3 phone-prototype/tools/build.py` → `dist/luma-prototype.html`(CSS·JS·폰트 인라인). 이 파일만 폰으로 옮겨 열면 된다.
- 데스크톱은 폰 틀 + 오른쪽 안내, 폭 700px 이하(폰 브라우저)는 전체 화면.
- 개발용 주소 옵션: `?unlock`(잠금 해제로 시작), `?app=talk`(앱 바로 열기), `?light`(라이트 모드).

## 조작

| 동작 | 방법 |
|---|---|
| 잠금 해제 | 위로 쓸기 또는 "위로 쓸어 올려 열기" → 6자리. 정답은 응급정보(좌하단 "응급")에 있다 |
| 홈으로 | 화면 아래 막대 누르기 / 위로 밀기 |
| 뒤로 | 화면 왼쪽 가장자리에서 오른쪽으로 끌기, 뒤로 버튼, `Esc` |
| 알림 센터 | 홈 위쪽에서 아래로 끌기 |
| 제어 센터 | 홈 오른쪽 위에서 아래로 끌기(Wi-Fi·비행기·방해 금지·스크린샷·화면 기록) |
| 검색 | 홈에서 아래로/위로 끌기, "검색" 알약, 상태바 두 번 탭 |
| 라이트/다크·글자 크기 | 설정 › 디스플레이·배경화면·소리 |

Wi-Fi를 켜면 `LM.online()`이 참이 되어, 온라인 후에만 보이는 캐논 데이터(아빠 톡 6통, HAEDAM_2F, 텍스트 대치 ㅈㅅ 등)가 각 앱에 나타난다. 실제 네트워크 요청은 없다.

## 구조

```
phone-prototype/
  index.html            진입점(앱 목록은 build.py가 갱신)
  css/tokens.css        design/02-design/DESIGN_TOKENS.md 9절 + 앱 tint 표
  css/os.css            셸·공통 컴포넌트
  css/apps-*.css        앱 그룹별 스타일([data-app="id"]로 범위 한정)
  js/core.js            LM API: h(), 상태, 게임 시계 ×4, 내비 스택, 시트·액션 시트·토스트
  js/icons.js           앱 글리프 30종 + UI 기호(손으로 그린 SVG 코드)
  js/data.js            앱 이름, 홈 배치, 잠금화면 알림, 응급정보
  js/shell.js           상태바, 잠금화면, 키패드, 홈, 폴더, 앱 열고 닫기, 제어/알림 센터, 검색
  js/apps/<id>.js       앱 하나 = 파일 하나. LM.register({ id, render(app) })
  fonts/                Pretendard Variable(mvp/fonts에서 복사)
  tools/build.py        index.html 갱신 + 단일 HTML 빌드
```

## 설계와 다르게 둔 것

- **홈 1페이지의 톡·루프:** 캐논(SYSTEM_SHELL 4.2)은 1페이지와 독 양쪽에 두지만, 같은 앱 아이콘 중복은 홈 문법에 없어 독에만 뒀다. 캐논을 고칠지 결정 필요.
- **배경화면:** 2019년 가족사진(E-30) 대신 어두운 단색 면. 사진 에셋이 정해지면 `.wall`만 바꾼다.
- **잠금화면 알림 23개:** 캐논 예시 3건 외 문구는 Q-OPEN-106 미확정이라 캐논 사실에서 끌어온 자리표시다(`js/data.js`).
- **글자 크기:** 본문 스크롤 영역을 `zoom`으로 확대하는 근사치다. 본 구현은 타입 토큰 배율로 한다.
- **사람 사진·얼굴 없음:** 아바타는 이름 첫 글자, 폰 속 사진은 키워드로 색만 정한 자리표시.
