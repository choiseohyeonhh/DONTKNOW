# DONTKNOW v6.2 — 아들의 폰

실종된 아들 도현의 폰(LUMA)을 뒤져 사건을 푸는 스마트폰 수사 어드벤처. 결과물은 **단일 HTML 파일** 하나다. 서버·설치·네트워크 없이 동작한다.

## 여는 방법

1. `python3 tools/build.py`로 `dist/dontknow.html`을 만든다.
2. `dist/dontknow.html`을 브라우저에서 연다.
   - PC: 파일을 더블클릭한다.
   - 아이폰 Safari: 파일을 아이폰으로 옮긴 뒤 파일 앱에서 연다. 오프라인에서도 그대로 동작한다(외부 폰트·CDN·이미지 요청 없음).
3. 새로 시작하려면 주소 뒤에 `?new`를 붙인다. 자동 저장은 브라우저 `localStorage`에 남는다.

## 조작

- **잠금화면**: 아래에서 위로 쓸어 올리거나 "위로 쓸어 올려 열기"를 누른다. 왼쪽 아래 **응급**에서 응급 의료 정보를 본다.
- **홈**: 앱 아이콘을 누른다. 페이지를 좌우로 넘기고, 아래 독에서 전화·메시지·톡·루프를 연다.
- **앱 안**: 왼쪽 가장자리에서 오른쪽으로 밀거나 "뒤로"를 눌러 돌아간다. 화면 맨 위를 한 번 누르면 맨 위로, 아래에서 위로 밀면 홈으로 간다.
- **상태바**: 왼쪽을 아래로 끌면 알림 센터, 오른쪽을 아래로 끌면 제어 센터. 위로 밀어 닫는다.
- **메시지**: 입력창에 쓰고 보내기. `+`로 사진·파일·위치·녹음을 첨부한다. 길게 누르면 복사·공유·정보.
- **은행**: 온라인에서 간편비밀번호 6자리를 누른다. 거래내역 → 거래 상세 → 공유.
- **바로택시**: 도착지 입력 → 검색 → 선택 → 호출. 호출은 되돌릴 수 없다.
- **일시정지**: 상태바의 일시정지 버튼. 저장·불러오기, "막혔을 때" 3단계 힌트, 처음부터.

## 개발용 주소 옵션

| 옵션 | 동작 |
|---|---|
| `?new` | 저장을 무시하고 새 게임을 시작한다. |
| `?debug` | 디버그 패널(시각 이동·플래그·이벤트 확인). 배포 빌드에서는 꺼진다. |
| `?seed=123` | 배경 잡담·알림 스케줄의 시드를 고정한다. 같은 시드는 같은 시각·같은 문장을 만든다. |
| `?unlock` | 잠금을 건너뛰고 홈에서 시작한다. |
| `?app=talk` | 잠금을 건너뛰고 해당 앱을 바로 연다. |
| `?light` | 라이트 테마로 시작한다. |

## 빌드와 테스트

```bash
python3 tools/build.py                     # dist/dontknow.html 생성
node tests/smoke.test.js                   # 앱 30종 스모크
node tests/engine.test.js                  # 엔진 단위
node tests/read.test.js                    # 읽음·배지·원격 삭제
node tests/dialogue.test.js                # 대사·반응표
node tests/crisis.test.js                  # 30분 위기·원격 지우기
node tests/crisis-ui.test.js               # 위기 UI
node tests/endings.test.js                 # 엔딩 판정·연출
node tests/playthrough.test.js             # 시작→모든 엔딩 UI 플레이스루(스크린샷 포함)
```

모든 테스트는 Playwright(chromium)를 쓴다. `game/tests/playthrough.test.js`는 `game/tests/shots/<run>/`에 주요 장면 스크린샷을 남긴다.

## 구조

- `js/core.js` — LM API(h, 이벤트, 시계, 내비 스택, 시트, 공용 UI)
- `js/engine/` — 상태·읽음·사건·대화·흔적·엔딩·최종 장면
- `js/content/` — 대사·사건·증거·배경 잡담 데이터
- `js/apps/` — 앱 30종
- `js/shell.js` — 잠금화면·홈·제어/알림 센터
- `css/` — 토큰과 화면 스타일
- `tools/build.py` — 단일 HTML 인라인 빌드
