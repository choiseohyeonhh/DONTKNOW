## 3. 결번·확인 항목

- `E-06`, `E-08`, `E-09`는 원장 본문에 단서 행이 없다(원장 확인 사항의 번호 결번). 구현 대상 아님.
- 최종 장면 작성창의 빚 고백은 메시지 앱 밖이지만 같은 플래그(F-CONFESS)를 쓴다.
- 부계정 6자리 코드는 `G.world.subCode`에 저장되며 메일 두 번째 계정에만 도착한다(온라인 전용).
- 예약 메일 수정은 본문·첨부를 바꾼다. 제목은 캐논상 고정으로 두었다.
- BR-23 지훈 넛지는 JH-1 이후 진전이 없을 때 한 번 보낸다(설계 예시 문장을 인물의 앎 범위에 맞춰 최소 변형).
- 바로택시 목적지 목록은 장소 목록에서만 나온다. 해담고시텔은 온라인 + 해담 관련 단서 1개 이상 열람, 성원스파는 F-MOVED일 때만 목록에 뜬다.
