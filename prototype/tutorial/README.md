# 튜토리얼 프로토타입 (S1 · S2)

아버지 폰 UI 시안(`docs/ui/mockups/`)을 실제로 조작할 수 있게 만든 첫 수직 슬라이스.
콘텐츠 고지 → 타이틀 → CN-00 프롤로그 → S1(폰, 부재) → S2(지훈, 문자/통화) → CN-01 첫 아침(08:40)까지 돈다. S3 이후는 없다.

## 실행
- 소스 그대로: `index.html`을 브라우저로 연다(파일 열기로 충분).
- 한 파일 빌드: `python3 build.py <출력경로>` → 이미지·폰트·스크립트가 전부 들어간 `tutorial.html`.
- 옵션
  - `?debug=1` : 우측 상단 패널에 phase, 선택지 대기, 획득 K 목록, 플래그, 시계 표시.
  - `?speed=N` : 모든 타이머를 N배 빠르게(넛지 450초 → 450/N초).

## 데이터 (수정 시 주의)
- `make_data.py` → `data.js`. `docs/content/father-phone-data.md`의 한결 34건, 부재중 47건, 배차실·대학교·광고를 읽어 만든다. **data.js를 직접 고치지 말고 문서를 고친 뒤 다시 생성한다.**
- 연락처, 지훈 스레드, S2 대사 스크립트는 `app.js`에 있다. 대사 출처는 `docs/sessions/S02.md` 3~4장(문자/통화 문장이 따로 있다), 문체 기준은 `docs/narrative/dialogue-style.md`.
- 화면 갱신은 `morph()`로 바뀐 노드만 고친다. `innerHTML` 통째 교체로 되돌리면 통화 화면·알림이 매초 깜빡이던 문제가 다시 생긴다.
