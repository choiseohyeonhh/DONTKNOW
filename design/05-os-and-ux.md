# 05. 스마트폰 운영체제(LUMA OS)와 UI/UX (v6.2)

> iOS를 복제하지 않는다. **"처음 쥐어도 쓸 줄 아는, 그러나 어디서도 본 적 없는 폰."** 비주얼은 13 문서, 앱별 기능은 06 문서, 설정 앱은 18 문서.
> v6.2: 화면 밖 레이어(수첩)가 없다. 폰이 화면 전부다.

## 1. 화면 구조

```
┌─────────────────────────────┐  ← 실제 기기 화면(모바일 웹 전체)
│ 상태바                        │  시각 · 회선 · Wi-Fi · 비행기 · 동기화 점 · 배터리
│                             │
│   LUMA OS 화면               │  잠금화면 / 홈 / 앱 / 제어 센터 / 검색 / 알림 센터
│   (아들의 폰)                  │
│                             │
│ ── 홈 인디케이터 ──            │
└─────────────────────────────┘
```

- 모바일: 폰 화면이 기기 화면 전체. 게임 UI는 **일시정지 메뉴 하나**(화면 위 가장자리를 세 손가락으로 길게 누르기, 또는 데스크톱 Esc). 메뉴: 계속 / 막혔을 때(04 문서 7절) / 설정(글자 크기·시간 흐름·소리) / 저장·불러오기.
- 데스크톱: 폰을 390×844 프레임으로 중앙에. 양옆은 도현의 방 책상(정적 배경, 정보 없음).

## 4. 홈 화면

- 4×5 격자 + 독, 3페이지. 배치가 도현의 습관을 보여 준다:
  - 1페이지: 루프·톡·메일·누리은행·사진·카메라·지도·캘린더·메모·시계·날씨·한서 포털·웨이브·튜브·설정. 독: 전화·메시지·톡·루프.
  - 2페이지: 한끼·이웃마켓·모아·바로택시·지갑·건강·음성 메모·파일·연락처·미리 알림·찾기, **"유틸" 폴더(계산기·블링크)** — 블링크를 계산기 옆에 숨겼다.
  - 3페이지: 비어 있음.
- 배지: 시작 시 오프라인 캐시 기준. 온라인 후 갱신.
- 배경화면: 2019년 어머니와 셋이 찍은 가족사진(E-30).
- 위로 끌기 = 검색. 아래로 끌기 = 알림 센터. 오른쪽 위에서 끌기 = 제어 센터.

## 5. 알림 시스템

| 종류 | 표시 | 비고 |
|---|---|---|
| 배너 | 상단 4초. 방해 금지 중엔 배너 없이 알림 센터로만 | 탭하면 해당 항목 |
| 알림 센터 | 시간 역순, 앱별 묶음 | **알림 기록은 원본이 지워져도 남는다**(LUMA 규칙). **미리보기 설정은 표시할 때 적용된다** → 설정을 바꾸면 이미 온 알림의 본문도 보인다(18 문서 7절) |
| 보안 알림 | 시러스 ID(로그인·암호·기기·동기화) | 회색 자물쇠. 같은 알림이 슬레이트에도 간다 |
| 동기화 삭제 | 해당 항목 0.4초 페이드 후 사라짐 + "1개 항목이 다른 기기에서 삭제됨" 3초 | 그 앱을 보고 있을 때만 목격 |

## 6. 전역 검색

- 홈에서 위로 끌기, 또는 상태바 두 번 탭.
- 입력한 낱말로 **현재 접근 가능한 모든 데이터**를 검색: 연락처·메시지·톡·메일·메모·미리 알림·캘린더·파일 이름·사진 위치명·지도 저장/최근·웨이브 기록·설정 항목·은행 거래 메모(G-03 이후)·루프(캐시/온라인).
- 결과는 앱별 그룹. 0건이면 "결과 없음" — 힌트 없음.
- 포함 검색 + 표기 변형(띄어쓰기·대소문자·하이픈 무시). 예: "7731", "리버뷰", "민석", "해담".
- 맨 위 **LUMA 제안** 줄: 최근 동기화로 새 데이터가 들어온 앱 3개(04 문서 7절).

## 7. 제어 센터

| 버튼 | 기능 |
|---|---|
| 비행기 모드 | 오프라인 강제 |
| Wi-Fi | 켜기/끄기, 길게 눌러 네트워크 목록 |
| 집중 모드 | 방해 금지 켜기/끄기(슬레이트와 공유) |
| **스크린샷** | 현재 화면을 사진으로. 블링크에서 찍으면 상대에게 알림. 사진 동기화가 켜져 있으면 슬레이트에도 올라감 |
| **화면 기록** | 지금부터 화면을 동영상으로. 블링크는 화면 기록도 감지한다(앱 안내 문구) |
| 손전등·밝기·음량 | 장식 |

## 8. 공통 조작

| 조작 | 결과 |
|---|---|
| 탭 | 열기 |
| **길게 누르기** | 맥락 메뉴: **공유** / 복사 / **정보(i)** / 앱별 동작(저장·좋아요·삭제 등) |
| 공유 | 공유 시트: 최근 대화 상대 5명 + 앱(메시지·톡·루프 DM·메일·블링크) + "스크린샷으로 저장" |
| 왼쪽 가장자리 밀기 | 뒤로 |
| 홈 인디케이터 위로 | 홈 / 위로 멈추면 앱 전환기 |
| 두 손가락 벌리기 | 사진·영상 확대(번호판·화이트보드 판독) |

- **정보(i)** 는 모든 항목에 있다: 사진(촬영 시각·위치·기기·편집 여부), 메시지(전송·읽음 시각·**보낸 기기**), 메일(머리글), 파일(받은 경로·시각), 거래(상대 계좌·메모). 화면에 미리 표시하지 않는다. 플레이어가 열어야 보인다.
- **의도치 않은 흔적:** 루프에서 사진을 두 번 탭하면 좋아요가 눌린다(실제 SNS와 같다). 스토리를 넘기다 다음 사람 스토리가 열린다. 이것도 흔적이다(19 문서). 취소는 가능하지만 알림은 이미 갔다.

## 9. 작성창 (LUMA 키보드)

```
┌─────────────────────────────┐
│ [추천] 누구세요 │ 아빠다 │ 어디야 │  ← 상대별 고정 목록(04 문서 6절)
├─────────────────────────────┤
│ [+] [ 메시지 입력…        ] [↑] │  ← +: 사진·스크린샷·파일·위치·녹음
├─────────────────────────────┤
│  ㅂ ㅈ ㄷ ㄱ ㅅ ㅛ ㅕ ㅑ ㅐ ㅔ   │  ← 두벌식 자판 + 숫자 전환
│  …                          │
└─────────────────────────────┘
```

- 자판 입력은 실제로 된다(한글·영문·숫자). 게임이 알아듣는 낱말 사전은 12 문서 5절.
- 키보드 위 줄에 **클립보드 붙여넣기 칩**이 뜬다(가장 최근 복사 1개). 클립보드 기록 전체는 설정(18 문서).
- **텍스트 대치**가 동작한다: 도현이 등록한 줄임말을 치면 자동으로 바뀐다(예: "ㅈㅅ" → 주소). 슬레이트에서 등록한 것도 온라인 후 동기화된다(18 문서 9절). 플레이어가 우연히 칠 수도 있다.

## 10. 접근성·편의

| 항목 | 규칙 |
|---|---|
| 글자 크기 | 일시정지 메뉴 = LUMA 설정 → 디스플레이(같은 값) |
| 시간 흐름 | 끄기 가능(04 문서 5절) |
| 색 의존 | 상태를 색만으로 표시하지 않는다 |
| 모션 | `prefers-reduced-motion` 시 동기화 삭제는 페이드 없이 문구만 |
| 소리 | 알림음·진동 대체(화면 미세 흔들림). 소리 없이도 모든 정보 전달. 음성 메모·튜브는 자막 |
| 저장 | 자동 저장(접근 해제·EV·공유·메일 발송 시) + 수동 슬롯 3 |

## 11. 화면 갱신 원칙 (구현 교훈 계승)

- 화면 갱신은 DOM 패치(`morph`). 전체 다시 그리기는 앱 전환 때만.
- 실시간 사건이 보고 있는 목록을 바꿀 때는 해당 행만 갱신하고 스크롤 위치를 유지한다.
