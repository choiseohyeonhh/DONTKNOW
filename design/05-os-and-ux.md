# 05. 스마트폰 운영체제(LUMA OS)와 UI/UX

> iOS를 복제하지 않는다. **"처음 쥐어도 쓸 줄 아는, 그러나 어디서도 본 적 없는 폰."** 비주얼 규격은 13 문서, 앱별 기능은 06 문서.

## 1. 화면 구조

```
┌─────────────────────────────┐  ← 실제 기기 화면(모바일 웹 전체)
│ ┌─────────────────────────┐ │
│ │ 상태바                    │ │  시각 · 회선 · Wi-Fi · 비행기 · 배터리
│ │                         │ │
│ │   LUMA OS 화면           │ │  잠금화면 / 홈 / 앱 / 제어 센터 / 검색
│ │   (아들의 폰)              │ │
│ │                         │ │
│ │ ── 홈 인디케이터 ──        │ │
│ └─────────────────────────┘ │
│ [ 수첩 손잡이 ]               │  ← 화면 아래 가장자리, 종이 탭. 위로 끌면 수첩
└─────────────────────────────┘
```

- **두 개의 질감:** 폰은 유리(차갑고 정확함), 수첩은 종이(따뜻하고 부정확함). 이 대비가 게임의 시각 정체성이다(13 문서).
- 데스크톱 브라우저: 폰을 화면 중앙 390×844 프레임으로, 수첩은 오른쪽에 펼쳐진 상태로 나란히(넓은 화면 전용 레이아웃).

## 2. 상태바

| 요소 | 규칙 | 수사적 의미 |
|---|---|---|
| 시각 | 게임 시계(04 문서 5절) | 모든 타임스탬프와 같은 형식 |
| 회선 | 시작 시 "서비스 없음"(분실 정지). 끝까지 복구 안 됨 | 전화·문자는 못 쓴다 → 데이터 앱으로 유도 |
| Wi-Fi | 꺼짐으로 시작. 켜면 "seongwon_home" 자동 연결 | 온라인/오프라인 딜레마의 스위치 |
| 비행기 | 제어 센터에서 토글 | 삭제 명령 차단 |
| 동기화 점 | 온라인일 때 Wi-Fi 아이콘 옆 작은 점이 깜빡이면 "지금 무언가 동기화 중" | **원격 삭제의 유일한 사전 징후.** 설명하지 않는다 |
| 배터리 | 시작 31%(충전 중 아이콘). 장식 | — |

| 영역 | 내용 | 조작 |

**잠금 해제 퍼즐(G-01):**
- 알림 미리보기(지훈 3/14 23:58 톡): "야 근데 너 폰 비번 아직도 아빠 생일이냐 바꿔라 ㅋㅋ" — 3/14 밤 지훈이 도현과 연락이 안 되자 장난 반 걱정 반 보낸 톡.
- 경찰 인수증(수첩 첫 장)과 수첩 메모: "내 생일 68.4.3".
- 정답 **680403**. 해제 순간 연출: 숫자가 들어가고, 아주 짧은 정지(0.6초), 수첩에 손글씨 "내 생일이었다." 그 외 연출 없음(P5).

## 4. 홈 화면

- 4×5 격자 + 독. 앱 배치는 **도현의 사용 습관을 보여 주는 단서**: 첫 페이지에 루프·톡·메일·은행. 블링크는 두 번째 페이지 "유틸" 폴더 안에 계산기와 같이 숨겨져 있다.
- 배지: 시작 시 오프라인 캐시 기준. 온라인 후 갱신.
- 배경화면: 2019년 어머니와 셋이 찍은 가족사진(아버지 포함). 응급정보에서 아버지를 뺀 아들이 배경화면에는 아버지를 두었다 — 설명하지 않는 정서 단서(E-30, 필수 아님).
- 위로 끌기 = **검색**(6절). 아래로 끌기 = 알림 센터. 오른쪽 위에서 끌기 = 제어 센터.

## 5. 알림 시스템

| 종류 | 표시 | 비고 |
|---|---|---|
| 배너 | 상단에서 내려와 4초 | 탭하면 해당 앱·항목으로 이동 |
| 알림 센터 | 시간 역순, 앱별 묶음 | **알림 기록은 원본이 지워져도 남는다**(LUMA 규칙) → 원격 삭제된 메시지의 첫 줄이 알림 센터에 남는 경우가 있다 |
| 보안 알림 | 시러스 ID 관련(로그인·암호 변경·기기 찾기) | 회색 자물쇠 아이콘. 실시간 사건의 주 통로 |
| 동기화 삭제 | 삭제된 항목은 앱에서 0.4초 페이드 후 사라짐. 목록에 "1개 항목이 다른 기기에서 삭제됨" 한 줄이 3초간 | 플레이어가 그 앱을 보고 있을 때만 목격 가능 |

## 6. 전역 검색

- 홈에서 아래→위로 끌거나, 어느 화면에서든 상태바를 두 번 탭.
- 입력한 단어로 **현재 접근 가능한 모든 데이터**를 검색: 연락처·메시지·메일·메모·캘린더·사진 위치명·지도 저장/최근·루프(캐시/온라인)·은행 거래 메모.
- 결과는 앱별 그룹. 결과가 0이면 "결과 없음" — 힌트를 주지 않는다.
- 검색은 정확 일치가 아니라 **포함 검색 + 표기 변형**(띄어쓰기·대소문자·숫자 하이픈 무시). 예: "7731", "352-1048", "리버뷰", "K", "강".
- 이 기능이 Her Story식 자율 탐색의 엔진이다. 플레이어가 다른 앱에서 본 단어를 직접 입력해 연결을 시험한다.

## 7. 제어 센터

| 버튼 | 기능 |
|---|---|
| 비행기 모드 | 오프라인 강제 |
| Wi-Fi | 켜기/끄기, 길게 눌러 네트워크 목록 |
| 화면 기록 | 없음(범위 밖) |
| **스크린샷** | 현재 화면을 사진으로 저장. 블링크에서 찍으면 상대에게 알림(06 문서) |
| 손전등·밝기·음량 | 장식 |

## 8. 공통 조작

| 조작 | 결과 |
|---|---|
| 탭 | 열기 |
| **길게 누르기** | 맥락 메뉴: "수첩에 붙이기" / "복사" / "정보"(메타데이터) / 앱별 동작 |
| 왼쪽 가장자리 밀기 | 뒤로 |
| 홈 인디케이터 위로 | 홈 |
| 수첩 손잡이 위로 | 수첩 열기(시계 멈춤) |
| 두 손가락 벌리기 | 사진 확대(번호판·간판 판독) |

- **"정보"(i)** 는 모든 항목에 있다: 사진(촬영 시각·위치·기기·편집 여부), 메시지(전송·읽음 시각), 메일(머리글: 보낸 사람 주소·받은 시각·예약 여부), 파일(생성·수정 시각). 메타데이터를 플레이어가 **직접 열어야** 보인다. 화면에 미리 표시하지 않는다(P2).

## 9. 수첩 (게임 레이어)

- 화면 아래 종이 손잡이. 위로 끌면 폰 위로 종이가 덮인다(폰은 흐릿하게 뒤에 보임).
- 탭: **질문 / 단서 / 사람 / 시간표 / 내 폰**. 상세는 11 문서.
- 수첩이 열려 있는 동안 게임 시계는 멈춘다.
- 수첩의 모든 글씨는 아버지 손글씨체. 플레이어가 입력하는 텍스트는 없다(카드 배치와 연결만). 예외: 검색어 입력은 폰에서.

## 10. 접근성·편의

| 항목 | 규칙 |
|---|---|
| 글자 크기 | 설정 → 디스플레이에서 3단계(게임 옵션과 LUMA 설정을 같은 화면으로 연결) |
| 시간 흐름 | 끄기 가능(04 문서 5절) |
| 색 의존 | 모순·판정 결과를 색만으로 표시하지 않는다. 손글씨 문장으로 표시 |
| 모션 | `prefers-reduced-motion` 시 동기화 삭제는 페이드 대신 즉시 사라지고 문구만 표시 |
| 소리 | 알림음·진동 대체(화면 미세 흔들림). 소리 없이도 모든 정보 전달 |
| 저장 | 자동 저장(질문 판정·접근 해제·EV 발생 시) + 수동 슬롯 3 |

## 11. 화면 갱신 원칙 (구현 교훈 계승)

- 화면 갱신은 DOM 패치(`morph`)로. 전체 다시 그리기는 앱 전환 애니메이션 때만. 실시간 시계·동기화 이벤트가 많아 이 원칙을 어기면 v5 MVP에서 겪은 깜빡임이 재발한다.
- 실시간 사건이 플레이어가 보고 있는 목록을 바꿀 때는 해당 행만 페이드 처리하고 스크롤 위치를 유지한다.
