# 17. 플레이타임 예산 — 보수 계산과 확장 설계 (v6.1)

> 목표: **빠르고 막히지 않는 숙련 플레이어 기준(보수)으로도 90분 이상.** 일반 플레이어 기준은 그보다 훨씬 길다.
> 원칙: 늘어난 시간은 전부 **읽고, 대조하고, 판정하는 시간**이어야 한다. 이동·대기·반복 클릭으로 시간을 늘리지 않는다(5절 금지 규칙).

## 1. 계산 방법

### 1.1 두 기준 플레이어

| 기준 | 정의 | 쓰임 |
|---|---|---|
| **보수(하한)** | 추리 게임 숙련자. 화면 글을 분당 약 900자로 훑는다(정독의 약 1.5배 속도). 헛걸음 거의 없음, 오답 0~1회, 힌트 안 봄. NPC 답장을 기다리는 동안 다른 일을 함(대기 시간 0으로 계산). 시네마틱은 끝까지 봄 | **설계 합격선. 90분 이상이어야 한다** |
| 일반 | 처음 하는 추리 게임 이용자. 정독, 앱을 여러 번 오감, 오답 판정 2~4회/질문, 힌트 ①을 가끔 봄 | 페이싱·시계 조정 기준 |

## 6. 게임 시계 재조정

v6.0의 실시간 1분 = 게임 6분은 일반 플레이어가 마감(09:00) 전에 끝내지 못한다. 재조정:

| 항목 | v6.0 | **v6.1** |
|---|---|---|
| 비율 | 1분 = 6분 | **1분 = 5분**(폰 화면을 보고 있을 때만) |
| 마감까지 폰 화면 시간 | 118분 | **142분** |
| 일반 플레이어(155분 중 폰 화면 약 105분, 나머지는 수첩) 종료 시각 | 마감 초과 | 약 05:55 → 여유 3시간 |
| 느린 플레이어 | — | 09:00에 닿으면 기본 엔딩(C). 옵션 "시간 흐름 끄기"로 제거 가능 |
| 도현의 경고 | "10분" = 게임 60분(허구와 숫자 불일치) | **"30분"** = 게임 30분 = 실시간 6분. 메시지 숫자와 게임 시계가 일치 |
