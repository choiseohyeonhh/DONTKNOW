## 1. 튜브

### 1.1 ① 레퍼런스 서비스의 핵심 UX

레퍼런스: 유튜브. 핵심은 (a) 홈·구독 피드, (b) 채널 페이지(영상 목록·소개·구독자 수), (c) 시청 페이지(영상·설명란·자막·댓글), (d) 검색, (e) 시청 기록, (f) 자막 켜기/끄기와 자막 내 검색, (g) 좋아요·구독·댓글이다.

### 1.2 ② 참고할 기능과 사용자 행동

- 채널을 열어 영상 목록과 채널 소개를 본다.
- 영상을 재생하고 자막을 켜며, 설명란의 링크를 확인한다.
- 자막에서 낱말을 검색해 구간으로 이동한다.
- 댓글을 최신·상위로 정렬해 읽는다.
- 시청 기록에서 다시 볼 영상을 찾는다.
- 채널의 얼굴·목소리·배경·소품으로 인물을 짐작한다.

### 1.3 ③ 레퍼런스의 불편한 점과 개선

| 불편 | 이 게임의 개선 |
|---|---|
| 추천 알고리즘이 다음 영상을 계속 밀어 준다 | 자동 재생·다음 영상 추천을 두지 않는다. 플레이어가 영상을 고른다. 시간을 늘리는 자동 재생은 금지한다([PLAYTIME_BUDGET.md](../01-product/PLAYTIME_BUDGET.md) 5절) |
| 자막이 숨겨져 있거나 검색이 어렵다 | 자막을 기본으로 켜고, 자막 내 낱말 검색을 제공한다. "그치?"·"화·금 GJ"를 바로 찾는다 |
| 채널의 얼굴이 없으면 허위 채널을 구분하기 어렵다 | 채널 소개에 "얼굴 없음"을 표시하고, 손·시계·차·사무실·말버릇을 단서로 쓴다. 얼굴 판독에 의존하지 않는다 |
| 삭제된 댓글이 사라져 맥락이 끊긴다 | "삭제된 댓글입니다 · 날짜" 자리와 남은 답글을 보존한다 |
| 시청 기록이 추천에 섞여 지워진다 | 시청 기록을 별도 화면에 시간순으로 남긴다. 기록은 플레이어의 타임라인 재구성에 쓴다 |
| 영상 길이·자막이 실제 스트리밍에 묶인다 | 스틸 6~10장 + 자막 + 파형으로 재현한다. 실제 동영상 파일이 없어도 된다 |

### 1.4 ④ 이 게임에 적용하는 방식

- 채널 **"머니코치 강"**(A-19, 얼굴 없음, 구독 4.3만). 영상은 스틸 6~10장 + 자막 + 파형으로 만든다. 실제 동영상은 불필요하다. 재생 막대와 **자막 검색**이 있다.
- 영상 5편의 제목·업로드·핵심·단서는 1.8의 표를 그대로 쓴다.
- 시청 기록(도현): V2 1/6, V3 2/21, V4 3/6, **V4 다시 보기 3/11 23:45**.
- **튜브는 차단과 무관하다.** 다른 서비스이므로 실장을 흔적 없이 보는 가장 쉬운 창이다. 차단된 계정의 영상도 채널 검색으로 볼 수 있다.
- V2 설명란의 "추천 부업 문의 → 루프 @side.money.kr"이 광고 계정과 튜브를 잇는다(E-120).
- V3은 "그치?"가 자막에 3회 나오고, 손목 초록 시계 클로즈업이 있다(E-121).
- V4는 화이트보드 "화·금 GJ / 12F", 창밖 성원대교, 책상 위 SUV 스마트키가 보인다(E-122). 댓글 64개 중 3/13 21:02 민지 댓글이 있다(E-123). EV-23이 발생하면 그 댓글은 "삭제된 댓글입니다 · 3/13" + 남은 답글 "@minji.sw 저도 정지됐어요"로 바뀐다.
- V5 "당분간 영상 쉽니다"는 2026.03.15 02:10, 사건 다음 새벽에 올라온다(E-124). 게임 시작 전에 이미 올라와 있다.
- 플레이어는 영상을 보고, 자막을 검색하고, 설명란·댓글을 읽는다. **댓글 작성·좋아요·구독은 제공하지 않는다**(캐논에 플레이어의 튜브 반응 행동이 없다). 튜브에서 플레이어가 남기는 것은 시청 기록뿐이다.
- 시청 기록은 플레이어의 수사 타임라인 재구성에 쓰는 **로컬·계정 기록**이다. [TRACES_AND_REACTIONS.md](../01-product/TRACES_AND_REACTIONS.md) TR 표에 대응 흔적이 없으므로 실장·도현에게 가는 흔적으로 설계하지 않는다(Q-OPEN-027 결정).

## 2. 모아

### 2.1 ① 레퍼런스 서비스의 핵심 UX

레퍼런스: 에브리타임(대학 익명 커뮤니티)과 당근 동네생활(지역 생활 커뮤니티). 핵심은 (a) 학교·지역 인증, (b) 익명 게시판, (c) 글마다 "익명1, 익명2…"로 붙는 댓글 번호, (d) 인기글·최신글, (e) 쪽지(DM), (f) 내가 쓴 글·댓글 모아 보기다.

### 2.2 ② 참고할 기능과 사용자 행동

- 게시판을 고르고 글 목록을 본다.
- 글을 열어 익명 댓글을 읽는다.
- 익명 번호로 같은 글 안의 발화자를 구분한다.
- 쪽지함에서 1:1 쪽지를 주고받는다.
- 내가 쓴 글·댓글을 모아 본다.
- 글의 시각·조회·댓글 수로 사건의 시간선을 맞춘다.

### 2.3 ③ 레퍼런스의 불편한 점과 개선

| 불편 | 이 게임의 개선 |
|---|---|
| 익명 번호가 글마다 초기화되어 맥락을 잃는다 | 글 안에서만 "익명1, 익명2…"를 쓰고, 글을 벗어나면 재사용하지 않는다. 같은 사람을 글 밖에서 추적하지 않는다 |
| 실시간 알림이 조사를 방해한다 | 새 글·댓글 알림을 기본으로 끈다. 플레이어가 게시판을 열 때만 새 글을 본다 |
| 내가 쓴 글이 묻힌다 | `내가 쓴 글 / 내가 쓴 댓글 / 쪽지함`을 최상위에 둔다 |
| 쪽지 읽음 상태가 모호하다 | 쪽지에 읽음 시각을 표시한다. 읽음이 상대에게 가는지는 앱 안에서만 표시하고, NPC 반응 규칙을 새로 만들지 않는다(Q-OPEN-028 결정) |
| 학교 인증이 익명성의 보장처럼 보인다 | "학교 메일 인증 · 익명"이라고만 표시하고, 신원 보장·추적 불가를 주장하지 않는다 |

### 2.4 ④ 이 게임에 적용하는 방식

- **성원 지역 대학생 익명 게시판 "성원광장"**(학교 메일 인증). 댓글은 글마다 "익명1, 익명2…".
- 도현 계정 A-20: `내가 쓴 글 / 내가 쓴 댓글 / 쪽지함`. 로그인 상태.
- 게시판 3개, 글 34개(8.10). 게시판 이름과 나머지 글은 **장식(단서 아님)**이다. 캐논의 글 2개와 쪽지 2개만 단서다(Q-OPEN-143).
- **내가 쓴 글 2/20:** "성원구청 근처 싼 고시원 추천 좀" — 댓글 "청운 괜찮음 역 4분", "청운 3층 창문방 추천", **"해담은 일세 돼서 급할 때 좋음"**(익명5)(E-130).
- **내가 쓴 글 3/9 04:10:** "통장 빌려준 건데 이거 나 감옥 가냐" — 댓글 32(E-131).
- **그 글의 댓글 익명7 3/9 04:31:** "혹시 굿잡? 나도 했는데 그거 실장K 맞지? 쪽지 줘"(E-132).

## 3. 두 앱의 공통 원칙

- **플랫폼을 건넌다.** 같은 사람이 루프·튜브·모아에서 다른 얼굴로 산다. 강민석은 루프(moneycoach.kang·side.money.kr), 튜브(머니코치 강), 블링크(실장K)에 있다. 윤민지는 루프(minji.sw), 튜브(댓글), 모아(익명7)에 있다.
- **얼굴로 식별하지 않는다.** 튜브는 손·시계·차·사무실·말버릇, 모아는 익명 번호와 문장 습관으로 식별한다.
- **노이즈 70% 이상.** 튜브 V1·모아의 장식 글은 각자의 일상을 산다. 단서를 반짝이게 표시하지 않는다.
- **시각 표기:** 화면은 상대 시각("3일 전"), 정보(i)는 절대 시각.
- **온라인:** 두 앱 모두 T2. 오프라인에서는 캐시 제목만.
- **플레이어의 공개 반응:** 튜브 댓글·좋아요·구독, 모아 글쓰기·댓글·쪽지 답장은 제공하지 않는다. 캐논에 그런 행동과 반응 규칙이 없다. 플레이어가 읽고 보는 것만으로 수사한다.

## 5. 확인 사항

- **Q-OPEN-141:** 튜브 시청 기록은 플레이어의 로컬 수사 기록만이며, 도현·실장에게 가는 흔적이 아니다. (해결 — Q-OPEN-027 결정)
- **Q-OPEN-142:** 모아 쪽지 읽음은 앱 안의 읽음 시각만이며, 익명7(민지)에게 가는 흔적이 아니다. (해결 — Q-OPEN-028 결정)
- **Q-OPEN-143:** 모아 게시판 3개의 이름과 34글의 분배가 캐논에 없다. 이 문서는 게시판 이름을 화면 구조로만 두고 장식으로 표시했다. 이름을 확정하거나 "게시판 1/2/3"으로 둘지 결정해야 한다.
- **Q-OPEN-144:** "내가 쓴 댓글"에 캐논 기록이 없다. 이 문서는 빈 화면으로 두었다. 도현의 모아 댓글을 장식으로 만들지, 실제 댓글을 추가할지 확인이 필요하다.
- **Q-OPEN-145:** 튜브 구독자 수는 "4.3만"으로 통일한다(43.2k는 같은 값의 정밀 표기). (해결 — Q-OPEN-036 결정)
- **Q-OPEN-146:** 튜브 영상의 실제 재생 길이·스틸 수(6~10장)가 영상별로 확정되어 있지 않다. 자막 검색 구간("그치?" 3회, "화·금 GJ")의 정확한 타임코드는 콘텐츠 작성 시 확정해야 한다.
- **Q-OPEN-147:** 모아의 익명 댓글 "익명5"(E-130)와 "익명7"(E-132·E-133)의 표기가 글마다 초기화되는데, E-133에서 익명7이 같은 사람으로 이어진다. 쪽지함에서 상대를 "익명7"로 계속 표시할지, "윤민지"로 바뀌는 시점을 둘지 확정이 필요하다.
