## 1. ① 레퍼런스 서비스의 핵심 UX

레퍼런스: 텔레그램. 핵심 UX는 (a) 대화 목록 상단의 필터(전체·비밀 대화·그룹·채널), (b) 비밀 대화의 기기 한정 표시와 자물쇠 글리프, (c) 읽은 뒤 사라지는 타이머, (d) 스크린샷 알림, (e) 활성 세션 목록, (f) 차단한 사용자 목록, (g) 자동 삭제 규칙이다.

## 2. 보안 표현 원칙 (필수)

### 2.1 일반 대화와 비밀 대화의 구분

이 폰의 블링크에는 **비밀 대화 1개만** 있다. 아래 표의 "일반 대화"는 원칙 설명용이며 이 게임 화면에는 등장하지 않는다.

| 항목 | 일반 대화(이 게임에 없음) | 비밀 대화(실장K) |
|---|---|---|
| 저장 위치 | 계정에 동기화되어 여러 기기에서 보임 | **이 기기에만 저장**. 슬레이트에서 보이지 않음 |
| 참여 | 1:1·그룹·채널 | 1:1만 |
| 삭제 | 직접 삭제, 기기 간 동기화 | **읽은 뒤 60초가 지나면 양쪽에서 사라진다** |
| 캡처 | 상대에게 알림 없음 | **스크린샷·화면 기록을 하면 상대에게 표시된다** |
| 읽음 | 설정에 따라 | **읽음은 즉시 전송된다** |
| 과거 | 남음 | 사라진 대화는 복구되지 않음 |

- 표의 "이 기기에만 저장"은 **본문의 저장 위치**를 말한다. 읽음·캡처 같은 상태 신호는 상대에게 전송된다. 이 구분을 UI 문구에서 흐리지 않는다.

### 2.2 게임 안 문구가 주장하지 않는 것

| 쓰지 않는 문구 | 이유 |
|---|---|
| "종단간 암호화", "복호화할 수 없습니다" | 이 게임은 암호학적 보장을 구현하지도, 검증하지도 않는다. 게임 안에서 그런 보장을 주장하지 않는다 |
| "서버에 절대 저장되지 않습니다" | 읽음·캡처 상태 신호와 전송 대기 상태가 있으므로 문자 그대로 참이 아니다. "이 기기에만 저장"처럼 **범위를 한정**해 말한다 |
| "완전 삭제", "복구 불가" | 60초 뒤 화면에서 사라지는 동작만 말한다. 포렌식적 완전 삭제를 주장하지 않는다 |
| "추적 불가", "해킹 불가", "안전이 보장됩니다" | 보장할 수 없다. 동작(저장 위치·삭제 시점·캡처 알림·읽음 전송)만 설명한다 |
| "익명", "신원 보장" | 계정 이름 "실장K"와 프로필 사진이 있다. 익명성을 주장하지 않는다 |

**허용하는 문구의 형태:** "이 대화는 이 기기에만 저장됩니다 · 읽으면 60초 뒤 양쪽에서 삭제됩니다", "스크린샷을 하면 상대에게 표시됩니다", "읽음은 즉시 전송됩니다". 모두 **관찰 가능한 동작**을 말한다.

### 2.3 현실의 게임이 실제로 하는 것

- 이 게임은 웹 게임이다. **어떤 실제 메시지도 저장·전송하지 않는다.** 실제 계정·서버·DB·인증 서버·네트워크 API가 없다.
- 블링크의 대화·읽음·캡처 알림은 모두 대본이 있는 NPC와 클라이언트 상태의 시뮬레이션이다.
- 저장은 브라우저의 localStorage(자동 저장 + 수동 슬롯 3)뿐이다. 실제 암호화를 제공하지 않는다.
- 따라서 이 게임의 블링크를 실제 비밀 대화·민감 정보 전달에 사용해서는 안 된다. 이 문장은 문서의 원칙이며, 게임 UI에 기술 보장처럼 표시하지 않는다.

## 3. ② 참고할 기능과 사용자 행동

- 대화 목록에서 필터를 바꾸고, 비밀 대화를 연다.
- 말풍선을 읽고, 답장·복사·공유·정보(i)를 쓴다.
- 프로필 사진을 열어 상대를 확인한다.
- 읽은 뒤 남은 삭제 시간을 본다.
- 스크린샷·화면 기록을 찍는다.
- 설정에서 활성 세션·차단 목록·스크린샷 알림 안내·자동 삭제 규칙을 확인한다.

## 4. ③ 레퍼런스의 불편한 점과 개선

- 레퍼런스는 "비밀 대화"라는 말이 무엇을 보장하는지 설명하지 않는다. 개선: LUMA는 대화 상단에 **저장 위치·삭제 시점**만 한 줄로 표시하고, 암호학적 보장은 주장하지 않는다.
- 레퍼런스는 삭제 타이머가 언제 시작되는지(읽기 전/후) 헷갈린다. 개선: 말풍선 아래에 "읽음 · 60초 뒤 삭제"를 숫자로 표시한다. 읽기 전에는 타이머가 시작되지 않는다고 명시한다.
- 레퍼런스는 스크린샷 알림의 범위(화면 기록 포함 여부)를 숨긴다. 개선: 앱 안내 문구에 "스크린샷·화면 기록"을 함께 쓴다.
- 레퍼런스는 세션 목록이 여러 기기를 보여 주지만, 이 게임의 블링크는 한 기기만 허용한다. 개선: 설정에 "이 기기 1대"만 표시하고, 슬레이트가 없다는 사실 자체를 정보로 쓴다.
- 레퍼런스는 그룹·채널 필터가 비어 있어도 빈 화면을 설명하지 않는다. 개선: 빈 필터에는 "대화 없음"만 표시하고 장식 콘텐츠를 넣지 않는다.

## 5. ④ 이 게임에 적용하는 방식

### 5.1 앱의 발견과 로그인

- 블링크는 홈 2페이지 "유틸" 폴더 안, 계산기 옆에 있다. 잠금화면 알림 "블링크: 새 메시지 2개"가 유일한 사전 힌트다(G-05).
- 계정 A-21 "dk". **기기 한 대에만 로그인**되는 앱이라 도현은 슬레이트로 이 대화를 볼 수 없다. 그래서 3/16 21:00 메시지를 도현은 보지 못했고, 3/14 사무실에서 같은 말을 들은 것으로 행동한다([NARRATIVE_CANON.md](../01-product/NARRATIVE_CANON.md) 3.3).
- 오프라인에서 안 읽은 메시지 2. 첫 온라인 때 3/16 메시지가 도착해 3이 된다. 잠금화면 배지는 온라인 전까지 2다.

### 5.2 대화 목록

- 상단 필터: `전체 / 비밀 대화 / 그룹 / 채널`.
- 이 폰에는 **실장K 비밀 대화 1개**만 있다. 그룹·채널 필터는 빈 화면 상태로 존재하며 장식 대화를 넣지 않는다.
- 비밀 대화 행: 자물쇠 글리프 + "실장K" + 마지막 메시지 대신 "새 메시지" 또는 삭제 상태 + 시각 + 안 읽음 수.
- 대화를 열면 상단에 "이 기기에만 저장 · 읽고 60초 뒤 삭제"를 표시한다. 이 문구는 2.2의 허용 범위를 넘지 않는다.

### 5.3 대화방

- 1:1 비밀 대화. 말풍선은 상대 왼쪽·내 오른쪽. 프로필 사진은 차 실내 일부이며 녹색 시계 문자판 끝이 보인다(E-61).
- 길게 누르기: 복사 / 공유 / 정보(i). 답장은 제공하되, 답장 자체가 위험하다는 경고를 별도로 띄우지 않는다(플레이어의 판단).
- 정보(i): 보낸 시각·읽음 시각·보낸 기기(슬레이트/이 기기)·삭제 예정 시각.
- 읽음 이벤트가 발생하면 그 대화의 메시지에 60초 카운트다운이 붙고, 0이 되면 양쪽에서 사라진다. 사라진 뒤에는 "이 대화의 메시지는 사라졌습니다"만 남고 복구 UI가 없다.
- 스크린샷·화면 기록: 제어 센터의 스크린샷/화면 기록을 쓰면 실장에게 "상대방이 화면을 캡처했습니다"가 표시된다(TR-06, KS-2, EV-12). 이 기기에는 캡처 사실이 남고, 캡처 이미지는 사진 앱에 저장된다.
- 앱 전환기 썸네일은 내용을 흐린다(공통 셸 규칙).

### 5.4 읽는 방법 네 가지

플레이어는 방법을 스스로 찾는다. 각 방법의 결과는 9.3의 표를 그대로 쓴다.

1. **그냥 연다(온라인):** 읽음 → KS-1, 60초 뒤 사라짐.
2. **비행기 모드에서 연다:** 읽을 수 있음. 읽음은 대기 → 다음 온라인 때 전송(KS-1). 읽음이 즉시 가지 않지만 결국 간다.
3. **설정 → 알림 → 블링크 → 미리보기 "항상":** 알림 센터에서 세 통의 본문이 다 보인다. 읽음 없음(V-15). 앱을 열지 않았으므로 60초 타이머도 시작되지 않는다.
4. **열고 스크린샷:** 캡처가 남는다. 실장에게 "상대방이 화면을 캡처했습니다" → KS-2.

- 미리보기로 읽은 뒤 앱을 열면 그때 읽음이 가고 60초가 시작된다. "이미 본 것을 또 읽는" 행동도 흔적이다.
- 3/10 도현의 캡처 1장이 사진첩에 있다(E-36). 1/9~3/10 대화는 이미 사라졌고 복구되지 않는다.

### 5.5 보내기와 위치 유출

- 실장에게 보낼 수 있다. 위험하다. 답장 자체가 생존 신호다(TR-19).
- 다음 중 하나를 보내면 **F-LEAK**가 된다([PROGRESSION_AND_ENDINGS.md](../01-product/PROGRESSION_AND_ENDINGS.md) 6.2).
  - 장소 낱말 "해담"·"207"·"성원구청로 31"·"성원구청역"(F-MOVED면 "성원스파")
  - 해담을 가리키는 단서 공유(E-150·E-198·E-219·E-220·E-73 스크린샷)
  - 정체 숨김 상태로 "어디야"에 "어"·"응"·"집 근처" 답 → 실장이 생존·근거리 확신
- **"청운"·"304"는 유출이 아니다.** 실장은 청운으로 가서 허탕 친다. 경계만 오른다(KS-2).
- F-LEAK 뒤 120분에 EV-17(@jh_lee_99 스토리: 성원구청역 2번 출구 사진)이 발생한다. 먼저 택시를 부르면 무효다.
- 청운·304를 보내는 것은 위치 유출이 아니지만, 실장을 움직여 KS-2를 만든다.

### 5.6 설정 > 개인정보 및 보안

- **활성 세션:** 이 기기 1대만. "도현의 슬레이트"는 없다. 이 화면이 "한 기기에만 로그인"의 시각적 증거다.
- **차단한 사용자:** 0. 차단 목록은 빈 화면이며 장식 사용자를 넣지 않는다.
- **스크린샷 알림 안내:** "스크린샷·화면 기록을 하면 상대에게 표시됩니다." 켜고 끄는 토글은 없다(규칙 고정).
- **자동 삭제 규칙:** "읽은 뒤 60초". 변경 불가.
- 설정에는 종단간 암호화 상태·보안 코드·비밀번호 같은 항목을 두지 않는다. 2.2의 원칙에 어긋나는 화면을 만들지 않는다.

## 9. ⑧ 캐논 데이터 (원본 그대로)

### 9.1 앱의 위치와 기본 상태

- 2페이지 "유틸" 폴더 안. 실장K 대화방 하나. 오프라인에서 안 읽은 메시지 2, 첫 온라인 때 3/16 메시지 도착 → 3. 기기 한 대에만 로그인되는 앱이라 도현은 슬레이트로 이 대화를 볼 수 없다.

### 9.2 규칙(앱 안내 문구)과 메시지

- 규칙(앱 안내 문구): ① 읽은 뒤 60초가 지나면 양쪽에서 사라진다 ② 스크린샷·화면 기록을 하면 상대에게 표시된다 ③ 읽음은 즉시 전송된다.
- 안 읽은 메시지:
  - 3/14 18:40 "오늘 8시 사무실. 안 오면 니 아빠 회사로 간다"
  - 3/14 21:30 "녹음했다고? 폰 내놔"
  - 3/16 21:00 "수요일 정오까지 돈 안 가져오면 니 아빠 회사 간다. 한빛물류 맞지?"

**읽는 방법 4가지(플레이어가 찾는다):**

| 방법 | 결과 |
|---|---|
| 그냥 연다(온라인) | 읽음 → KS-1, 60초 뒤 사라짐 |
| 비행기 모드에서 연다 | 읽을 수 있음. 읽음은 대기 → 다음 온라인 때 전송(KS-1) |
| **설정 → 알림 → 블링크 → 미리보기 "항상"** | 알림 센터에서 세 통의 본문이 다 보인다. 읽음 없음([SETTINGS_SPECIFICATION.md](SETTINGS_SPECIFICATION.md) 7절) |
| 열고 스크린샷 | 캡처가 남는다. 실장에게 "상대방이 화면을 캡처했습니다" → KS-2 |

- 사라진 대화(1/9~3/10)는 없다. 도현의 3/10 캡처 1장이 사진첩에 있다(E-36).
- 실장에게 보낼 수 있다(위험). 위치 관련 낱말·공유는 위치 유출(F-LEAK).

### 9.3 프로필·과거 대화·설정

- 실장K 프로필 사진: 차 실내, 녹색 시계 끝(E-61).

- 스크린샷 알림 안내, 자동 삭제 규칙: 9.2의 규칙 ②③과 같다. 이 게임에서는 고정이며 플레이어가 끄지 못한다.

## 11. 확인 사항

- **Q-OPEN-121:** [MAIL_AND_CLOUD_SPECIFICATION.md](MAIL_AND_CLOUD_SPECIFICATION.md) 1절의 "서버에서 대기: 블링크 미전송 읽음"과 "이 기기에만 저장" 문구가 충돌해 보인다. 이 문서는 본문은 기기에만, 읽음·캡처 상태 신호만 전송되는 것으로 정리하고, UI 문구를 "이 대화는 이 기기에만 저장됩니다"로 한정했다. 이 해석을 총괄이 확정해야 한다.
- **Q-OPEN-122:** 60초 타이머의 시작 단위가 메시지별인지 대화 전체인지 캐논에 명시되지 않았다. 이 문서는 "읽음 이벤트가 발생한 대화의 메시지 전체에 60초"로 정했다. 메시지별 타이머가 필요하면 문구를 바꿔야 한다.
- **Q-OPEN-123:** 오프라인에서 캡처하면 "상대에게 표시"가 즉시인지 다음 온라인 때인지 캐논에 없다. 이 문서는 흔적 지연 원칙([TRACES_AND_REACTIONS.md](../01-product/TRACES_AND_REACTIONS.md) 1절)에 따라 다음 온라인 때 전송으로 정했다.
- **Q-OPEN-124:** 화면 기록의 저장 위치가 캐논에 없다. 이 문서는 사진 앱의 화면 기록 앨범으로 정했다. 사진 앱 명세와 일치시켜야 한다.
- **Q-OPEN-125:** "읽음은 즉시 전송"과 "비행기 모드에서 읽으면 대기"가 함께 성립하는지 확인이 필요하다. 이 문서는 온라인일 때 즉시, 오프라인일 때 다음 온라인 때로 해석했다.
- **Q-OPEN-126:** 비밀 대화의 과거(1/9~3/10)가 "없다"는 것과 3/10 캡처 1장이 남는다는 것의 화면 표현을 확정해야 한다. 이 문서는 대화방에 사라진 과거를 표시하지 않고, 사진 앱 캡처만 남긴다.
