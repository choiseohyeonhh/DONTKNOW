## 2. ② 참고할 기능과 사용자 행동

- 잠금화면에서 알림을 훑고, 응급정보를 열고, 카메라로 지금 앞을 찍는다. 암호를 입력해 들어간다.
- 홈에서 앱을 열고, 페이지를 넘기고, 폴더를 연다. 배지로 새 데이터를 짐작한다.
- 상태바의 회선·Wi-Fi·동기화 점·집중 모드를 보고 온라인/오프라인을 판단한다.
- 배너를 놓치면 알림 센터에서 다시 본다. 미리보기 설정을 바꿔 본문을 확인한다.
- 제어 센터에서 Wi-Fi·비행기·집중 모드를 바꾸고, 스크린샷·화면 기록을 찍는다.
- 전역 검색에 이름·번호·장소를 넣어 앱을 가로질러 찾는다.
- 앱 전환기로 앱 사이를 오가며 읽던 위치를 유지한다.
- 항목을 길게 눌러 공유·복사·정보(i)를 연다. 공유 시트에서 대상과 앱을 고른다.
- 작성창에서 추천 문장을 고르거나 직접 입력하고, 클립보드·텍스트 대치·첨부를 쓴다.
- 일시정지 메뉴에서 멈추고, 막혔을 때 힌트를 단계적으로 받고, 저장·불러오기를 한다.
- 프롤로그·엔딩을 스틸과 자막으로 본다.

## 3. ③ 레퍼런스의 불편한 점과 개선

| 불편 | 이 게임의 개선 |
|---|---|
| 알림이 너무 많아 중요한 것이 묻힌다 | 앱별 묶음 + 미리보기 설정을 표시 시점에 적용. 알림 기록은 원본이 지워져도 남는다. 단, 첫 온라인 때는 방해 금지 때문에 배너가 아니라 알림 센터에만 쌓인다(의도된 놓침). |
| 미리보기 설정의 의미가 직관적이지 않다 | 앱별 설정 행에 "잠금화면에 무엇이 보이는지"를 한 줄로 표시한다. 설정을 바꾸면 이미 쌓인 알림에도 즉시 반영된다. |
| 숨은 제스처가 많다 | 같은 동작을 두 가지로 제공한다: 위로 끌기 = 검색, 상태바 두 번 탭 = 검색. 홈 인디케이터 위로 = 홈, 멈추면 앱 전환기. |
| 파괴적 동작이 깊은 메뉴에 있다 | 원격 지우기·암호 변경처럼 되돌릴 수 없는 동작만 중앙 경고창을 쓰고, 나머지는 하단 시트에서 확인한다. |
| 키보드가 무엇을 학습했는지 모른다 | 클립보드는 최근 1개를 작성창 위에 칩으로 보여 주고, 전체 10개는 설정에서만 본다. 텍스트 대치는 바뀐 결과를 입력창에 즉시 보여 준다. |
| 접근성 설정이 앱마다 다르다 | 글자 크기·동작 줄이기·소리는 일시정지 메뉴와 LUMA 설정이 같은 값을 쓴다. 상태를 색만으로 표시하지 않는다. |
| 시스템 UI가 게임의 판정을 대신한다 | LUMA는 정답·오답을 표시하지 않는다. 잠금 오답은 시간만 지연시키고, 검색 0건은 "결과 없음"만 말한다. |

## 4. ④ 이 게임에 적용하는 방식

- **폰이 화면 전부다.** 게임 UI는 일시정지 메뉴 하나뿐이다. 폰 밖 판정·수집 화면은 없다.
- **모든 것은 시뮬레이션이다.** 상태바의 온라인·동기화 점, 알림, 메시지 송수신, 원격 삭제는 단일 상태 트리와 이벤트 로그로만 동작한다. 실제 기기 권한·네트워크 요청·푸시는 쓰지 않는다.
- **시작 상태:** 3/17(화) 21:10, 잠금, 오프라인, 방해 금지 켜짐, 배터리 31%·충전 중, 다크 모드. 잠금화면 시계와 모든 타임스탬프는 같은 형식(24시간)을 쓴다.
- **라이트/다크:** 게임 시작 시 다크(도현의 설정). 설정 → 디스플레이에서 라이트/다크/자동 전환을 제공하며 플레이어 전환을 허용한다(스토리 영향 없음, Q-OPEN-017 결정). 모든 화면은 두 모드를 모두 명세한다.
- **동작 줄이기:** `prefers-reduced-motion` 또는 게임 설정 "동작 줄이기"가 켜지면 화면 이동 없이 150ms 페이드. 동기화 삭제도 페이드 없이 문구만 바뀐다.
- **글자 크기:** 0.85 / 1.0 / 1.15 / 1.3의 4단계. `caption-2`는 최소 11을 유지한다. 같은 값이 일시정지 메뉴와 LUMA 설정에 적용된다.
- **화면 갱신:** DOM 패치. 실시간 사건이 보고 있는 목록을 바꿀 때는 해당 행만 갱신하고 스크롤 위치를 유지한다.

### 4.1 잠금화면 (T0)

- 구성: 시계·날짜, 분실 모드 카드, 알림 더미, 위젯, 응급정보 진입, 카메라, 비밀번호 키패드. 표는 8.1.
- **분실 모드 카드:** 도현이 3/15 00:20 슬레이트에서 켰다. 문구는 "이 폰을 주우셨다면 연락 부탁드립니다. 010-XXXX-2290". [통화]를 누르면 "서비스 없음"만 뜬다. 잠금 해제 시 문구가 사라진다(E-02).
- **알림 더미:** 3/15 03:58 이전 알림 23개. 앱별 묶음. 잠금화면에서 메시지·톡·메일·은행은 첫 줄 미리보기를 보여 주고, 블링크·루프 DM은 "새 메시지" 문구만 보여 준다. 이는 [BUSINESS_RULES.md](../01-product/BUSINESS_RULES.md) 9절의 프롤로그 예시(은행 "…지급정지…", 경찰 "[성원경찰서] 이도현님…", 지훈 "야 너 어디야 전화 좀 받아")와 일치한다. [SETTINGS_SPECIFICATION.md](SETTINGS_SPECIFICATION.md) 7절의 "잠금 해제 시"는 해제 후 알림 센터 표시 규칙으로 해석한다(Q-OPEN-016 결정).
- **위젯:** 캘린더 "다음 일정: 3/16 입실"(지난 일정, 회색) / 배터리. 고시원 첫 단서지만 아직 이름은 없다. 위젯은 표시만 하고 탭해도 앱을 열지 않는다(잠금 상태).
- **응급정보:** 좌하단 "응급"에서 연다. 이름 이도현 · 생년월일 2007.09.21 · 혈액형 A+ · 메모 "왼쪽 손목 골절 수술(2021)" · 긴급 연락처 정지훈(친구). **아빠가 없다.** 잠금 해제 없이 볼 수 있다(E-07).
- **카메라:** 오른쪽 아래. 찍기만 가능하고 사진첩은 볼 수 없다. 도현의 방을 찍을 수 있다. 찍은 사진은 잠금 해제 후 사진 앱에 저장된다.
- **비밀번호 키패드:** 6자리. 오답 6회째부터 30초 대기, 잠금 초기화 없음. 정답은 **070921**(응급정보 생년월일, E-07). 해제 순간 연출 없음. 홈이 바로 나온다. 이 쉬움은 "폰을 만지는 법"을 배우는 구간이며, 다음 자물쇠(잠긴 메모 암호)부터 어려워진다.
- 잠금화면에서는 제어 센터·알림 센터·전역 검색을 열 수 없다. 알림을 탭하면 키패드가 먼저 뜬다.
- 잠금 상태에서 전화를 걸 수 없다. 분실 모드 카드의 [통화]도 실패한다.

### 4.2 홈

- **4×5 격자 + 독, 3페이지.** 배치는 8.3의 표를 그대로 쓴다. 배치 자체가 도현의 습관을 보여 준다.
- 1페이지: 루프·톡·메일·누리은행·사진·카메라·지도·캘린더·메모·시계·날씨·한서 포털·웨이브·튜브·설정. 독: 전화·메시지·톡·루프.
- 2페이지: 한끼·이웃마켓·모아·바로택시·지갑·건강·음성 메모·파일·연락처·미리 알림·찾기, **"유틸" 폴더(계산기·블링크)**. 블링크를 계산기 옆에 숨겼다.
- 3페이지: 비어 있음.
- 배지: 시작 시 오프라인 캐시 기준. 온라인 후 갱신. 배지 숫자는 앱의 "안 읽은 항목 수" 규칙을 따른다.
- 배경화면: 2019년 어머니와 셋이 찍은 가족사진(E-30). 잠금화면과 홈에 같은 사진을 쓴다.
- 제스처: 화면 가운데에서 아래로 끌기 = 검색, **화면 맨 위 왼쪽(폭 60%)에서 끌어내리기 = 알림 센터, 맨 위 오른쪽(나머지 40%)에서 끌어내리기 = 제어 센터**, 좌우로 끌기 = 페이지. 위쪽 끌어내리기는 홈과 앱 안 어디서나 된다(4.4·4.5).
- 끌어내리기는 손가락을 따라온다. 알림 센터는 커튼처럼 위에서 내려오고, 제어 센터는 오른쪽 위를 기준으로 커지며 나타난다. 놓을 때 30% 이상 내렸거나 빠르게 튕겼으면 열리고, 아니면 되돌아간다. 열린 화면은 위로 밀어 닫는다(손가락을 따라 올라간다).
- 폴더: "유틸"은 한 페이지짜리 폴더다. 폴더 안에서 계산기와 블링크만 보인다. 다른 앱은 넣을 수 없다.
- 홈 편집 모드(아이콘 흔들기·삭제)는 없다. 아이콘 탭만 동작한다. 앱 삭제·이동으로 단서를 잃는 상태를 만들지 않는다.
- 홈 인디케이터 위로 = 홈. 앱 안에서 위로 밀면 홈으로 나가고, 멈추면 앱 전환기다.

### 4.3 상태바

- 요소와 의미는 8.4의 표를 그대로 쓴다. 상태바는 모든 화면 위에 있고, 시네마틱·일시정지 메뉴에서는 숨긴다.
- 시각은 게임 시계(실시간 1분 = 게임 4분)다. 모든 타임스탬프와 같은 24시간 형식이다.
- 회선은 끝까지 "서비스 없음"(분실 정지). 전화·문자(셀룰러 SMS) 불가 → 데이터 앱으로 간다.
- Wi-Fi는 꺼짐으로 시작. 켜면 "seongwon_home"에 자동 연결된다. 이것이 온라인/오프라인 딜레마의 스위치다(G-02).
- 비행기 모드는 제어 센터에서 켠다. 오프라인을 강제하며 삭제 명령·흔적 전송을 막는다.
- **동기화 점:** Wi-Fi 아이콘 옆 작은 점. 깜빡이면 "지금 무엇인가 오가는 중"이다. 원격 삭제와 흔적 전송의 유일한 사전 징후이며, 설명하지 않는다. 툴팁·라벨·경고 문구를 붙이지 않는다. 오프라인이면 나타나지 않는다.
- 집중 모드: 달 아이콘 "방해 금지"가 켜진 채로 시작한다(슬레이트에서 공유됨). 끄면 슬레이트의 방해 금지도 꺼진다(TR-12).
- 배터리: 31%, 충전 중. 장식이다.

### 4.4 알림 배너와 알림 센터

- **열기:** 상태바 왼쪽(화면 폭 0~60%)에서 아래로 끌어내린다. 홈과 앱 안 어디서나 된다. 잠금화면에서는 열리지 않는다(잠금화면 자체가 알림 더미를 보여 준다). 닫기는 위로 밀기·홈 인디케이터·Esc.
- **배경 알림:** 캐논 사건 말고도 친구·단톡·앱의 일상 알림이 불규칙하게 온다(온라인일 때만). 빈도·간격·캐논 사건과의 간격·묶음 규칙은 [MESSAGING_SPECIFICATION](MESSAGING_SPECIFICATION.md) 3.9.3·3.9.5가 단일 출처다.
- 배너는 상단에 4초. 방해 금지 중엔 배너 없이 알림 센터로만 간다. 탭하면 해당 항목을 연다(잠금 상태면 키패드 먼저).
- 알림 센터는 시간 역순, 앱별 묶음. **알림 기록은 원본이 지워져도 남는다**(LUMA 규칙). 원본이 사라져도 첫 줄과 앱 이름·시각은 남는다.
- **미리보기 설정은 알림을 표시할 때 적용된다.** 설정을 바꾸면 이미 온 알림의 본문도 보인다([SETTINGS_SPECIFICATION.md](SETTINGS_SPECIFICATION.md) 7절). 블링크를 "항상"으로 바꾸면 세 통의 본문이 알림 센터에 보이고, 앱을 열지 않았으므로 읽음은 가지 않는다(V-15).
- 시작 기본값: 블링크 미리보기 "안 함"(3/10 도현이 바꿈), 루프 DM "안 함", 나머지 "잠금 해제 시". 잠금화면 표시는 4.1의 규칙을 우선한다.
- 보안 알림: 시러스 ID(로그인·암호·기기·동기화). 회색 자물쇠. 같은 알림이 슬레이트에도 간다(E-16). 플레이어가 보는 보안 알림을 도현도 본다.
- 동기화 삭제: 해당 항목이 0.4초 페이드 후 사라지고 "1개 항목이 다른 기기에서 삭제됨"이 3초 표시된다. 그 앱을 보고 있을 때만 목격한다. `prefers-reduced-motion`이면 페이드 없이 문구만.
- 알림을 길게 눌러도 새 동작을 만들지 않는다. 탭 = 열기 하나만 둔다.
- 빈 상태: "알림 없음". 추천·광고를 넣지 않는다.

### 4.5 제어 센터

- 열기: 상태바 오른쪽(화면 폭 60%~100%)에서 아래로 끌기. 홈과 앱 안 어디서나 열린다. 잠금화면에서는 열리지 않는다.
- 닫기: 위로 밀기, 바깥 탭, 홈 인디케이터, Esc. 토글을 눌러도 닫히지 않고 그 자리에서 상태만 바뀐다.
- 버튼: 비행기 모드 / Wi-Fi(켜기·끄기, 길게 눌러 네트워크 목록) / 집중 모드(방해 금지, 슬레이트와 공유) / **스크린샷** / **화면 기록** / 손전등·밝기·음량(장식). 표는 8.6.
- **스크린샷:** 현재 화면을 사진으로 저장한다. 블링크에서 찍으면 상대에게 알림이 간다(TR-06, KS-2). 사진 동기화가 켜져 있으면 슬레이트에도 올라간다(TR-07). 다른 앱의 스크린샷은 조용하다.
- **화면 기록:** 지금부터 화면을 동영상으로 저장한다. 블링크는 화면 기록도 감지한다(앱 안내 문구). 저장 위치는 사진 앱의 화면 기록 앨범이다.
- 토글 상태는 즉시 상태바에 반영된다. 오프라인 전환 시 대기 중인 흔적·삭제 명령은 다음 온라인 순간 몰아서 적용된다.

### 4.6 전역 검색

- 열기: 홈에서 위로 끌기, 또는 상태바 두 번 탭.
- 입력한 낱말로 **현재 접근 가능한 모든 데이터**를 검색한다: 연락처·메시지·톡·메일·메모·미리 알림·캘린더·파일 이름·사진 위치명·지도 저장/최근·웨이브 기록·설정 항목·은행 거래 메모(G-03 이후)·루프(캐시/온라인).
- 결과는 앱별 그룹. 0건이면 "결과 없음"만 표시하고 힌트를 넣지 않는다.
- 포함 검색 + 표기 변형(띄어쓰기·대소문자·하이픈 무시). 예: "7731", "리버뷰", "민석", "해담".
- 맨 위 **LUMA 제안** 줄: 최근 동기화로 새 데이터가 들어온 앱 3개. 무엇이 새로 들어왔는지만 알려 주고, 단서의 내용은 말하지 않는다.
- 오프라인: 로컬 데이터와 루프 캐시만. 온라인: 동기화 데이터와 실시간 데이터까지. 잠긴 앱의 데이터(은행 거래, 부계정)는 해당 게이트 전에는 결과에 나오지 않는다.
- 검색 기록은 남기지 않는다. 검색어를 다시 입력해야 한다.

### 4.7 앱 전환기

- 홈 인디케이터를 위로 밀다가 멈추면 열린다. 열린 앱 카드가 최근 순서로 보인다. 카드 탭 = 그 앱. 카드를 위로 밀면 닫는다.
- 앱을 닫아도 계정 로그아웃·이벤트 중단은 없다. 알림은 계속 도착한다.
- 카드의 스크롤 위치·입력 중이던 글은 보존된다. 단, 앱을 닫으면 작성 중 초안이 사라지는 앱은 없다(초안은 앱 상태에 남는다).
- 블링크 카드와 잠금 상태의 카드 썸네일은 내용을 흐리고 앱 이름만 보여 준다. 어깨너머로 비밀 대화가 노출되지 않게 하는 UI 안전 장치다.
- "모두 닫기"는 없다.
- 시간 흐름을 끈 상태에서는 앱 전환 1회 = 게임 1분으로 계산한다([BUSINESS_RULES.md](../01-product/BUSINESS_RULES.md) 5절).

### 4.8 공통 조작

- 조작표는 8.8. 탭 = 열기, 길게 누르기 = 맥락 메뉴(공유 / 복사 / 정보(i) / 앱별 동작), 왼쪽 가장자리 밀기 = 뒤로, 홈 인디케이터 위로 = 홈, 두 손가락 벌리기 = 사진·영상 확대.
- **공유 시트:** 최근 대화 상대 5명 + 앱(메시지·톡·루프 DM·메일·블링크) + "스크린샷으로 저장". 오프라인이면 온라인 대상은 비활성되고 "온라인이 필요합니다"를 표시한다. 스크린샷 저장은 오프라인에서도 된다.
- **정보(i)** 는 모든 항목에 있다. 사진(촬영 시각·위치·기기·편집 여부), 메시지(전송·읽음 시각·**보낸 기기**), 메일(머리글), 파일(받은 경로·시각), 거래(상대 계좌·메모). 화면에 미리 표시하지 않는다. 플레이어가 열어야 보인다.
- **확대:** 사진·영상은 두 손가락으로 확대한다. 번호판·화이트보드·문 번호는 확대해야 읽힌다. 루프 사진 게시물의 두 번 탭은 확대가 아니라 좋아요다(의도치 않은 흔적, TR-14).
- **의도치 않은 흔적:** 루프에서 사진을 두 번 탭하면 좋아요가 눌린다. 스토리를 넘기다 다음 사람 스토리가 열린다. 취소는 가능하지만 알림은 이미 갔다(TR-05, TR-14).
- 복사는 텍스트에만 있다. 복사한 텍스트는 클립보드 최근 1개가 되고, 전체 10개는 설정 → 키보드에 남는다.

### 4.9 작성창/LUMA 키보드

```
┌─────────────────────────────┐
│ [추천] 누구세요 │ 아빠다 │ 어디야 │
├─────────────────────────────┤
│ [+] [ 메시지 입력…        ] [↑] │
├─────────────────────────────┤
│  ㅂ ㅈ ㄷ ㄱ ㅅ ㅛ ㅕ ㅑ ㅐ ㅔ   │
│  …                          │
└─────────────────────────────┘
```

- **추천 문장 줄:** 키보드 위 3~5개. 대화 상대별 고정 목록이다. 플레이어가 무엇을 알아냈는지에 따라 바뀌지 않는다(자동 연결 금지). 도현에게는 "누구세요"·"아빠다"·"어디야" 등이 있다. 전체 목록은 콘텐츠 데이터이며 [ACTION_PROOF.md](../01-product/ACTION_PROOF.md) 3절의 낱말 사전과 별개다.
- **직접 입력:** 한글·영문·숫자가 실제로 입력된다(두벌식, 숫자 전환). 게임이 알아듣는 것은 미리 정한 낱말(사람·장소·돈·정체·기타)뿐이고, 나머지는 인물별 기본 반응으로 받는다.
- 입력 처리 순서: ① 공유 첨부가 있으면 첨부의 단서 ID로 반응표를 먼저 찾는다 ② 없으면 추천 문장 ID ③ 없으면 직접 입력에서 사전 낱말을 찾는다(여러 개면 위험 낱말(장소) → 사람 → 돈 → 정체 순) ④ 다 없으면 기본 반응.
- **클립보드 칩:** 키보드 위에 가장 최근 복사 1개가 뜬다. 탭하면 입력창에 붙는다. 전체 기록은 설정 → 키보드에서 본다.
- **텍스트 대치:** 도현이 등록한 줄임말을 치면 자동으로 바뀐다. 예: "ㅈㅅ" → "성원구청로 31 해담고시텔 207호". 슬레이트에서 등록한 것도 온라인 후 동기화된다. 플레이어가 우연히 칠 수 있다.
- **+ 첨부:** 사진·스크린샷·파일·위치·녹음. 첨부는 칩으로 표시되고, 보내면 상대에게 간다. 첨부의 단서 ID가 반응을 결정한다.
- 발신은 온라인에서만. 오프라인이면 전송 버튼이 비활성되고 "온라인이 필요합니다"가 뜬다. 입력한 글은 초안으로 남는다.
- 전송 상태: 입력 중 → 전송 중 → 전송됨. 읽음 표시는 앱별 규칙(톡 "1", 블링크 읽음, 루프 DM 읽음 확인)을 따른다. 실패는 "전송 실패"로만 표시하고 재시도를 제공한다.
- 정체: "아저씨다"·"아빠다"·"도현이 아빠입니다"를 보내기 전까지 상대는 도현이 보낸 줄 안다. 자동으로 밝혀지지 않는다.
- 키보드 예측 단어·음성 입력은 없다. 추천 줄은 게임의 대화 추천이지 자판 학습이 아니다.

### 4.10 일시정지 메뉴

- 열기: 화면 위 가장자리를 세 손가락으로 500ms 길게 누르기, 상태바 시각 1.5초 길게 누르기, 또는 데스크톱 Esc. 상태바 시각은 단일 포인터 대체 경로다(Q-OPEN-019 결정).
- 열리면 게임 시계와 NPC 이벤트가 멈춘다. 닫으면 이어서 흐른다.
- 항목: **계속 / 막혔을 때 / 설정 / 저장·불러오기.**
- **막혔을 때:** [PROGRESSION_AND_ENDINGS.md](../01-product/PROGRESSION_AND_ENDINGS.md) 7절의 목표 목록에서 "가장 이른 미완료 목표" 하나를 고르고 3단계 힌트를 한 번에 하나씩 보여 준다(① 방향 ② 앱 ③ 위치). 목표 목록을 화면에 나열하지 않는다. ③을 본 뒤에도 플레이어가 직접 행동해야 한다. 힌트 사용은 판정·엔딩에 영향을 주지 않는다.
- **설정:** 글자 크기(4단계) · 시간 흐름(켜기/끄기) · 소리(켜기/끄기) · 동작 줄이기. 글자 크기는 LUMA 설정 → 디스플레이와 같은 값이다. 시간 흐름을 끄면 앱 전환 1회 = 게임 1분.
- **저장·불러오기:** MVP는 자동 저장(접근 해제·EV·공유·메일 발송 시)만 쓴다. 수동 슬롯 3은 본편(P8)이다(Q-OPEN-023 결정). 슬롯에는 시각·진행 요약(예: "락 해제 · T2 · DH-2")만 표시하고 단서 내용은 표시하지 않는다. 덮어쓰기·불러오기는 확인 시트 1회. 불러오면 그 시점의 시계·플래그·알림·열람 기록(`seen`/`inspected`)이 함께 돌아간다.
- 일시정지 메뉴는 폰 화면 위에 뜨는 유일한 게임 UI다. 폰 밖 배경(데스크톱 여백)은 도현의 방 책상이며 정보가 없다.

### 4.11 프롤로그·엔딩 시네마틱 재생기

- 형식: 스틸 3~5컷 + 하단 자막. 3인칭 상황 자막은 허용하되 감정을 설명하지 않는다. 소리 없이도 모든 정보가 전달된다.
- 조작: 탭/스페이스 = 다음 컷. 첫 재생에서는 건너뛰기가 없다. 한 번 본 뒤 다시 보기에서는 건너뛰기와 컷 이동을 제공한다. 자막은 항상 표시한다.
- **프롤로그:** 3컷. ① 경찰서 민원실 "3월 15일 밤, 이상철 씨는 아들의 실종을 신고했다." 경찰 "성인이라 가출인으로 분류됩니다." ② 같은 자리, 경찰 "여자친구분이 토요일 밤 10시까지 같이 있었다고 하시네요." / 인수증 "습득 3/15 01:10 바로택시 차내." ③ 도현의 방, 충전기에 꽂힌 폰. "3월 17일 밤 9시 10분."(E-01)
- **엔딩:** 판정은 [PROGRESSION_AND_ENDINGS.md](../01-product/PROGRESSION_AND_ENDINGS.md) 6.4. 마지막 장면과 마지막 폰 화면은 8.11의 표를 그대로 쓴다. 엔딩 뒤 크레딧 후일담은 조건에 따라 문장이 갈린다(8.11).
- 엔딩 재생 중에는 일시정지 메뉴를 열 수 있다. 엔딩을 건너뛰고 "다시 보기"로 갈 수 없다. 엔딩 후 "다시 보기"는 찾지 못한 앱 기능 수와 남긴 흔적 목록만 보여 주고 정답은 공개하지 않는다.
- `prefers-reduced-motion`이면 컷 전환을 페이드로만 한다.

### 8.6 전역 검색

- 홈에서 위로 끌기, 또는 상태바 두 번 탭.
- 입력한 낱말로 **현재 접근 가능한 모든 데이터**를 검색: 연락처·메시지·톡·메일·메모·미리 알림·캘린더·파일 이름·사진 위치명·지도 저장/최근·웨이브 기록·설정 항목·은행 거래 메모(G-03 이후)·루프(캐시/온라인).
- 결과는 앱별 그룹. 0건이면 "결과 없음" — 힌트 없음.
- 포함 검색 + 표기 변형(띄어쓰기·대소문자·하이픈 무시). 예: "7731", "리버뷰", "민석", "해담".
- 맨 위 **LUMA 제안** 줄: 최근 동기화로 새 데이터가 들어온 앱 3개.

## 10. 확인 사항

- **Q-OPEN-101:** 잠금화면에서 메시지·톡·메일·은행은 첫 줄 미리보기, 블링크·루프 DM은 "새 메시지"를 보여 준다. 설정의 "잠금 해제 시"는 해제 후 알림 센터 표시 규칙이다. (해결 — Q-OPEN-016 결정)
- **Q-OPEN-102:** 일시정지 열기는 세 손가락 500ms + 상태바 시각 1.5초 + Esc로 확정한다. (해결 — Q-OPEN-019 결정)
- **Q-OPEN-103:** 3페이지가 비어 있는 상태를 그대로 보여 줄지, 페이지 인디케이터에서 숨길지 확인이 필요하다. 이 문서는 "3페이지, 비어 있음"을 그대로 둔다.
- **Q-OPEN-104:** 원본 OS/UX 자료의 카메라 설명이 은행 절(20절)을 가리키지만, 카메라는 [MEDIA_SPECIFICATION.md](MEDIA_SPECIFICATION.md) 8절이다. 참조 번호만의 오류로 보고 카메라 8절로 해석했다.
- **Q-OPEN-105:** 다크 모드가 시작 기본값이며, 플레이어의 라이트/다크/자동 전환을 허용한다(스토리 영향 없음). (해결 — Q-OPEN-017 결정)
- **Q-OPEN-106:** 알림 더미 23개의 앱별 배분·문구 목록은 캐논에 없다. [BUSINESS_RULES.md](../01-product/BUSINESS_RULES.md) 9절의 예시 3건 외의 알림 내용은 콘텐츠 작성 시 확정해야 한다.
- **Q-OPEN-107:** 일시정지 메뉴의 "설정"과 LUMA 설정 앱의 "디스플레이"가 같은 글자 크기 값을 쓴다는 것 외에, 두 설정 화면의 항목을 어디까지 공유할지 확정이 필요하다. 이 문서는 게임 설정(글자·시간·소리·동작)과 LUMA 설정(디스플레이)만 값을 공유한다.
- **Q-OPEN-108:** 첫 재생 시네마틱의 건너뛰기 금지가 재도전 플레이어에게도 적용되는지 확인이 필요하다. 이 문서는 "첫 재생만 금지, 이후 재생은 허용"으로 정했다.
