# SETTINGS_SPECIFICATION — 설정 앱

> **역할:** 설정 앱의 메뉴 구조·기능·데이터·상태·상호작용을 구현 가능한 수준으로 정의한다. 설정 앱은 폰 주인의 생활이 가장 정직하게 남는 곳이다. 사람은 메시지는 지워도 Wi-Fi 기록·스크린 타임·근처 공유 기록·텍스트 대치까지 지우지는 않는다.
> **단일 출처:** 이 문서 = 설정 앱의 메뉴 구조·화면 데이터·상태. 시러스 ID 동기화의 **효과**는 [MAIL_AND_CLOUD_SPECIFICATION.md](MAIL_AND_CLOUD_SPECIFICATION.md) 4절과 이 문서가 함께 정의하며, 충돌 시 이 문서를 따른다. 단서는 [EVIDENCE_LEDGER.md](../01-product/EVIDENCE_LEDGER.md), 행동 증명은 [ACTION_PROOF.md](../01-product/ACTION_PROOF.md), 흔적은 [TRACES_AND_REACTIONS.md](../01-product/TRACES_AND_REACTIONS.md), 사건·게이트·플래그는 [PROGRESSION_AND_ENDINGS.md](../01-product/PROGRESSION_AND_ENDINGS.md).
> **참조:** [SETTINGS_SPECIFICATION](SETTINGS_SPECIFICATION.md) 0~18절 · [MAIL_AND_CLOUD_SPECIFICATION](MAIL_AND_CLOUD_SPECIFICATION.md) 1~5절 · [SYSTEM_SHELL_SPECIFICATION](SYSTEM_SHELL_SPECIFICATION.md) 5절·7절·10절 · [TRACES_AND_REACTIONS](../01-product/TRACES_AND_REACTIONS.md) · [PROGRESSION_AND_ENDINGS](../01-product/PROGRESSION_AND_ENDINGS.md) 2절·4.1 · [BUSINESS_RULES](../01-product/BUSINESS_RULES.md) 4절.
> **화면:** 화면 ID 목록의 단일 출처는 [NAVIGATION_ARCHITECTURE.md](../02-design/NAVIGATION_ARCHITECTURE.md), 레이아웃 수치는 [SCREEN_SPECIFICATIONS.md](../02-design/SCREEN_SPECIFICATIONS.md), 토큰 값은 [DESIGN_TOKENS.md](../02-design/DESIGN_TOKENS.md)다. 이 문서의 `SCR-`는 제안이다.

## 0. 범위와 원칙

- 메뉴 19개(이 문서). 보수 경로 필수 메뉴 9개.
- 원칙: **실제 스마트폰 설정에 있는 기능만 쓴다.** 이름과 화면은 LUMA식으로 바꾸되, 기능의 범위는 현실을 넘지 않는다.
- 설정 앱 상단에 **설정 검색**이 있다(예: "Wi-Fi", "공유", "전사", "차단").
- 깊이 제한: 루트에서 전체 화면 push 기준 **3단계 이하**. 4단계가 필요한 항목은 시트(sheet)로 처리한다.
- 게임 옵션(글자 크기·시간 흐름·소리)과 설정 앱의 값은 같은 값을 공유한다.

## 1. ① 레퍼런스 분석 — iOS/Android 설정

> 이 절에서만 실제 서비스명을 쓴다. 앱 화면 문구·메뉴 이름에는 쓰지 않는다.

### 1.1 iOS 설정의 핵심 UX

- 최상단 계정 배너(Apple ID) → 계정·기기·클라우드.
- 그 아래 **그룹 목록**(무선·알림·일반·접근성 등). 행을 누르면 상세로 들어가는 계층 구조.
- **검색**이 목록 최상단에 있고, 메뉴 이름과 하위 항목까지 찾는다.
- 토글은 행 오른쪽, 선택형은 상세 화면, 파괴적 동작(지우기·로그아웃)은 빨간 글자와 확인 대화상자.
- 앱별 설정이 별도 목록으로 모여 있고, 알림·개인정보·백그라운드 새로고침이 앱 단위로 흩어져 있다.
- 기기 간 공유 항목(예: 스크린 타임)은 "기기 간 공유" 토글과 함께 표시된다.

### 1.2 Android 설정의 핵심 UX

- 최상단 **검색**과 계정.
- 네트워크·연결 기기·앱·알림·배터리·저장공간·개인정보·보안·접근성 등 기능 중심 그룹.
- 항목을 누르면 상세, 상세 안에 다시 하위 항목이 이어지는 깊은 계층이 생기기 쉽다.
- "앱" 목록에서 앱별 권한·알림·저장공간을 한곳에서 본다.
- 디지털 웰빙(사용 시간), 개인정보 대시보드(권한 사용 기록)처럼 **기록을 모아 보는 화면**이 있다.

### 1.3 두 레퍼런스의 공통 핵심 UX

- 검색 → 그룹 목록 → 상세 → 토글/선택.
- 앱별 설정과 시스템 설정이 분리되어 있다.
- "이 기기"와 "다른 기기/계정"의 구분이 배지·하위 화면으로 표현된다.
- 파괴적 동작은 확인을 받는다.

## 2. ② 참고할 기능과 사용자 행동

- 설정 검색으로 원하는 항목을 바로 연다.
- 계정 → 기기 목록에서 다른 기기를 확인하고 제거한다.
- 계정 → 동기화에서 앱별 스위치를 끄고 사본 유지/삭제를 고른다.
- 네트워크(Wi-Fi·핫스팟)를 켜고 알려진 네트워크를 본다.
- 알림에서 앱별 미리보기·배너를 바꾼다.
- 집중 모드의 기기 간 공유를 끄고 방해 금지를 끈다.
- 키보드의 클립보드 기록·텍스트 대치를 본다.
- 스크린 타임에서 이 폰과 다른 기기의 사용 시간을 본다.
- 개인정보에서 중요 위치·앱 개인정보 보고서를 본다.
- 손쉬운 사용에서 음성 메모 전사를 켠다.
- 일반에서 근처 공유 기록·저장 공간·기기 정보를 본다.
- 배터리·셀룰러·암호를 확인한다.
- 디스플레이에서 라이트/다크/자동과 글자 크기를 바꾼다.

## 3. ③ 레퍼런스의 불편한 점과 개선

| 레퍼런스의 불편 | LUMA의 개선 |
|---|---|
| 하위 메뉴가 4~5단계까지 깊어져 원하는 항목을 찾기 어렵다 | 전체 화면 push **3단계 이하**. 더 필요한 정보는 시트로. |
| 검색이 메뉴 이름만 찾고 하위 항목·값을 놓친다 | 메뉴 이름·하위 행·값·동의어를 모두 인덱싱한다(예: "공유" → 근처 공유, "전사" → 손쉬운 사용, "차단" → 알림·집중 모드). |
| "다른 기기에서 바뀐 값"의 출처가 표시되지 않는다 | 값 옆에 **"다른 기기에서"** 배지와 시각을 표시한다(예: "3/15 00:21 · 도현의 슬레이트"). |
| 오프라인에서 바꾼 설정이 언제 적용되는지 모호하다 | 행에 **"온라인 연결 시 적용"** 배지를 표시한다. |
| 파괴적 동작의 결과가 불명확하다 | 암호 변경·기기 제거·기기 지우기는 확인 시트에 결과를 한 줄로 명시한다. |
| 앱별 알림·권한·저장공간이 여러 화면에 흩어져 있다 | 앱 이름으로 검색하면 알림·개인정보·저장공간 행이 한 결과 그룹에 모인다. |
| 토글의 현재 상태가 색에만 의존한다 | 스위치 + "켜짐/꺼짐" 텍스트를 함께 표시한다(색 의존 금지). |
| 설정을 바꿨을 때 상대에게 알림이 가는지 알 수 없다 | 동기화·집중 모드 변경은 화면에 "상대에게 알림이 가지 않습니다"를 명시한다(예외: 집중 모드 끄기는 TR-12). |

## 4. ④ 이 게임에 적용하는 방식

### 4.1 구조

```
설정 (루트)
├─ [검색]
├─ 시러스 ID
│   ├─ 기기
│   ├─ 동기화
│   ├─ 암호 및 보안
│   └─ 가족
├─ Wi-Fi
├─ 개인용 핫스팟
├─ 알림
├─ 집중 모드
├─ 키보드
│   ├─ 클립보드 기록
│   └─ 텍스트 대치
├─ 스크린 타임
├─ 개인정보 보호
│   ├─ 위치 서비스 → 중요 위치
│   └─ 앱 개인정보 보고서
├─ 손쉬운 사용
├─ 일반
│   ├─ 근처 공유
│   ├─ 저장 공간
│   └─ 정보
├─ 암호
├─ 셀룰러
└─ 디스플레이·배경화면·소리
```

- 이 문서의 19개 메뉴를 빠짐없이 둔다. 전체 표는 ⑧에 원본 그대로 있다.
- 깊이: 루트(1) → 그룹/상세(2) → 세부(3). 예: 루트 → 시러스 ID → 기기(3). 기기 상세는 시트. 루트 → 일반 → 근처 공유(3). 최근 기록은 같은 화면 안. 루트 → 개인정보 보호 → 위치 서비스(3) 안에 중요 위치를 둔다.
- **설정 검색**: 루트 상단 고정. 입력하면 메뉴·하위 행·값을 검색하고, 결과를 누르면 해당 화면으로 바로 이동한다. 결과에 경로를 함께 표시한다(예: "일반 › 근처 공유").
- **값의 출처**: 이 기기에서 바꾼 값 / 다른 기기에서 동기화된 값 / 오프라인 대기 값을 구분한다. 다른 기기 값에는 기기 이름과 시각을 붙인다.
- **게임 옵션 겸용**: 글자 크기·시간 흐름·소리는 일시정지 메뉴와 같은 값이다. 어느 쪽에서 바꿔도 즉시 반영된다.
- **설정 변경의 흔적**: 동기화·집중 모드·암호·가족 요청은 흔적과 결과가 있다([TRACES_AND_REACTIONS](../01-product/TRACES_AND_REACTIONS.md)). 나머지 열람은 흔적을 만들지 않는다.
- Wi-Fi 스위치는 꺼진 상태로 시작한다. 켜면 "seongwon_home" 자동 연결 = G-02(온라인).

## 5. ⑤ 다른 앱·게임 시스템과의 연결

| 설정 항목 | 연결 | 근거 ID |
|---|---|---|
| 시러스 ID → 기기 | 슬레이트의 존재·마지막 활동·제거 | E-76, DH-X |
| 시러스 ID → 동기화 | 원격 삭제 방어·녹음 업로드·실시간 데이터 | E-204, EV-04/05/07, V-14, TR-13 |

- 인터랙션:

## 9. 디스플레이·배경화면·소리 메뉴 (신규 결정)

### 9.1 화면 모드

- 기본은 **다크**다(캐논: 도현의 설정).
- 자동 전환: **게임 시계 07:00~18:59 라이트, 19:00~06:59 다크.** 전환은 `dur-base` 크로스페이드. `prefers-reduced-motion` 또는 게임 설정 "동작 줄이기"가 켜져 있으면 즉시 전환한다.

## 11. 확인 사항

- **Q-OPEN (3.4 결정):** 다크 모드의 **플레이어 전환 허용 여부**. 이 문서는 허용·스토리 영향 없음으로 설계했다. 추천: 허용. 총괄 확인 필요.
- **Q-OPEN:** 자동 모드의 판정 기준을 **게임 시계**로 명세했다. 실제 기기 시계와 게임 시계가 다를 때(예: 낮에 플레이) 어느 쪽을 따를지 확정해야 한다. 추천: 게임 시계.
- **Q-OPEN:** 글자 크기 4단계 값(0.85/1.0/1.15/1.3)은 3.2 공통 결정을 그대로 썼다. 설정 앱의 "글자 크기"와 일시정지 메뉴의 접근성 옵션이 이미 같은 값이라는 [SYSTEM_SHELL_SPECIFICATION](SYSTEM_SHELL_SPECIFICATION.md) 서술과 일치한다. 별도 이견 없음.
- **Q-OPEN:** 이 문서 메뉴 19번 "디스플레이·배경화면·소리"의 필수 열은 "—"다. 디스플레이 메뉴가 보수 97분 계산에 들어가지 않는다. 새 결정(라이트/다크/자동·글자 크기)을 넣어도 플레이타임 계산은 바뀌지 않는 것으로 확정할지 확인이 필요하다(추천: 계산 불변, 접근성 옵션은 어디서든 접근 가능).
- **Q-OPEN:** 이 문서은 "시러스 ID → 동기화"를 필수 ○로 두지만, 실제 원격 삭제 방어는 플레이어가 스위치를 끄지 않아도 다른 해법(V-04)이 있다. 필수 표기는 "보수 경로에서 반드시 들어가는 메뉴"의 뜻으로 유지한다. 별도 수정 없음.
