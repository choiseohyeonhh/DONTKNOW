# DONTKNOW v6 설계 문서

> **v6 캐논은 이 폴더다.** `docs/`(v5.4)는 폐기된 설계로 보관만 한다. 충돌하면 이 폴더가 이긴다.
> 이번 버전은 전면 재설계다: 아버지 폰의 선형 스토리 게임 → **아들 폰을 무대로 한 스마트폰 수사 어드벤처.**
> **v6.1(2026-11):** 플레이타임 보강, 앱 25종, SNS 추적 확장.
> **v6.2(2026-11):** **아빠 수첩 폐기.** 판정 UI 없이 폰에서 하는 행동이 곧 증명(11). 내가 본 것이 상대에게 보이는 흔적·반응(19), 설정 앱 수사(18), 앱 30종, 오프라인 은신처(청운)는 미끼·진짜(해담)는 온라인 단서만. 잠금은 응급정보 생일 070921, 아빠 생일 680403은 잠긴 메모 암호. 보수 97 / 일반 165분, 시계 ×4.

## 한 줄

실종된 아들의 폰을 돌려받은 아버지가, 아들이 지금도 다른 기기로 지우고 있는 흔적을 붙잡아 진실과 아들의 위치를 밝혀낸다.
