# 13. 아트 디렉션과 디자인 시스템

> 이번 문서는 **방향과 규격**이다. 아이콘·이미지를 실제로 만들거나 교체하지 않는다(작업 지시상 금지). 제작은 15 문서 로드맵 P5.

## 1. 기존 아트의 문제

| 문제 | 원인 | v6 원칙 |
|---|---|---|
| 앱 아이콘이 AI 생성처럼 보임 | 래스터 생성 이미지, 제각각의 광택·그라데이션·원근 | **벡터 손작업. 생성 이미지 금지** |
| 장소 일러스트 의존 | 대면 장면 40여 장 | 장소 일러스트 폐기. 그림은 **폰 속 사진**으로만 존재 |
| 사진과 UI의 질감 불일치 | 만화풍 그림이 사진 앱에 들어감 | 사진은 "폰으로 찍은 사진처럼 보이는 일러스트" 단일 스타일 |
| iOS 복제 | 프로토타입이 iOS 외형을 그대로 따름 | 익숙하되 고유한 LUMA OS |

## 2. 시각 정체성: 유리와 종이

| | LUMA OS (아들의 폰) | 아빠의 수첩 |
|---|---|---|
| 질감 | 평평한 면, 정확한 선, 미세한 반투명 | 크라프트지, 볼펜 자국, 테이프, 접힌 모서리 |
| 색 | 차가운 중성 + 앱별 단색 | 누런 종이 + 검정·파랑 볼펜 + 빨강 한 가지(밑줄) |
| 글꼴 | Pretendard(본문), Pretendard Mono 없음 — 숫자는 Pretendard 고정폭 숫자(tnum) | 나눔손글씨 펜(OFL) |
| 움직임 | 짧고 정확(160~240ms, ease-out) | 느리고 물리적(종이 넘김 320ms, 손글씨 써지는 연출) |
| 감정 | 무표정. 데이터는 감정이 없다 | 사람의 흔적. 지운 자국, 비뚤어진 줄 |

> 한 화면에 두 질감이 동시에 보이는 순간(수첩이 폰 위로 반쯤 올라온 상태)이 게임의 대표 이미지다. 키 비주얼·스토어 스크린샷의 기준 구도.

## 4. 아이콘 시스템 (전면 재설계 규격)

### 4.1 공통 규격
| 항목 | 규칙 |
|---|---|
| 타일 | 슈퍼타원(n=4.6) 60×60pt, 단색 채움. **그라데이션·광택·그림자·3D 금지** |
| 글리프 | 24단위 격자 위 **모노라인 2px**(60pt 타일 기준 2.5pt), 둥근 끝·둥근 모서리, 흰색(#FFFFFF) 단색 |
| 글리프 영역 | 타일 중앙 32×32pt 안 |
| 강조 | 아이콘당 최대 1개의 **채움 점 또는 면**(글리프 색과 동일) — 정체성 포인트 |
| 텍스트 | 아이콘 안에 글자 금지(캘린더 날짜 숫자만 예외) |
| 실루엣 테스트 | 16px 흑백으로 줄였을 때 25개 아이콘(v6.1)이 전부 구분되어야 함 |

## 5. 폰 속 사진 (게임의 유일한 일러스트)

- **스타일:** "폰 카메라로 찍은 장면"을 단순화한 회화형 일러스트. 실제 사진 질감(노이즈, 약한 렌즈 왜곡, 자동 HDR 느낌의 평평한 명암)을 흉내 낸 평면 채색. 만화 선 금지.
- **얼굴 원칙:** 사람의 얼굴은 작거나, 뒷모습이거나, 프레임 밖이다. **인물 식별은 물건으로**(녹색 시계, 검은 SUV, 서아의 노란 필름카메라 끈, 지훈의 빨간 모자). 공정한 추리(얼굴 판독 능력에 의존하지 않음)와 제작 비용을 동시에 해결.
- **레이어 제작:** 같은 장면의 변형(편집본/원본, 버스트 18프레임, 스크린샷)은 한 장면 파일의 레이어로 만든다. 예: 1/20 단체사진 = 전체 원본 1장 → 크롭은 코드로. 버스트 = 배경 1장 + 차 레이어 위치·흔들림 18단계 + 11번만 선명.
- **판독 요소 규칙:** 번호판·간판·문 번호처럼 플레이어가 읽어야 하는 글자는 **확대 시 2배 이상 해상도**로 별도 제작. 확대 전엔 읽히지 않아야 한다.
- 필요 수량(본편): 사진 약 60장(노이즈 포함), 그중 핵심 12장. MVP: 30장.

## 6. 수첩 디자인

- 화면 아래에서 올라오는 종이 한 장(전체 높이의 92%). 위쪽에 스프링 구멍.
- 탭은 종이 오른쪽 가장자리의 **색 인덱스 스티커** 5개(질문·단서·사람·시간표·내 폰).
- 카드: 폴라로이드 비율 축소 인쇄 + 손글씨 메모 + 테이프. 끌 때 살짝 기울어짐(±3°).
- 연결선: 빨간 볼펜으로 그어지는 애니메이션(성공 시에만 선이 남음. 실패 시 그었다 지우는 연출).
- 판정 결과 문장: 손글씨로 한 글자씩 써짐(초당 18자), 탭하면 즉시 완성.

## 7. 시네마틱

- 프롤로그 1편(폰을 돌려받는 밤: 경찰서 봉투, 식탁, 충전기) + 엔딩 5편. 스틸 3~5컷 + 하단 자막. v5.4의 자막 규칙(상황만, 감정 설명 금지) 계승.
- 스틸도 5절 "폰 사진" 스타일과 같은 화풍(따로 놀지 않게). 얼굴 원칙 동일.

## 8. 소리 (선택)

- 소리 없이 완결되게 설계한다. 소리 켬: LUMA 알림음 3종(일반·보안·블링크), 수첩 종이·볼펜 소리, 녹음 재생 음성(대사 4구간은 성우 녹음 권장, 그 외 웅성거림).
- 원격 삭제·지우기에 효과음 없음(무음이 더 무섭다).
