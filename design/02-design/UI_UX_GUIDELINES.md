## 1. 내비게이션 패턴

### 1.1 선택 기준

| 패턴 | 쓰는 경우 | 쓰지 않는 경우 | 등장 |
|---|---|---|---|
| **푸시(push)** | 목록 → 항목 상세, 설정 → 하위 설정, 프로필 → 게시물. 현재 맥락을 유지한 채 한 단계 들어간다 | 독립 작업을 시작할 때 | 오른쪽에서 밀려 들어옴, 350ms `ease-sheet` |
| **모달(modal)** | 작성·촬영·확대처럼 **끝내야 하는 작업**이 현재 화면을 덮는다. 취소/완료가 명확하다 | 단순 정보 확인 | 아래에서 전체 화면, 350ms `ease-sheet` |
| **시트(sheet)** | 맥락 메뉴, 공유, 정보(i), 필터, 짧은 선택. 현재 화면을 유지한다 | 여러 단계 입력, 긴 목록 탐색 | 아래에서 올라옴, z=70, 배경 scrim 0.48 |
| **오버레이(overlay)** | 제어 센터, 알림 센터, 일시정지 메뉴. 시스템 층이 앱을 덮는다 | 콘텐츠 탐색 | z=80/100, 화면 전체 |
| **탭(tab)** | 앱의 최상위 영역 3~5개. 각 탭의 스크롤·상태를 기억한다 | 하위 상세 | 하단 고정, z=20 |

### 1.2 규칙

1. **깊이 3단계 이하.** 앱 루트 → 중간 목록 → 상세. 4단계가 필요하면 화면 구조를 다시 짠다. 예: 설정 > 시러스 ID > 기기(3단계)까지. 그 아래는 시트나 섹션으로 푼다.
2. **뒤로 버튼을 항상 둔다.** 왼쪽 가장자리 밀기와 함께, 내비 바 왼쪽에 뒤로 버튼을 둔다. iOS Safari의 가장자리 제스처와 충돌해도 게임 안에서 돌아올 수 있어야 한다([RESPONSIVE_DESIGN.md](./RESPONSIVE_DESIGN.md) 6절).
3. **뒤로는 스크롤 위치를 복원한다.** 목록으로 돌아오면 이전 위치·선택·필터를 유지한다.
4. **탭 재탭은 맨 위로.** 같은 탭을 다시 누르면 그 탭의 스크롤을 맨 위로 올린다. 두 번째 재탭은 아무 일도 하지 않는다.
5. **모달은 한 번에 하나.** 모달 위에 모달을 쌓지 않는다. 시트 위에 시트를 쌓지 않는다. 필요하면 기존 것을 닫고 연다.
6. **시트는 드래그 다운으로 닫는다.** 위쪽 그랩 영역(24×5)과 바깥 scrim 탭 모두 닫기다. 파괴적 동작은 시트가 아니라 경고창에서 확인한다.
7. **햄버거 메뉴를 쓰지 않는다.** 최상위 탐색은 탭, 하위 탐색은 목록, 맥락 동작은 시트다.
8. **드롭다운을 쓰지 않는다.** 선택지는 시트 또는 전체 화면 목록이다.
9. **모달 취소는 왼쪽, 완료는 오른쪽.** 작성 중 뒤로 가면 "작성 중인 내용이 있습니다" 확인은 **내용이 있을 때만** 띄운다. 빈 작성창은 확인 없이 닫는다.
10. **탭 바는 5개 이하.** 3개 미만이면 탭 대신 세그먼트를 쓴다. 탭 라벨은 `caption-1` 12pt, 아이콘 아래 2.

## 2. 문구 규칙

### 2.1 시스템 문구 톤

| 규칙 | 내용 | 좋은 예 | 나쁜 예 |
|---|---|---|---|
| 말투 | 시스템은 **합쇼체**(`-습니다/‑ㅂ니다`)로 짧게. 감정·농담·이모지 없음 | "연결할 수 없습니다." | "앗! 연결이 안 됐어요 😢" |
| 길이 | 제목 1줄 20자 이내, 본문 2줄 40자 이내 | "Wi-Fi가 꺼져 있습니다." | "현재 기기의 네트워크 상태를 확인해 주시기 바랍니다." |
| 주체 | 시스템은 자기 행동을 말한다. 플레이어를 평가하지 않는다 | "저장했습니다." | "잘하셨어요!" |
| 금지어 | 단서, 수사, 정답, 오답, 힌트, 목표, 미션, 레벨, 클리어, 게임, 플레이어 | — | "새 단서를 찾았습니다" |
| 금지 부호 | `!` 연속, 말줄임표 남용, 이모지, `ㅋㅋ`, `~` | — | "삭제됐어요~" |
| 실제 서비스명 | 쓰지 않는다. 앱 이름은 캐논 이름만 | "톡", "블링크", "루프" | 실제 메신저·SNS 이름 |
| OS 이름 | "LUMA"만. 다른 OS 이름을 화면에 쓰지 않는다 | "LUMA 저장 공간" | 다른 OS 이름 + 저장 공간 |

### 2.2 버튼

- 버튼은 **동사형**이다. `확인`·`예`·`아니오`를 기본으로 쓰지 않는다.
- 파괴적 버튼은 동작을 그대로 쓴다: `삭제`, `차단`, `원격 지우기`, `기기 제거`, `암호 변경`.
- 취소는 `취소` 하나로 통일한다.
- 주요 버튼은 화면당 하나. 나머지는 텍스트 버튼 또는 시트 항목이다.
- 비활성 버튼은 왜 비활성인지 바로 위 또는 아래에 `footnote`로 쓴다. 툴팁을 쓰지 않는다.

| 동작 | 라벨 | 금지 |
|---|---|---|
| 메시지 전송 | `보내기` | `전송`, `확인` |
| 메일 발송 | `보내기` | `발송하기` |
| 저장 | `저장` | `완료` |
| 삭제 | `삭제` | `지우기`(원격 지우기 제외) |
| 차단 | `차단` | `차단하기` |
| 차단 해제 | `차단 해제` | `해제` |
| 원격 초기화 | `원격 지우기` | `초기화`, `삭제` |
| 비행기 모드 | `비행기 모드` | `비행기` |
| 시간 흐름 | `시간 흐름` | `타이머` |
| 글자 크기 | `글자 크기` | `폰트` |

### 2.3 오류 문구

오류는 **무엇이 일어났는지 + 왜 + 다음 행동** 순서로 쓴다. 최대 3문장, 40자 내외.

| 상황 | 문구 | 행동 |
|---|---|---|
| 네트워크 없음 | "연결할 수 없습니다. Wi-Fi가 꺼져 있습니다." | `Wi-Fi 열기` |
| 서버 없음(회선) | "서비스 없음. 이 기기에서는 전화와 문자를 쓸 수 없습니다." | 없음 |
| 암호 오류 | "암호가 맞지 않습니다. 다시 입력하세요." | 재입력 |
| 6회 오류 대기 | "30초 후 다시 시도할 수 있습니다." | 카운트다운 |
| 파일 없음 | "파일을 열 수 없습니다. 이 기기에 없습니다." | `닫기` |
| 저장 실패 | "저장하지 못했습니다. 저장 공간이 부족합니다." | `저장 공간 열기` |
| 권한 없음 | "이 항목을 볼 수 없습니다." | 없음 |
| 예약 메일 실패 | "예약 메일을 보내지 못했습니다. 연결을 확인하세요." | `다시 시도` |

- 오류 코드·스택·기술 용어를 노출하지 않는다.
- 오류를 축하하거나 농담하지 않는다.
- 같은 오류를 반복해서 토스트로 띄우지 않는다. 화면 안 인라인으로 한 번만.

### 2.4 빈 화면 문구

- 없는 것을 있는 것처럼 말하지 않는다. **없음 + 이유(아는 경우) + 다음 행동(사용자가 만들 수 있는 경우만)**.
- 수사 화면에서는 다음 행동을 권하지 않는다. "단서를 찾아보세요" 금지.

| 화면 | 제목 | 본문 | 행동 |
|---|---|---|---|
| 검색 결과 0 | `결과 없음` | 없음 | 없음 |
| 메시지 없음 | `메시지가 없습니다` | 없음 | 없음 |
| 사진 없음 | `사진이 없습니다` | 없음 | 없음 |
| 알림 없음 | `알림이 없습니다` | 없음 | 없음 |
| 메모 없음 | `메모가 없습니다` | 없음 | `새 메모` |
| 즐겨찾기 없음 | `즐겨찾기가 없습니다` | "사진에서 즐겨찾기를 추가할 수 있습니다." | 없음 |
| 오프라인 캐시 없음 | `저장된 항목이 없습니다` | "연결되면 표시됩니다." | `Wi-Fi 열기` |
| 블링크 그룹 필터 | `대화가 없습니다` | 없음 | 없음 |
| 삭제된 댓글 자리 | `삭제된 댓글입니다 · 3/13` | 없음 | 없음 |

### 2.5 숫자·날짜·시각 형식

캐논 표기와 일치한다. 임의로 바꾸지 않는다.

| 항목 | 형식 | 예 | 쓰는 곳 |
|---|---|---|---|
| 잠금화면 날짜 | `M월 D일 요일` | `3월 17일 화요일` | 잠금화면 |
| 잠금화면 시각 | `HH:MM` 24시간 | `21:10` | 잠금화면 |
| 메시지·목록 시각 | `M/D HH:MM` | `3/17 21:10` | 톡·메시지·알림·거래 |
| 같은 날 시각 | `HH:MM` | `03:58` | 대화방 안 날짜 구분선 아래 |
| 절대 날짜 | `YYYY.MM.DD` | `2026.03.05`, `2023.11.20` | 게시물·가입일·서류 |
| 생년월일 | `YYYY.MM.DD` | `2007.09.21`, `1968.04.03` | 응급정보·연락처 |
| 기간 | `N일`, `N개월` | `15일`, `19개월` | 계약·예약 |
| 지속 시간 | `N분`, `N분 N초` | `42분`, `14분 12초` | 통화·녹음·사용 시간 |
| 금액 | 천 단위 쉼표 + `원` | `113,000,000원`, `6,400,000원` | 은행·영수증 |
| 수수료·작은 금액 | 천 단위 쉼표 + `원` | `300,000원` | UI. 대사에서 "30만 원"은 대사 원문 |
| 퍼센트 | `N%` | `31%` | 배터리·진행 |
| 파일 크기 | `NMB`, `NGB` | `41MB`, `1.2GB` | 저장 공간·파일 |
| 전화번호 | 캐논 그대로 | `010-XXXX-2290`, `1600-XXXX` | 연락처·문자 |
| 개수 | 숫자만 또는 `N개` | 배지 `1`, 목록 "23개" | 배지·요약 |
| 상대 시각 | `방금 전`, `어제`, `M월 D일` | `방금 전`, `3월 15일` | 기기 마지막 활동(캐논) |

- **증거가 되는 시각은 상대 표현을 쓰지 않는다.** `방금 전`은 살아 있는 상태(기기 마지막 활동)에만. 메시지·거래·사진·게시물은 전부 절대 시각이다.
- 24시간제. `오후 9:10`을 쓰지 않는다.
- 연도가 현재와 같아도 생년월일·서류·게시물은 연도를 생략하지 않는다.
- 숫자는 `tabular-nums`. 시각·금액·개수를 오른쪽 정렬한다.
- 단위와 숫자 사이에 공간을 넣지 않는다(`42분`, `41MB`, `31%`). 금액도 `113,000,000원`처럼 붙인다.

### 2.6 알림 문구

- 알림은 앱이 실제로 보내는 것처럼 쓴다. 게임이 플레이어에게 말을 걸지 않는다.
- 미리보기 설정을 따른다. 블링크·루프 DM은 설정이 "새 메시지"면 본문을 숨긴다([SETTINGS_SPECIFICATION](../03-features/SETTINGS_SPECIFICATION.md) 7절).
- 보안 알림은 시러스 ID 발신, 회색 자물쇠. 문구 예: "도현의 폰이 잠금 해제되었습니다", "새 로그인".
- 알림을 탭하면 해당 항목으로 간다. 알림 자체에 정답·힌트를 쓰지 않는다.

### 3.1 로딩

- 스피너는 20pt, `label-2`. 300ms 이전에 띄우지 않는다. 깜빡임 방지.
- 목록은 스켈레톤 3~5행. 스켈레톤은 `fill-2`, 불투명도 `op-skeleton`. 실제 행 높이와 같게 만든다.
- 3초를 넘기면 스켈레톤 아래 `footnote`로 "불러오는 중…"을 쓴다.
- 로딩 중에도 이미 캐시된 항목은 먼저 보여 준다. 전체 화면 스피너로 덮지 않는다.

### 3.2 오프라인

- "서비스 없음"은 회선 상태다(전화·문자 불가). "오프라인"은 데이터 연결 상태다. 두 가지를 같은 문구로 합치지 않는다.
- 연결이 필요 없는 앱(사진·메모·설정 일부)은 오프라인 배너를 띄우지 않는다. 캐시 데이터를 그대로 보여 준다.
- 캐시임을 밝혀야 하는 곳은 목록 하단에 `footnote` "오프라인 저장본 · 3/15 03:58 기준" 한 줄. 반복 배너 금지.
- 오프라인에서 한 행동은 대기 상태로 남고, 다음 온라인에 전송된다는 사실만 문구로 알린다. 누가 보는지는 설명하지 않는다.

### 3.3 삭제됨

- 다른 기기에서 삭제된 항목은 **행이 0.4초 페이드 후 사라지고**, "1개 항목이 다른 기기에서 삭제됨"이 3초 뜬다(캐논). 그 앱을 보고 있을 때만 목격한다.
- 댓글·게시물 자리는 남는다: "삭제된 댓글입니다 · 3/13". 자리와 날짜를 지우지 않는다.
- `prefers-reduced-motion` 또는 동작 줄이기에서는 페이드 없이 문구만 3초 표시한다.
- 삭제된 항목을 복구하는 UI를 만들지 않는다. 휴지통·최근 삭제된 항목은 캐논에 있는 앱만.

### 3.4 잠김

- 잠금은 **입력 필드 + 숫자 키패드**다. 6자리. 오답 6회째부터 30초 대기. 잠금 초기화 버튼은 없다.
- 힌트는 캐논에 적힌 것만 표시한다. 예: 잠긴 메모의 힌트 "아빠". 힌트를 새로 만들지 않는다.
- 잠금 해제에 성공 연출을 넣지 않는다. 화면이 바로 바뀐다.

### 3.5 오류

- 오류는 **문제가 생긴 컴포넌트 아래**에 인라인으로 둔다. 전체 화면 모달을 쓰지 않는다. 단, 파괴적 동작 실패는 경고창 안에서 알린다.
- 재시도 버튼은 같은 동작을 다시 실행한다. 재시도로 해결되지 않는 오류에는 버튼을 두지 않는다.
- 오류 상태에서도 다른 화면으로 이동할 수 있다. 오류가 앱을 잠그지 않는다.

## 4. 확인 대화상자

### 4.1 원칙

- **파괴적이거나 되돌릴 수 없는 동작에만** 확인 대화상자를 쓴다.
- 되돌릴 수 있는 동작은 확인 없이 실행하고, 필요하면 실행 후 되돌리기를 제공한다.
- **중앙 경고창(CMP-ALERT, z=90)은 캐논대로 두 곳만:** 원격 지우기, 암호 변경 확인. 그 밖의 파괴적 동작 확인은 하단 **액션 시트(CMP-ACTION-SHEET)** 로 한다: 동작 버튼(`destructive` 글자) + 분리된 `취소` 버튼. 아래 4.2 표의 "확인 방식" 열을 따른다.
- 경고창은 scrim 0.48 + `bg-elevated` + `elev-3`(라이트) + 모서리 20. 제목 `headline`, 본문 `footnote`, 버튼 세로 배치.
- 버튼 순서: **취소가 위, 파괴 동작이 아래.** 파괴 버튼은 `destructive-fill` 채움 + `on-tint` 글자. 취소는 `bg-tertiary` + `label`.
- 바깥 탭으로 닫히지 않는다. 취소 버튼·Esc·뒤로 제스처로만 닫는다.
- 기본 포커스는 **취소**다. Enter는 취소, Esc는 취소.

### 4.2 확인을 쓰는 동작

| 동작 | 확인 방식 | 문구 예 |
|---|---|---|
| 원격 지우기 | 경고창 | 제목 "이 기기를 원격으로 지우시겠습니까?" / 본문 "사진·메시지·메모가 이 기기에서 삭제됩니다. 되돌릴 수 없습니다." / `취소` `원격 지우기` |
| 암호 변경 | 경고창 | "암호를 변경하시겠습니까?" / "이 기기 외의 기기는 로그아웃됩니다." / `취소` `암호 변경` |
| 기기 제거 | 액션 시트 | "이 기기를 계정에서 제거하시겠습니까?" / `취소` `기기 제거` |
| 예약 메일 삭제 | 액션 시트 | "예약 메일을 삭제하시겠습니까?" / `취소` `삭제` |
| 예약 메일 지금 보내기 | 액션 시트 | "지금 보내시겠습니까?" / "예약 시각보다 먼저 발송됩니다." / `취소` `지금 보내기` |
| 사진·메모 영구 삭제(휴지통 없음) | 액션 시트 | "삭제하시겠습니까?" / "되돌릴 수 없습니다." / `취소` `삭제` |
| 차단 | 액션 시트 | "이 계정을 차단하시겠습니까?" / "서로의 게시물이 보이지 않습니다." / `취소` `차단` |
| 대화방 나가기 | 액션 시트 | "대화방을 나가시겠습니까?" / `취소` `나가기` |
| 앱 데이터 삭제 | 액션 시트 | "데이터를 삭제하시겠습니까?" / `취소` `삭제` |
| 메시지 전송 | 금지 | 바로 보낸다 |
| 좋아요·팔로우·저장 | 금지 | 바로 반영 |
| 공유 | 금지 | 공유 시트에서 대상 선택 |
| 읽음 처리 | 금지 | 여는 순간 읽음 |
| 설정 변경(글자 크기·시간 흐름·테마) | 금지 | 즉시 반영 |
| 차단 해제 | 금지 | 바로 해제 |
| 휴지통으로 이동 | 금지 | 이동 후 `되돌리기` 3초 |

### 4.3 확인창을 쓰지 않는 오류

- 전송 실패, 동기화 실패, 로그인 실패는 경고창이 아니라 인라인 오류다.
- 확인창을 "알림" 용도로 쓰지 않는다. 정보 전달은 배너·인라인·알림 센터가 한다.

## 5. 게임 특수 규칙

### 5.1 정답 판정 UI 금지

- 다음을 만들지 않는다: "정답", "오답", "연결 성공", "일치", "추리 완료", "진행도 N%", "단서 3/12", 체크리스트, 카드 뒤집기, 실 연결선.
- 플레이어가 알아낸 것은 **폰에서의 행동**으로만 세계가 반응한다. 예: 경찰에 메일을 쓰고 이름을 적으면 답장이 온다. "정답입니다" 토스트는 없다.
- 검색 결과·목록·상세는 사실만 보여 준다. 게임이 "이것이 중요합니다"라고 강조하지 않는다.
- 엔딩 후 "다시 보기"는 찾지 못한 앱 기능 수와 남긴 흔적 목록만 보여 준다. 정답을 공개하지 않는다.

### 5.2 "새 단서" 알림 금지

- "새 단서", "새 정보", "확인해 보세요", "중요" 배지·점·하이라이트를 만들지 않는다.
- 알림 센터에는 **앱이 실제로 보낸 알림**만 들어간다. 게임 시스템 알림을 넣지 않는다.
- 새로 동기화된 항목은 앱 안의 실제 목록 갱신으로만 보인다.
- 단, 캐논의 `LUMA 제안`은 검색 화면 위에 "최근 동기화된 앱 3개"만 보여 준다. 단서 이름·내용은 쓰지 않는다.

### 5.3 동기화 점은 설명하지 않는다

- 상태바 Wi-Fi 아이콘 옆 4pt 점. 깜빡이면 "지금 무언가 오가는 중"이다.
- 범례·툴팁·설정 설명·온보딩 문구를 만들지 않는다. "이 점은 원격 삭제 신호입니다" 같은 설명 금지.
- 스크린리더용 레이블은 중립적으로 `동기화 표시`만 준다. 의미를 해설하지 않는다.
- 점의 깜빡임은 1.2초 주기, 불투명도 1↔0.35. 초당 3회 이상 깜빡이지 않는다.

### 5.4 정보(i)는 열어야 보인다

- 사진의 촬영 시각·위치·기기·편집 여부, 메시지의 전송·읽음 시각·보낸 기기, 메일 머리글, 파일 받은 경로, 거래 상대 계좌·메모는 **화면에 미리 표시하지 않는다.**
- 길게 누르기 → `정보` 시트에서만 보인다. 라벨-값 2열, 값은 tnum, 사진은 지도 미리보기 썸네일.
- 메타데이터를 요약한 칩·배지·서브타이틀을 목록에 붙이지 않는다.

### 5.5 흔적을 설명하지 않는다

- "상대가 볼 수 있습니다", "흔적이 남았습니다", "읽음이 전송되었습니다" 같은 시스템 안내를 띄우지 않는다.
- 읽음 표시·스토리 조회·활동 상태·동기화는 실제 폰처럼 조용히 동작한다. 결과는 상대의 반응으로만 온다.
- 흔적을 되돌리는 UI를 만들지 않는다. 읽음을 취소하는 버튼, 조회 기록 삭제, 좋아요 알림 취소는 없다. 좋아요 취소는 가능하지만 알림은 이미 간다(캐논).
- 의도치 않은 흔적(두 번 탭 좋아요, 스토리 넘김)을 막는 확인창을 넣지 않는다. 실제 SNS처럼 동작한다.

### 5.6 시간

- 화면에 카운트다운 HUD를 두지 않는다. 남은 시간은 상태바 시계와 메시지 문구로만 읽는다.
- "30분 안에 대답 없으면 지웁니다"는 **메시지 본문**이다. 타이머 위젯으로 만들지 않는다.
- 시간 흐름 끄기는 일시정지 메뉴와 설정 > 디스플레이 양쪽에서 같은 값으로 제공한다. 끄면 앱 전환 1회 = 게임 1분.
- 일시정지 메뉴는 폰 밖 게임 UI다. z=100, `material-thick`. 항목: 계속 / 막혔을 때 / 설정(글자 크기·시간 흐름·소리) / 저장·불러오기.

### 5.7 막혔을 때

- "막혔을 때"는 **일시정지 메뉴에만** 있다. 앱 안에 힌트 버튼·물음표·자동 제안을 두지 않는다.
- 3단계: ① 방향(질문) ② 앱 ③ 위치(경로). 예: "도현이가 마지막으로 연락한 사람은?" → "톡에서 3월 15일 이후를 보자" → "톡 → 지훈 → 3/15 10:40".
- 정답 문장을 주지 않는다. 플레이어가 그 화면에 도달하게만 한다.

### 5.8 화면 문구 검수 체크

- [ ] 실제 서비스명이 없다.
- [ ] "단서·수사·정답·힌트·목표"가 시스템 문구에 없다.
- [ ] 정답 판정·진행도·새 단서 배지가 없다.
- [ ] 시각·날짜·금액이 2.5 형식과 캐논 값에 맞다.
- [ ] 파괴적 동작에만 확인창이 있다.
- [ ] 정보(i) 메타데이터가 화면에 미리 노출되지 않는다.
- [ ] 오프라인·삭제·잠김·오류 상태가 정의돼 있다.
- [ ] 색만으로 상태를 표시하지 않는다.

## 확인 사항

- (해결) 홈 격자는 캐논 4×5.
- (해결) 중앙 경고창은 캐논대로 두 곳만, 나머지 확인은 액션 시트.
