## 2. 명도 대비

### 2.1 계산 방법

- sRGB 상대 휘도 `L = 0.2126R + 0.7152G + 0.0722B`(각 채널은 0~1로 정규화 후 감마 해제).
- 대비비 `(L1 + 0.05) / (L2 + 0.05)`, 밝은 쪽이 L1.
- `rgba()` 값은 배경 위에 알파 합성한 뒤 계산한다. 예: 라이트 `label-2` = `rgba(60,60,67,.62)`를 `#F2F2F5` 위에 합성한 실효색.
- 큰 글자 기준은 18pt(24px) 이상, 또는 14pt(18.66px) 이상 + 굵기 700이다.

### 2.4 비텍스트 대비

- 아이콘·입력 테두리·상태 점·차트는 인접 색과 **3:1 이상**이어야 한다.
- `warning` 2.63:1은 라이트에서 비텍스트 3:1도 통과하지 못한다. 라이트의 경고 점·아이콘은 `warning-ink`(5.30:1)를 쓴다.
- `separator`(1.36:1/1.59:1)는 장식 구분선이다. 입력 필드 경계를 구분선만으로 표시하지 않는다. `fill` 배경 또는 1px `label-2-aa` 테두리를 함께 쓴다.
- 포커스 링은 인접 배경과 3:1 이상이어야 한다. `tint`는 라이트 `bg`에서 4.03:1, 다크 `bg`에서 6.59:1이다. `tint-fill` 채움 위에서는 `on-tint` 링을 쓴다.
- 앱 tint 30종의 `on-tint` 조합은 전부 4.5:1 이상이다(최소 4.60:1). [DESIGN_TOKENS.md](./DESIGN_TOKENS.md) 8절.
- `success`·`warning` 채움 위 `on-status` #111114는 라이트 5.53:1·6.40:1, 다크 8.30:1·8.61:1이다.

### 2.5 대비 규칙

1. 라이트에서 17pt 이하의 읽어야 하는 보조 텍스트는 `label-2`가 아니라 `label-2-aa`를 쓴다.
2. 라이트에서 본문 크기 링크 텍스트는 `tint-ink`를 쓴다. `tint`는 큰 글자·아이콘·테두리에만 쓴다. 채움 버튼은 `tint-fill` + `on-tint`다.
3. 상태 텍스트는 라이트에서 `-ink` 파생 토큰을 쓴다. 상태 점도 라이트에서는 `warning-ink`·`success-ink`를 쓴다.
4. `destructive`는 채움·테두리·아이콘에만. 파괴적 텍스트는 `destructive-ink`.
5. `label-3`는 비활성·장식 전용. 플레이스홀더·읽어야 하는 메타데이터에 쓰지 않는다.
6. 회색 위 회색(예: `label-3` on `bg-tertiary`)을 만들지 않는다.

## 3. 터치

| 항목 | 값 |
|---|---|
| 최소 터치 영역 | **44×44** (WCAG 2.5.8의 24×24보다 엄격) |
| 시각 아이콘 | 17/20/24/28. 터치 영역은 보이지 않게 44까지 확장 |
| 인접 대상 간격 | 최소 8. 없으면 44 영역이 겹치지 않게 분리 |
| 하단 여백 | 홈 인디케이터 위 8px 안에 터치 대상 금지 |
| 탭 바 | 높이 49, 각 탭 44 이상 |
| 작은 칩 | 시각 높이 24라도 터치 영역 44 |
| 슬라이더 | 트랙 4, 손잡이 시각 20, 터치 44 |
| 표 형태 목록 | 행 전체가 터치 대상. 행 높이 44 이상 |

- 터치 대상이 겹치면 z-index가 아니라 여백으로 푼다.
- 길게 누르기는 **항상 단일 탭 대체 동작**이 있어야 한다(2.5.1). 예: 길게 누르기 맥락 메뉴 → 행 오른쪽 `더보기` 버튼.
- 드래그·스와이프는 버튼 대체를 제공한다(2.5.7). 예: 시트 드래그 다운 → `닫기` 버튼, 사진 스와이프 → `이전/다음` 버튼, 슬라이더 드래그 → 키보드 화살표.
- 두 손가락 핀치 확대는 `+/-` 버튼으로 대체한다(10절).
- 두 번 탭 좋아요는 좋아요 버튼으로 대체한다. 두 번 탭을 몰라도 모든 기능을 쓸 수 있다.

## 4. 포커스

### 4.1 포커스 링

| 항목 | 값 |
|---|---|
| 두께 | 2px |
| 색 | `tint`(중립 배경), `tint-fill` 채움 위에서는 `on-tint` |
| 오프셋 | 2px |
| 모서리 | 대상의 `border-radius`를 따른다 |
| 표시 | `:focus-visible`에서 항상. 마우스 클릭에도 표시(게임은 키보드 사용자를 배려) |
| 금지 | `outline: none` 단독 사용, 1px 이하, 그림자만으로 표시 |

- 포커스 링은 잘리지 않는다. `overflow: hidden` 컨테이너 안의 대상은 안쪽으로 2px 오프셋을 조정한다.
- 고대비 모드(`forced-colors: active`)에서는 `outline: 2px solid CanvasText`로 대체한다.

### 4.2 포커스 순서

- DOM 순서 = 시각 순서. CSS `order`로 순서를 바꾸지 않는다.
- 앱 진입 시 포커스는 화면 제목(`h1`)으로. 스크린리더는 앱 이름과 제목을 읽는다.
- 모달·시트가 열리면 포커스는 첫 포커스 가능 요소(제목 또는 첫 입력)로. 닫히면 연 요소로 복귀.
- 포커스 트랩은 모달·시트·경고창 안에서만. `Tab`/`Shift+Tab`이 밖으로 나가지 않는다.
- 비활성 요소는 `tabindex="-1"`이 아니라 `disabled` 또는 `aria-disabled`로. 포커스 순서에서 제외하되, 왜 비활성인지는 문구로 제공.

### 4.3 포커스 가려짐(2.4.11)

- 고정 내비·탭 바 아래로 포커스가 들어가면 `scroll-padding-top/bottom`으로 보정한다.
- 상단 `scroll-padding-top`: 상태바 + 내비(큰 제목 포함). 하단 `scroll-padding-bottom`: 탭 바 + 안전영역 + 16.
- 키보드가 열린 상태에서 포커스된 입력은 키보드 위 16에 보인다.

## 5. 키보드

### 5.1 기본

| 키 | 동작 |
|---|---|
| `Tab` / `Shift+Tab` | 다음/이전 포커스 |
| `Enter` / `Space` | 활성화. `Space`는 스크롤 대신 활성화(포커스된 버튼) |
| `Esc` | 최상위 오버레이 닫기. 오버레이가 없으면 **일시정지 메뉴** |
| `↑` / `↓` | 목록·메뉴 항목 이동. 입력 필드에서는 커서 이동 |
| `←` / `→` | 탭·세그먼트 이동. 사진 캐러셀 이전/다음. 지도 이동 |
| `Home` / `End` | 목록 처음/끝 |
| `PageUp` / `PageDown` | 목록 한 화면 |
| `Cmd/Ctrl + C/V` | 본문·메시지 복사/붙여넣기(작성창) |
| `Cmd/Ctrl + F` | 브라우저 찾기 허용(막지 않음) |

- Esc의 우선순위: 경고창 → 시트 → 모달 → 일시정지 메뉴. 한 번에 하나만 닫는다.
- 일시정지 메뉴에서 Esc는 메뉴를 닫고 게임으로 돌아간다.
- 키보드 트랩 없음. 모달 안에서도 Esc로 나간다.

### 5.2 데스크톱

- 물리 키보드 입력은 가상 키보드와 같은 입력 필드에 들어간다. 한글 조합은 OS IME를 쓴다.
- `Tab`으로 폰 프레임 안的所有 상호작용에 도달한다. 프레임 밖 배경은 포커스 대상이 아니다.
- 방향키로 목록을 이동할 때 `aria-activedescendant` 또는 실제 포커스 이동을 쓴다. 한 방식만.
- 단축키를 새로 만들지 않는다. 브라우저 단축키를 가로채지 않는다.

### 5.3 모바일 외부 키보드

- iPad/iPhone에 물리 키보드가 연결되면 같은 키 매핑을 쓴다.
- 가상 키보드와 물리 키보드가 동시에 입력되지 않게, 물리 키 입력이 있으면 가상 키보드는 숨기지 않고 하이라이트만 한다.

### 5.4 드래그 대체

| 드래그 | 대체 |
|---|---|
| 시트 아래로 닫기 | `닫기` 버튼 |
| 사진 캐러셀 스와이프 | `이전`/`다음` 버튼 |
| 슬라이더(밝기·음량) | 화살표 키, `+/-` 버튼 |
| 지도 이동 | 방향키, `+/-` 확대, 주소·핀 목록 |
| 스토리 넘기기 | `다음` 버튼, 자동 넘김 끄기 |
| 목록 행 순서 변경 | 위/아래 버튼(해당 기능이 있을 때) |

## 6. 스크린리더

### 6.1 기본 규칙

- 문서 언어 `lang="ko"`. 앱 이름·화면 제목을 앱 진입 시 읽는다.
- 아이콘만 있는 버튼은 `aria-label`을 준다. 라벨에 "버튼"을 넣지 않는다(역할이 읽힌다).
- 상태를 가진 컨트롤은 `aria-pressed`/`aria-selected`/`aria-checked`/`aria-expanded`를 쓴다.
- 목록은 실제 목록 시맨틱(`ul/li` 또는 `role=list/listitem`)을 쓴다. div 더미를 쓰지 않는다.
- 표는 실제 `table`을 쓰지 않는다. 라벨-값은 `dl` 또는 `role=group` + `aria-labelledby`.
- 숨김 정보(i)는 스크린리더에도 열기 전에는 노출하지 않는다. `aria-describedby`에 메타데이터를 미리 넣지 않는다.
- 시간은 `<time datetime="2026-03-17T21:10">3/17 21:10</time>`로 준다.
- 금액·수량은 `aria-label`로 읽기 좋게: "113,000,000원"은 그대로 읽힌다. 필요하면 "1억 1천 3백만 원"을 라벨로.
- 알림·토스트는 `role=status`(`aria-live=polite`). 파괴적 실패만 `role=alert`.
- 읽지 않은 수는 "안 읽은 메시지 1개"로 읽는다. 배지 숫자만 읽지 않는다.

### 6.2 ARIA 역할 매핑

| UI | 역할 | 필수 속성 | 비고 |
|---|---|---|---|
| 앱 셸 | `main` | `aria-labelledby`(화면 제목) | 앱당 하나 |
| 내비게이션 바 | `navigation` | `aria-label="내비게이션"` | 뒤로 버튼 포함 |
| 탭 바 | `tablist` | `aria-label="앱 탭"` | 탭 3~5 |
| 탭 | `tab` | `aria-selected`, `aria-controls` | 재탭 = 맨 위 |
| 탭 패널 | `tabpanel` | `aria-labelledby` | 숨김 시 `hidden` |
| 목록 | `list` / `listitem` | — | 실제 ul/li 우선 |
| 목록 행 | `listitem` | `aria-label`(주 정보+시각+상태) | 중복 읽기 방지 |
| 대화 로그 | `log` | `aria-live="polite"`, `aria-relevant="additions"` | 새 메시지 |
| 말풍선 | `article` | `aria-label`(보낸 사람·시각) | 본문은 텍스트 |
| 게시물 | `article` | `aria-labelledby` | 좋아요 `aria-pressed` |
| 사진 | `img` | `alt`(보이는 내용) | 장식은 `alt=""` |
| 시트 | `dialog` | `aria-modal="true"`, `aria-labelledby` | 포커스 트랩 |
| 경고창 | `alertdialog` | `aria-modal="true"`, `aria-labelledby`, `aria-describedby` | 기본 포커스 취소 |
| 배너·토스트 | `status` | `aria-live="polite"` | 4초 |
| 세그먼트 | `tablist` | `aria-label` | 보기 전환 |
| 스위치 | `switch` | `aria-checked` | 설정 |
| 슬라이더 | `slider` | `aria-valuemin/max/now`, `aria-valuetext` | 밝기·음량 |
| 검색 | `search` + `searchbox` | `aria-label="검색"` | 결과 수 안내 |
| 키패드 | `group` | `aria-label="숫자 키패드"` | 각 키는 버튼 |
| 가상 키보드 | `group` | `aria-label="키보드"` | 각 키 버튼 |
| 진행 | `progressbar` | `aria-valuemin/max/now` | 로딩 |
| 지도 | `region` | `aria-label="지도"` | 핀 목록을 별도 제공 |
| 동기화 점 | `img` | `aria-label="동기화 표시"` | 의미 설명 금지 |
| 시간 | `time` | `datetime` | — |

### 6.3 읽기 순서 예

- 채팅 목록 행: "지훈, 3월 15일 10:40, 폰 잃어버림… 우리 아빠한테는 말하지 마, 읽지 않음, 버튼"
- 사진 정보(i): "촬영 2026년 3월 14일 18시 41분, 위치 성원구청역, 기기 도현의 폰, 편집됨"
- 잠금화면: "3월 17일 화요일, 21시 10분. 알림 23개. 응급정보 버튼. 암호 6자리 입력."
- 잠금 해제 후: 연출 없음. "홈, LUMA"로 바로 이동.

| 사건 | 역할 | 읽는 시점 |
|---|---|---|

| 동기화 삭제 | `status` | "1개 항목이 다른 기기에서 삭제됨" |
| 전송 실패 | `alert` | 즉시 |

| 화면 전환 | 포커스 이동 | 새 화면 제목 |

## 7. 색에 의존하지 않기

| 상태 | 색 외 신호 |
|---|---|
| 읽지 않음 | 숫자 배지 + 굵은 제목 |
| 온라인·활동 중 | 점 + "활동 중" 텍스트 |
| 성공 | 체크 아이콘 + "완료" 텍스트 |
| 경고 | 느낌표 아이콘 + 문구 |
| 오류 | 오류 아이콘 + 문구 + `role=alert` |
| 선택된 탭 | 채움 + 굵기 + `aria-selected` |
| 잠김 | 자물쇠 아이콘 + "잠김" 텍스트 |
| 삭제됨 | 취소선 또는 "삭제됨" 텍스트 |
| 좋아요 | 채운 하트 + `aria-pressed` + 숫자 변화 |
| 동기화 점 | 점의 유무·깜빡임 + 스크린리더 라벨. 색만으로 구분하지 않음 |

- 색만 바뀌는 호버·선택을 만들지 않는다.
- 적록 색맹을 가정한다. 빨강/초록을 동시에 상태 구분에 쓰지 않는다.

## 8. 자막·전사

| 콘텐츠 | 규칙 |
|---|---|
| 음성 메모(42분) | 전사 텍스트를 제공한다. 설정 > 손쉬운 사용 > 음성 메모 전사로 켠다(캐논). 접근성 "자막 항상 켜기"를 켜면 전사가 기본으로 켜진다. 재생 화면에 `자막` 버튼을 두고 현재 상태를 읽는다 |
| 음성 메모 대사 4구간 | 성우 녹음 + 정확한 자막. 웅성거림 구간은 "알아들을 수 없는 대화"로 표기 |
| 튜브 영상 | 자막 트랙 기본 제공. `자막` 버튼, 언어 "한국어". 자동 생성 자막이 아니라 검수된 자막 |
| 녹음 파일(첨부) | 파형 + 전사. 전사가 없으면 "전사 없음"을 명시 |
| 소리 알림 | 소리 없이도 모든 정보 전달. 알림음·진동은 보조. 원격 삭제·지우기는 무음(캐논) |
| 오디오 자동 재생 | 금지. 사용자가 재생을 눌러야 한다 |

- 자막은 화면 하단 48, 최대 2줄, `body`, 배경 scrim 0.48.
- 자막이 없어도 게임 진행에 필요한 정보는 다른 경로(사진·메타데이터·설정)로 얻을 수 있어야 한다(P4 이중 경로).
- 음성 메모 전사 퍼즐은 유지하고, 접근성 "자막 항상 켜기" 설정으로 우회 경로를 제공한다(Q-OPEN-020 결정).

## 9. 모션·시간·인증

### 9.1 동작 줄이기

- `prefers-reduced-motion: reduce` 또는 게임 설정 "동작 줄이기"가 켜지면:
  - 화면 푸시·시트 이동을 없애고 150ms 페이드.
  - 탭 눌림 축소(0.97)를 없앤다.
  - 동기화 삭제는 페이드 없이 문구만 3초.
  - 동기화 점은 깜빡이지 않는다. 전송 중에는 불투명도 1, 유휴에는 0.35. **정보는 유지하고 움직임만 없앤다.**
  - 패럴랙스·자동 스크롤·흔들림을 없앤다.
- 동작 줄이기는 게임 진행·정보에 영향을 주지 않는다.

### 9.2 깜빡임

- 어떤 요소도 **초당 3회 이상** 깜빡이지 않는다.
- 동기화 점: 1.2초 주기, 불투명도 1↔0.35. 초당 0.83회.
- 카메라 셔터·플래시 효과: 화면 전체 번쩍임 금지. 1회 100ms 이하의 약한 밝기 변화만.
- 로딩 스피너: 회전 1초/바퀴. 번쩍임 없음.

### 9.3 시간 압박 완화

| 항목 | 규칙 |
|---|---|
| 기본 시간 | 실시간 1분 = 게임 4분. 일시정지 메뉴에서만 멈춘다(캐논) |
| **시간 흐름 끄기** | 일시정지 메뉴 > 설정과 설정 > 디스플레이 양쪽에서 끌 수 있다. 끄면 앱 전환 1회 = 게임 1분(캐논) |
| 일시정지 | 세 손가락 길게 누르기 또는 **상태바 시각 1.5초 길게 누르기**, 데스크톱 `Esc`. 일시정지 중 시간·이벤트 정지 |
| 입력 시간 | 메시지 작성에 제한 시간 없음. 작성 중 시간이 흘러도 입력을 끊지 않는다. 시간 흐름 끄기로 완전히 멈출 수 있다 |
| 마감 | 3/18 09:00은 엔딩 분기 조건이지 실패 화면이 아니다. 게임 오버 없음(캐논) |
| 반사 신경 | 요구하지 않는다. 모든 timed event는 앱 전환·행동으로 진행된다 |
| 대기 | 30초 잠금 대기는 데이터 손실이 없다. 남은 시간을 문구와 스크린리더로 알린다 |

- 카운트다운 HUD를 만들지 않는다. 남은 시간은 상태바 시계와 메시지 본문으로만.
- 일시정지는 세 손가락 500ms + 상태바 시각 1.5초 + Esc로 확정한다. 상태바 시각은 단일 포인터 대체 경로다(Q-OPEN-019 결정).

### 9.4 일관된 도움말(3.2.6)

- "막혔을 때"는 모든 화면에서 **일시정지 메뉴의 같은 위치**에 있다. 앱마다 다른 도움말 버튼을 두지 않는다.
- 도움말은 3단계(방향 → 앱 → 위치)로 같은 형식이다.
- 접근성 설정(글자 크기·시간 흐름·동작 줄이기·소리)은 일시정지 메뉴와 설정 > 디스플레이에서 같은 값으로 연결된다.

### 9.5 접근 가능한 인증(3.3.8)

- 잠금은 6자리 숫자다. 인지 기능 테스트·퍼즐·CAPTCHA를 추가하지 않는다.
- 데스크톱에서는 물리 키보드로 입력할 수 있다. 모바일에서는 숫자 키패드와 `inputmode="numeric"`.
- 붙여넣기를 허용한다. 붙여넣은 숫자는 화면에 마지막 1자리만 잠깐 보이고, 스크린리더는 "6자리 입력됨"으로 읽는다.
- 오답 6회째 30초 대기. 대기 중에도 다른 화면을 볼 수 있고, 데이터는 유지된다. 대기 시간을 스크린리더에 알린다.
- 응급정보는 잠금화면에서 접근 가능하다(캐논). 인증 없이 볼 수 있는 정보와 없는 정보를 섞지 않는다.

## 10. 판독용 확대

| 방법 | 규칙 |
|---|---|
| 두 손가락 벌리기 | 사진·지도·영상에서 1×~4×. `touch-action: none` 영역 |
| 두 번 탭 | 사진에서 1×↔2× 토글. 좋아요 두 번 탭과 충돌하지 않게 사진 영역에서만, 300ms |
| **버튼 대체** | 모든 확대 영역에 `+`/`−` 버튼(44×44)과 `1×` 리셋 버튼. 핀치를 몰라도 확대 가능 |
| 키보드 | 확대 영역에 포커스 후 `+`/`-`, 화살표로 이동, `0`으로 리셋 |
| 텍스트 확대 | 동적 글자 4단계(0.85/1.0/1.15/1.3) + 브라우저 확대 허용 |
| 리플로 | 320 폭에서 가로 스크롤 없음(1.4.10). 400% 확대에서도 동일 |
| 판독 요소 | 번호판·간판·문 번호는 확대 시 2배 해상도(아트 규칙). 확대 전엔 읽히지 않아야 한다 |
| 확대 상태 표시 | "2.0×"를 `caption-1`로 표시. 스크린리더에 "확대 200%" 알림 |

- 브라우저의 페이지 확대를 막지 않는다. `user-scalable=no`를 쓰지 않는다.
- 확대 중에는 한 손가락 드래그로 이동, 두 손가락으로 이동·확대. 버튼 대체는 항상 보인다.
- 지도는 확대·이동 외에 **핀 목록 보기**를 제공한다. 지도만으로 정보를 전달하지 않는다.

## 11. 검수 체크리스트

- [ ] 모든 텍스트가 2.5의 대비 규칙을 통과한다. 라이트 `label-2`를 17pt 이하 본문에 쓰지 않았다.
- [ ] 모든 터치 대상이 44×44 이상이고 8 이상 떨어져 있다.
- [ ] 포커스 링 2px·오프셋 2가 모든 상호작용에 보인다. 가려지지 않는다.
- [ ] Tab만으로 모든 기능에 도달한다. Esc로 오버레이/일시정지를 닫는다.
- [ ] 아이콘 버튼에 `aria-label`이 있다. 상태 컨트롤에 `aria-*` 상태가 있다.
- [ ] 색만으로 상태를 표시하는 곳이 없다.
- [ ] 동작 줄이기에서 이동이 사라지고 정보는 유지된다.
- [ ] 음성 메모·튜브·녹음에 자막/전사 경로가 있다.
- [ ] 시간 흐름 끄기가 일시정지 메뉴와 설정 양쪽에 있다.
- [ ] 초당 3회 이상 깜빡이는 요소가 없다.
- [ ] 확대를 버튼으로 할 수 있고, 320 폭에서 가로 스크롤이 없다.
- [ ] 스크린리더가 정보(i)를 열기 전에 메타데이터를 읽지 않는다.
- [ ] 동기화 점을 설명하는 문구가 없다. 라벨은 "동기화 표시"뿐이다.

## 확인 사항

- `Q-OPEN-08`: 음성 메모 전사 퍼즐은 유지하고, 접근성 "자막 항상 켜기" 설정을 추가한다. (해결 — Q-OPEN-020 결정)
