# COMPONENT_SPECIFICATIONS — 컴포넌트 규격

> **역할:** LUMA OS를 구성하는 **컴포넌트 `CMP-`의 단일 출처**. 각 컴포넌트의 용도, 해부도, 치수, 글자, 색, 상태, 변형, 접근성, 사용 금지 상황을 구현자가 판단 없이 따라 할 수 있게 정의한다.
> **단일 출처:** 이 문서 = 컴포넌트 ID(`CMP-`), 내부 구조, 상태, 변형, 접근성 역할. 값은 [DESIGN_TOKENS.md](./DESIGN_TOKENS.md)를 그대로 쓰며 새 값을 만들지 않는다. 화면 배치는 [SCREEN_SPECIFICATIONS.md](./SCREEN_SPECIFICATIONS.md), 화면 목록은 [NAVIGATION_ARCHITECTURE.md](./NAVIGATION_ARCHITECTURE.md), 움직임은 [INTERACTION_SPECIFICATIONS.md](./INTERACTION_SPECIFICATIONS.md)가 단일 출처다.
> **참조:** [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) · [UI_UX_GUIDELINES.md](./UI_UX_GUIDELINES.md) · [ACCESSIBILITY.md](./ACCESSIBILITY.md) · [RESPONSIVE_DESIGN.md](./RESPONSIVE_DESIGN.md) · [ICONOGRAPHY_AND_IMAGERY.md](./ICONOGRAPHY_AND_IMAGERY.md) · 03-features 문서 전체.
> **근거:** 공통 지시서 3.2·3.4, [DESIGN_TOKENS.md](./DESIGN_TOKENS.md) 1~8절. 토큰과 충돌하는 수치를 이 문서에 만들지 않는다.

## 0. 공통 규칙

### 0.1 토큰 사용

- 모든 치수는 `--lm-space-*`, `--lm-radius-*`, `--lm-*` 크롬 토큰으로 표기한다. 값은 [DESIGN_TOKENS.md](./DESIGN_TOKENS.md)와 같다.
- 색은 의미 토큰만 쓴다. 라이트/다크는 같은 토큰이 자동으로 다른 값을 갖는다. 컴포넌트별 "색" 항목은 **토큰 이름**을 적는다.
- 앱별 강조색은 `--lm-app-tint` / `--lm-app-on-tint` 하나만 쓴다.
- 글자는 [DESIGN_TOKENS.md](./DESIGN_TOKENS.md) 2.2의 스타일 토큰만 쓴다. 동적 글자 배율(`--lm-type-scale`)을 모든 컴포넌트에 적용한다. `caption-2`만 11pt 하한을 지킨다.
- 숫자는 항상 `font-variant-numeric: tabular-nums`다.

### 0.2 상태 표기

| 상태 | 시각 규칙 |
|---|---|
| 기본 | 명시 |
| 눌림 | `--lm-op-pressed` 0.72 오버레이 또는 `fill-2` 배경. 탭 축소는 `--lm-tap-scale` 0.97, `--lm-dur-instant` 100ms. |
| 비활성 | `--lm-op-disabled` 0.38. 왜 비활성인지 바로 위/아래 `footnote`로 쓴다. |
| 선택 | 앱 tint 옅은 면 `--lm-op-tint-wash` 0.12 또는 `--lm-fill`. |
| 포커스 | 2px `tint` 링, 오프셋 2. `tint-fill` 채움 위에서는 `on-tint` 링. |
| 로딩 | `--lm-op-skeleton` 0.08 스켈레톤 또는 20pt 스피너. 300ms 넘을 때만. |
| 오류 | `destructive` 아이콘 + `destructive-ink` 텍스트. 색만으로 표시하지 않는다. |

### 0.3 접근성 공통

- 최소 터치 영역 `--lm-touch-min` 44×44. 시각 크기가 작아도 터치 영역을 44까지 확장한다.
- 인접 터치 대상 간격 최소 8.
- 아이콘만 있는 버튼은 `aria-label`을 준다. 라벨에 "버튼"을 넣지 않는다.
- 상태를 가진 컨트롤은 `aria-pressed` / `aria-selected` / `aria-checked` / `aria-expanded`를 쓴다.
- 상태를 색만으로 표시하지 않는다. 점·숫자·문구·굵기를 함께 쓴다.
- 포커스 트랩은 모달·시트·경고창 안에서만. 닫히면 연 요소로 복귀한다.
- 동작 줄이기에서 이동·확대·축소·흔들림을 없애고 150ms 페이드 또는 즉시 상태 변화로 대체한다.

### 0.4 공통 금지

- 실제 서비스명·로고·플랫폼 독점 심볼·에셋을 쓰지 않는다.
- 장식 그라데이션, 광택, 3D, 손글씨 UI를 쓰지 않는다.
- 같은 화면에 강조색 두 개를 쓰지 않는다. 단, 상태 점(성공·경고·파괴)은 강조색으로 세지 않는다.
- 다크에서 `box-shadow`를 쓰지 않는다. 깊이는 `bg` → `bg-elevated` → `bg-tertiary` 면 밝기와 재질로 만든다.
- 정답·오답·진행도·"새 정보" 배지를 만들지 않는다.

## 1. 셸 크롬

### CMP-STATUS-BAR

**용도** 모든 화면 위의 기기 상태. 시각·회선·Wi-Fi·동기화 점·집중 모드·배터리·화면 기록 표시를 담는다.
**해부도**
```
┌──────────────────────────────────────────────┐
│ 21:10        서비스 없음  ⌁  ·  ☾  31%  ▮   │ 47
└──────────────────────────────────────────────┘
  좌: 시각                      우: 회선·Wi-Fi·동기화·집중·배터리·기록
```
**치수** 높이 `--lm-statusbar-h` 47(실기기 `calc(--lm-safe-top + 44)`). 좌우 `--lm-space-4` 16. 아이콘 12. 요소 간격 `--lm-space-2` 8.
**글자** `--lm-text-caption-1` 12/16 400. 숫자 tnum.
**색** 라이트/다크: 글자 `--lm-label-2`, 활성 아이콘 `--lm-label`, 경고·집중 `--lm-warning-ink`, 화면 기록 `--lm-destructive` 점 + `--lm-label` "기록" 글자, 동기화 점 `--lm-tint`.
**상태** 기본 / 오프라인(회선 "서비스 없음" 고정) / 동기화 중(점 깜빡임 1.2초) / 집중 모드(달 아이콘 + "방해 금지" 라벨) / 화면 기록(빨간 점 8 + "기록") / 충전 중(배터리 번개).
**변형** 잠금화면(시각 없음, 상태바 숨김) / 시네마틱(숨김) / 일시정지(숨김).
**접근성** `role="status"`가 아니라 정적 `header` 그룹. 시각은 `<time>`. 동기화 점은 `aria-label="동기화 표시"`만 주고 의미를 해설하지 않는다. 화면 기록은 "화면 기록 중"으로 읽는다.
**금지** 회선을 복구된 것처럼 표시. Wi-Fi 아이콘만으로 온라인을 설명. 동기화 점의 의미를 툴팁·범례로 설명. 색만으로 기록 중을 표시.

### CMP-HOME-INDICATOR

**용도** 홈 제스처의 시각적 기준. 하단 중앙 고정.
**해부도** `──────────` 134×5, 하단 8.
**치수** `--lm-home-indicator-w` 134 × `--lm-home-indicator-h` 5. 하단 `--lm-home-indicator-bottom` 8. 모서리 `--lm-radius-full` 999.
**글자** 없음.
**색** 라이트/다크: `--lm-label` 불투명도 0.32(`label-3`와 동일). 배경 위에서 3:1 이상이 아니면 `--lm-label-2`로 올린다.
**상태** 기본 / 시트·모달 위(시트가 있으면 시트 하단 기준) / 시네마틱(숨김).
**변형** 없음.
**접근성** 장식(`aria-hidden="true"`). 제스처의 단일 대체는 내비 바 뒤로·홈 버튼이다.
**금지** 인디케이터 자체를 버튼으로 만들기. 위 8px 안에 터치 대상 두기.

### CMP-NAV-BAR

**용도** 화면 제목, 뒤로, 동작 버튼. 큰 제목·검색 포함 변형이 있다.
**해부도**
```
┌──────────────────────────────────────────────┐
│ ←    제목(중앙)                    ⋯    ⌕   │ 44
├──────────────────────────────────────────────┤
│ 큰 제목                                       │ 96(펼침)
│ ┌──────────────────────────┐ [취소]          │
│ │ ⌕ 검색                    │                 │
│ └──────────────────────────┘                 │
└──────────────────────────────────────────────┘
```
**치수** 일반 `--lm-navbar-h` 44. 큰 제목 `--lm-navbar-large-h` 96(상태바 제외). 좌우 `--lm-space-4` 16. 뒤로·동작 버튼 44×44. 검색 포함 변형은 제목 아래 `--lm-space-2` 8, 검색 필드 높이 36(터치 44).
**글자** 일반 제목 `--lm-text-headline` 17/22 600. 큰 제목 `--lm-text-large-title` 34/41 700. 검색 필드 `--lm-text-callout` 16/21 400. 스크롤 시 큰 제목은 `headline`으로 축소한다.
**색** 라이트/다크: 배경 `--lm-material-thin` + 블러 20, 글자 `--lm-label`, 보조 아이콘 `--lm-tint-ink`, 구분선 `--lm-separator`. 큰 제목 배경은 스크롤 전 `--lm-bg`, 스크롤 후 `material-thin`.
**상태** 기본 / 스크롤(큰 제목 축소) / 검색 활성(취소 버튼) / 비활성 동작(`op-disabled`) / 오프라인(제목 아래 인라인 안내는 `CMP-INLINE-NOTICE`).
**변형** 일반 / 큰 제목 / 검색 포함 / 모달형(왼쪽 `취소`, 오른쪽 `저장`·`보내기`).
**접근성** `navigation` + `aria-label="내비게이션"`. 제목은 `h1`. 뒤로 버튼 라벨 "뒤로". 동작 아이콘은 이름을 준다.
**금지** 한 화면에 제목 두 개. 뒤로 버튼 없는 화면. 큰 제목과 탭 바를 같은 화면에 동시에 쓰기(앱 루트는 하나만).

### CMP-TAB-BAR

**용도** 앱 최상위 영역 3~5개 전환. 탭별 스택·스크롤을 기억한다.
**해부도**
```
┌──────────────────────────────────────────────┐
│    ⌂        ⌕        ＋        ♡        ◉    │ 49
│   홈      탐색     만들기     활동    프로필  │
├──────────────────────────────────────────────┤
│                 안전영역 34                    │
└──────────────────────────────────────────────┘
```
**치수** 본체 `--lm-tabbar-h` 49 + 하단 `max(34, --lm-safe-bottom)`. 각 탭 최소 44×44. 아이콘 24, 라벨 아래 `--lm-space-0_5` 2. 라벨 `caption-1` 12/16. 좌우 `--lm-space-2` 8.
**글자** `--lm-text-caption-1` 12/16 400. 10pt 금지.
**색** 라이트/다크: 배경 `--lm-material-regular` + 블러 30, 선택 아이콘·라벨 `--lm-app-tint`, 비선택 `--lm-label-2`, 배지 `CMP-BADGE`.
**상태** 기본 / 선택 / 재탭(맨 위로) / 배지 / 비활성(없음).
**변형** 3탭(톡) / 5탭(루프) / 2탭(전화) / 만들기 강조(가운데 `+`, 앱 tint 원형 44).
**접근성** `tablist` + `aria-label="앱 탭"`. 각 탭 `tab` + `aria-selected` + `aria-controls`. 라벨은 아이콘 이름이 아니라 탭 이름("홈", "탐색"). 안전영역 아래 터치 대상 금지.
**금지** 6개 이상. 라벨 없는 아이콘만. 탭 바 위에 콘텐츠를 가리는 고정 요소. 스크롤에 따라 숨기기.

### CMP-SEGMENTED

**용도** 같은 화면 안의 보기 전환. 팔로잉/추천, 전체/비밀 대화/그룹/채널, 교통/결제, 사진/글/태그됨 등.
**해부도**
```
┌───────────────────────────────┐
│ [ 팔로잉 ]  추천               │ 32
└───────────────────────────────┘
```
**치수** 높이 32. 트랙 패딩 `--lm-space-0_5` 2. 세그먼트 최소 44 터치. 모서리 트랙 `--lm-radius-sm` 10, 썸 `--lm-radius-full` 999.
**글자** `--lm-text-subhead` 15/20 400. 선택 상태는 `--lm-label` 색 + 이동하는 썸 + `aria-selected`로 구분하며 굵기를 바꾸지 않는다.
**색** 라이트/다크: 트랙 `--lm-fill`, 썸 `--lm-bg-elevated` + `elev-1`(라이트) / 다크 `--lm-bg-tertiary`, 선택 글자 `--lm-label`, 비선택 `--lm-label-2`.
**상태** 기본 / 선택 / 눌림 / 비활성 / 포커스. 로딩 없음.
**변형** 2분할 / 3분할 / 4분할(블링크 필터) / 스크롤형(항목이 많을 때 가로 스크롤, 가장자리 페이드).
**접근성** `tablist` + 각 `tab` + `aria-selected`. 화살표 키 이동. 4개 이상이면 라벨이 잘리지 않게 가로 스크롤.
**금지** 5개 이상을 한 화면 폭에 억지로 넣기. 선택 상태를 색만으로 표시. 세그먼트를 내비게이션 대신 쓰기(깊이 이동은 push).

### CMP-SEARCH-FIELD

**용도** 목록·전역 검색 입력.
**해부도**
```
┌───────────────────────────────────┐
│ ⌕  검색                    ⊗       │ 36
└───────────────────────────────────┘
```
**치수** 높이 36(터치 44). 좌우 패딩 `--lm-space-3` 12. 아이콘 17. 지우기 버튼 28 시각·44 터치. 모서리 `--lm-radius-sm` 10.
**글자** `--lm-text-callout` 16/21 400. 플레이스홀더 `--lm-label-3`(라이트에서는 `label-2-aa`).
**색** 라이트/다크: 배경 `--lm-fill`, 글자 `--lm-label`, 아이콘 `--lm-label-2`, 포커스 링 `--lm-tint` 2px.
**상태** 기본 / 포커스 / 입력됨(지우기 버튼) / 비활성 / 오류(검색은 오류 없음) / 로딩(입력 즉시 결과, 스피너 없음).
**변형** 인라인(목록 상단) / 내비 포함 / 전역 검색(큰 입력, 취소 버튼).
**접근성** `search` + `searchbox`, `aria-label="검색"`. 결과 수를 `aria-live="polite"`로 알린다. 지우기 버튼 라벨 "지우기".
**금지** 검색 기록 저장·노출(전역 검색). 결과 0건에 힌트 문구. 플레이스홀더에만 라벨을 두기.

### CMP-LIST-ROW

**용도** 목록의 기본 단위. 1줄/2줄/썸네일/스위치/값/화살표 변형.
**해부도**
```
1줄     │ 텍스트                          값 › │ 44
2줄     │ 주 텍스트                            │ 60
        │ 보조 텍스트              시각        │
썸네일  │ [56] 주 텍스트               배지 › │ 72
        │      보조 텍스트                     │
스위치  │ 텍스트                    [●──]     │ 44
값      │ 텍스트                     값  ›     │ 44
```
**치수** 1줄 `--lm-row-h` 44 / 2줄 `--lm-row-h-2` 60 / 썸네일 `--lm-row-h-thumb` 72. 좌우 `--lm-space-4` 16. 썸네일 56, 텍스트 시작 = 썸네일 오른쪽 + `--lm-space-3` 12. 구분선 `--lm-separator-w` 0.5, 왼쪽 들여쓰기 = 텍스트 시작점. 화살표 17 `label-3`.
**글자** 주 `--lm-text-headline` 17/22 600. 보조 `--lm-text-subhead` 15/20 400 `label-2`. 값·시각 `--lm-text-footnote` 13/18 400 `label-2`, tnum.
**색** 라이트/다크: 배경 `--lm-bg-grouped-cell`, 글자 `--lm-label`, 보조 `--lm-label-2`, 구분선 `--lm-separator`, 선택 `--lm-op-tint-wash`, 눌림 `--lm-fill-2`.
**상태** 기본 / 눌림 / 선택 / 비활성 / 포커스 / 스와이프(삭제·보관 등 앱별) / 로딩(스켈레톤).

## 4. 확인 사항

- **Q-OPEN-211:** `CMP-SEGMENTED`의 선택 상태를 색·썸·`aria-selected`로만 구분하고 굵기를 바꾸지 않았다. [DESIGN_TOKENS.md](./DESIGN_TOKENS.md) 2.2에 선택용 600 굵기 토큰이 없기 때문이다. 선택 강조를 위해 `subhead` 600 토큰을 추가할지 총괄 확인이 필요하다. 추천: 추가하지 않고 현재 방식 유지.
- **Q-OPEN-212:** `CMP-BADGE`의 숫자 배경을 `tint-fill`로 정했다. 관용적 기대(빨간 배지)와 다르다. [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) 4절 "빨강은 파괴적 동작만"을 지키기 위한 결정이다. 앱별 배지는 `--lm-app-tint`를 쓴다. 총괄 확인 필요.
- **Q-OPEN-213:** `CMP-LIST-ROW` 2줄 행의 주 텍스트·보조 텍스트 굵기를 `headline` 600 / `subhead` 400으로 정했다. 2줄 행에서 주 텍스트를 400으로 낮출지 확인이 필요하다.
- **Q-OPEN-214:** `CMP-KEYBOARD` 높이 286은 토큰에 없는 레이아웃 값이다. 키 높이·간격에서 계산한 값이며, 실제 브라우저 `visualViewport` 높이에 따라 줄일 수 있다. SCREEN_SPECIFICATIONS와 합의가 필요하다.
- **Q-OPEN-215:** `CMP-POST-CARD-PHOTO`의 좋아요 색을 `--lm-app-tint`로 정했다. 캐논·관용적 기대는 하트 빨강이지만, [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) 4절의 "빨강은 파괴적 동작만"과 충돌한다. 앱 tint로 확정할지, 좋아요만 예외로 둘지 총괄 확인이 필요하다.
- (해결) 홈 격자는 캐논 4×5 + 독 4칸.
