# ICONOGRAPHY_AND_IMAGERY — 아이콘·사진·카메라·시네마틱·소리

> **역할:** 앱 아이콘 30종, 시스템 글리프, 폰 속 사진, 카메라 방, 시네마틱, 소리의 규격과 원칙을 정의한다. **이 문서는 규격만 쓴다. 아이콘·이미지를 생성하지 않는다.**
> **단일 출처:** 이 문서. 아이콘·사진·카메라·시네마틱·소리의 단일 출처다. 색·모서리·치수 값은 [DESIGN_TOKENS.md](./DESIGN_TOKENS.md)를 따른다.
> **참조:** [DESIGN_TOKENS.md](./DESIGN_TOKENS.md) · [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) · [UI_UX_GUIDELINES.md](./UI_UX_GUIDELINES.md) · [ACCESSIBILITY.md](./ACCESSIBILITY.md) · [MEDIA_SPECIFICATION.md](../03-features/MEDIA_SPECIFICATION.md) · [EVIDENCE_LEDGER.md](../01-product/EVIDENCE_LEDGER.md) · [LOCATIONS.md](../01-product/LOCATIONS.md)
> **근거:** 원본 아트 디렉션 [ICONOGRAPHY_AND_IMAGERY](ICONOGRAPHY_AND_IMAGERY.md) 4~8절(읽기 전용). 4~8절은 원문을 그대로 옮기고, 충돌하는 값은 이 문서 말미의 "토큰 우선" 표기로 해결한다.

## 1. 원칙

1. **벡터 손작업만.** SVG를 손으로 그린다. 래스터 생성 이미지·AI 생성 이미지·사진을 아이콘으로 쓰지 않는다.
2. **한 사람이 30종을 전부 그린다.** 선 굵기·둥근 끝·광학 보정이 통일되어야 한다.
3. **그라데이션·광택·그림자·3D 금지.** 단색 채움과 모노라인만.
4. **글자 금지.** 아이콘 안에 글자를 넣지 않는다. 예외는 캘린더의 날짜 숫자 하나뿐이다.
5. **실루엣 테스트.** 16px 흑백으로 줄였을 때 30종이 전부 구분되어야 한다. 구분되지 않으면 형태를 다시 잡는다.
6. **레퍼런스 분석은 표의 "피해야 할 것" 열에서만.** 실제 서비스명을 아이콘·화면·문구에 쓰지 않는다.
7. **접근성.** 아이콘만 있는 버튼은 `aria-label`을 갖는다. 터치 영역은 44×44다. 상태를 아이콘 색만으로 표시하지 않는다.

## 2. 두 계열

| 계열 | 어디에 | 규격 |
|---|---|---|
| **앱 아이콘** | 홈, 앱 전환기, 알림, 공유 시트 | 60×60 슈퍼타원 타일 + 32×32 글리프 영역. 24 격자 2.5pt 선(60 기준) |
| **시스템 글리프** | 내비, 탭 바, 목록 동작, 상태바, 시트 항목 | 24 격자 2px 선. 크기 17/20/24/28. 타일 없음 |

- 두 계열은 같은 손·같은 둥근 끝을 쓴다. 시스템 글리프를 앱 타일에 넣지 않는다.
- 앱 아이콘은 정체성, 시스템 글리프는 동작이다. 같은 모양을 공유하지 않는다(예: 앱 "사진"과 동작 "사진 추가"는 다르다).

## 6. 폰 속 사진 (원본 5절)

- **스타일:** "폰 카메라로 찍은 장면"을 단순화한 회화형 일러스트. 실제 사진 질감(노이즈, 약한 렌즈 왜곡, 자동 HDR 느낌의 평평한 명암)을 흉내 낸 평면 채색. 만화 선 금지.
- **얼굴 원칙:** 사람의 얼굴은 작거나, 뒷모습이거나, 프레임 밖이다. **인물 식별은 물건으로**(녹색 시계, 검은 SUV, 서아의 노란 필름카메라 끈, 지훈의 빨간 모자). 공정한 추리(얼굴 판독 능력에 의존하지 않음)와 제작 비용을 동시에 해결한다.
- **레이어 제작:** 같은 장면의 변형(편집본/원본, 버스트 18프레임, 스크린샷)은 한 장면 파일의 레이어로 만든다. 예: 1/20 단체사진 = 전체 원본 1장 → 크롭은 코드로. 버스트 = 배경 1장 + 차 레이어 위치·흔들림 18단계 + 11번만 선명.
- **판독 요소 규칙:** 번호판·간판·문 번호처럼 플레이어가 읽어야 하는 글자는 **확대 시 2배 이상 해상도**로 별도 제작. 확대 전엔 읽히지 않아야 한다.
- 필요 수량(본편): 사진 약 60장(노이즈 포함), 그중 핵심 12장. MVP: 30장.

### 6.1 추가 규칙

- 사진은 "폰으로 찍은 사진처럼 보이는 일러스트" 단일 스타일이다. UI 일러스트·만화 컷·3D 렌더를 섞지 않는다.
- 스크린샷은 UI를 그대로 캡처한 이미지처럼 보여야 한다. 사진과 같은 화풍을 입히지 않는다.
- 인물의 얼굴을 확대해 식별하게 만들지 않는다. 얼굴이 프레임에 들어와도 작게·흐리게·가려지게.
- 사진의 alt 텍스트는 보이는 내용만 쓴다. 숨은 단서를 alt에 미리 쓰지 않는다.

## 7. 카메라 뷰 — 도현의 방 (원본 6절)

- 4개 구도(책상 / 서랍 / 침대 / 창밖). 각 구도 1장 + 서랍 열림 레이어. 폰 카메라 뷰파인더 질감(약한 노이즈, 자동 노출).
- 판독 요소: 봉투 글씨 "박미선님 65", 포스트잇 "이웃마켓 예약 — 3/14 리버뷰"는 확대 시 2배 해상도.
- 사람은 없다. 아버지의 손도 화면에 나오지 않는다.
- 찍은 사진은 5절 "폰 사진" 스타일과 같은 화풍으로 사진첩에 저장된다.

### 7.1 추가 규칙

- 카메라 뷰는 게임에서 **유일하게 "지금"을 보여 주는 그림**이다. 다른 화면은 과거의 데이터다.
- 데스크톱 배경(도현의 방 책상)과 카메라 뷰를 혼동시키지 않는다. 데스크톱 배경은 초점이 흐리고 정보가 없다.
- 카메라 뷰에 UI가 아닌 단서를 새로 그려 넣지 않는다. 캐논에 있는 판독 요소만 그린다.
- 서랍 열림은 레이어 전환이다. 열림 애니메이션은 160ms, 소리 없음.

## 8. 시네마틱 (원본 7절)

- 프롤로그 1편(경찰서 민원실 2컷 + 도현의 방 충전기 1컷, 구성은 [NARRATIVE_CANON.md](../01-product/NARRATIVE_CANON.md)) + 엔딩 5편. 스틸 3~5컷 + 하단 자막. 자막 규칙(상황만, 감정 설명 금지) 계승.
- 스틸도 5절 "폰 사진" 스타일과 같은 화풍(따로 놀지 않게). 얼굴 원칙 동일.

### 8.1 추가 규칙

- 시네마틱은 스틸 + 자막이다. 영상 재생·카메라 무빙·줌을 넣지 않는다.
- 자막은 하단 48, `body`, 최대 2줄, 배경 scrim. `prefers-reduced-motion`에서도 동일(정지 스틸).
- 스킵 버튼을 제공한다. 스킵해도 게임 정보를 잃지 않는다(스틸의 정보는 이후 폰에서 다시 얻을 수 있다).
- 시네마틱에 실제 서비스명·로고를 넣지 않는다.
- 제목 표기는 `@dontknow__`의 언더바 두 개를 숨긴 **DONTKNOW** 변형을 쓴다(Q-OPEN-034 결정).

## 11. 제작·검수

### 11.1 제작 순서

1. 24 격자에 선을 그린다. 22×22 안쪽, 1px 여백.
2. 2px 선, 둥근 끝·연결. 광학 보정이 필요하면 0.5px 단위로 조정한다.
3. 16px로 줄여 실루엣을 확인한다. 구분되지 않으면 형태를 단순화한다.
4. 앱 아이콘은 60 타일 중앙 32 영역에 배치하고, 강조점 1개만 채운다.
5. 8색 타일과 흰 타일 조합을 확인한다. 흰 글리프가 타일에서 3:1 이상인지 확인한다(타일 8색은 전부 흰 글리프와 4.5:1 이상).
6. `currentColor`로 내보낸다. 앱 아이콘은 타일색을 CSS 변수로 받는다.

### 11.2 검수

- [ ] 30개 앱 아이콘이 16px에서 전부 구분된다.
- [ ] 44개 시스템 글리프가 16px에서 전부 구분된다.
- [ ] 그라데이션·그림자·3D·글자가 없다(캘린더 숫자 예외).
- [ ] 강조점이 아이콘당 1개 이하다.
- [ ] 아이콘 안에 실제 서비스명·로고가 없다.
- [ ] 아이콘만 있는 버튼에 `aria-label`이 있다.
- [ ] 터치 영역 44×44.
- [ ] 아이콘 이미지를 생성하지 않았다(이 문서는 규격만).
