> **단일 출처:** 페르소나의 정의·행동 기준. 원문은 [[PRODUCT_PRINCIPLES](../00-foundation/PRODUCT_PRINCIPLES.md)](../00-foundation/PRODUCT_PRINCIPLES.md) 5절("플레이어는 누구인가")과 [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1("두 기준 플레이어")다.
> **참조:** [`PRD.md`](PRD.md), [`USER_JOURNEYS.md`](USER_JOURNEYS.md), [`../00-foundation/PRODUCT_VISION.md`](../00-foundation/PRODUCT_VISION.md), [`../01-product/CHARACTERS.md`](CHARACTERS.md).
> **금지:** 원본에 없는 인구통계(성별·직업·소득·거주지·가족 구성 등)를 창작하지 않는다. 아래에 없는 속성은 "원본에 없음"이다.

## 1. P-01 — 이상철(57), 플레이어 캐릭터

| 항목 | 내용 | 근거 |
|---|---|---|
| 정체 | 도현의 아버지. 실종된 아들의 폰을 돌려받은 사람 | [[PRODUCT_PRINCIPLES](../00-foundation/PRODUCT_PRINCIPLES.md)](../00-foundation/PRODUCT_PRINCIPLES.md) 5절 |
| 나이 | 57세 | [[PRODUCT_PRINCIPLES](../00-foundation/PRODUCT_PRINCIPLES.md)](../00-foundation/PRODUCT_PRINCIPLES.md) 5절 |
| 장소 | 도현의 방 책상 앞. 아들의 폰을 충전기에 꽂은 사람 | [[PRODUCT_PRINCIPLES](../00-foundation/PRODUCT_PRINCIPLES.md)](../00-foundation/PRODUCT_PRINCIPLES.md) 5절 |
| 화면에 없는 것 | 아버지의 얼굴·목소리·손글씨. 아버지의 목소리는 아버지가 보낸 톡 6통으로만 존재 | [[PRODUCT_PRINCIPLES](../00-foundation/PRODUCT_PRINCIPLES.md)](../00-foundation/PRODUCT_PRINCIPLES.md) 5절 |
| 아는 것 | 경찰이 한 말(프롤로그 스틸 3컷 자막) + 자기가 보낸 톡 6통. **빚은 어디에도 적혀 있지 않다** | [[NARRATIVE_CANON](NARRATIVE_CANON.md)](NARRATIVE_CANON.md) 6절 |
| 모르는 것 | 한결캐피탈, 빚의 행방, 직장 위협, 아들의 은신처·계좌 대여 | [[NARRATIVE_CANON](NARRATIVE_CANON.md)](NARRATIVE_CANON.md) 6절 |
| 결함 | 회피. 아들에게 빚을 말하지 않았다. 말하지 않은 것이 아버지의 결함이다 | [[NARRATIVE_CANON](NARRATIVE_CANON.md)](NARRATIVE_CANON.md) 6절 · [`../00-foundation/Bible.md`](../00-foundation/Bible.md) 2절 |

**이 페르소나가 게임에서 하는 일:**
- 아들의 폰을 뒤져 아들이 무엇을 했는지, 어디에 있는지 알아낸다.
- 알아낸 것을 폰에서 행동으로 쓴다: 답장, 사진 전송, 공유, 설정 변경, 택시 호출.
- 마지막에 빚을 말할지(정체 고백) 결정한다. 이것이 A/A′를 가른다.

**설계 함의:**
- 플레이어에게 정보를 주는 통로는 **폰 안의 데이터**와 **아버지가 이미 보낸 말**뿐이다. 아버지가 새로 알게 되는 사실을 독백으로 설명하지 않는다(P5).
- 아버지의 무지는 결함이자 미스터리의 엔진이다. 그를 무능하게 그리지 않고, 폰을 통해 능동적으로 알아가게 한다.

## 2. P-02 — 숙련 플레이어(보수 기준)

| 항목 | 내용 | 근거 |
|---|---|---|
| 정의 | 추리 게임 숙련자 + 스마트폰 숙련자 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 읽기 속도 | 화면 글을 분당 약 900자로 훑는다 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 헛걸음 | 거의 없음. 틀린 공유 0~1회 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 힌트 | 보지 않는다 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 대기 | NPC 답장을 기다리는 동안 다른 앱을 본다(대기 0) | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 쓰임 | **플레이타임 합격선 90분**의 기준 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |

**행동 특성(설계가 가정하는 것):**
- 설정 깊은 메뉴·정보(i)·다른 기기 기록까지 스스로 찾아 들어간다.
- 흔적의 대가를 이해하고, 필요하면 미리보기·비행기 모드로 피한다.
- 같은 정보를 두 번 읽게 하는 경로를 싫어한다.

**이 플레이어에게 게임이 보장해야 하는 것:**
- 첫 앱 진입에서 길을 잃지 않는 정보 구조(설정 검색, 깊이 3단계 이하).
- 모든 필수 행동의 근거가 서로 다른 앱 2개 이상(P4).
- 90분 이상의 실제 읽기·대조·행동 분량. 패딩·강제 대기 없이.

**이탈 위험:**
- 픽셀 헌팅, 설정 미로, 같은 정보의 중복 필수 경로, 오답 페널티. [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 5절의 금지 규칙으로 막는다.

## 3. P-03 — 일반 플레이어

| 항목 | 내용 | 근거 |
|---|---|---|
| 정의 | 처음 하는 추리 게임 이용자 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 읽기 | 정독 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 재방문 | 같은 앱 재방문 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 틀린 공유 | 2~3회/인물 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 힌트 | ①(방향)을 가끔 본다 | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1 |
| 쓰임 | 페이싱·시계 기준. 예상 플레이타임 **약 165분** | [`PLAYTIME_BUDGET.md`](PLAYTIME_BUDGET.md) 1.1·3절 |

**행동 특성(설계가 가정하는 것):**
- 읽는 데 시간이 걸리고, 같은 화면을 다시 연다.
- 인물에게 틀린 것을 보내고 반응을 통해 수정한다.
- 힌트가 없으면 특정 화면에서 막힐 수 있다.

**이 플레이어에게 게임이 보장해야 하는 것:**
- 세계의 넛지(새 메시지·새 스토리·새 주문·저장 공간 알림)가 방향을 준다.
- 일시정지 메뉴의 3단계 힌트가 막힘을 풀어 준다.
- 틀린 공유에도 페널티 없이 세계가 반응한다(흔적은 남는다).
- 시계 압박으로 생각할 시간을 빼앗지 않는다(×4, 일시정지, 시간 흐름 끄기).

**이탈 위험:**
- "내가 맞았나" 불안, 20분 이상 새 행동 없음, 미끼(청운)에 대한 배신감, 원격 지우기로 인한 조기 엔딩. [`PRD.md`](PRD.md) 7절 리스크 표의 대응을 따른다.

## 4. 두 기준이 설계에 미치는 영향

| 결정 | 숙련(P-02) | 일반(P-03) | 공통 해법 |
|---|---|---|---|
| 힌트 | 안 봄 | 가끔 ① | 일시정지 메뉴 안에만, 상시 목록 없음 |
| 흔적 | 피하는 법을 안다 | 반응을 보고 배운다 | 첫 반응을 크게, 이후 지연·암시 |
| 시간 | 97분 하한 | 165분 기준 | ×4 + 일시정지 + 시간 흐름 끄기 |
| 미끼 | 빨리 간파 | 청운 취소 메일이 결정적 | 취소 메일을 받은편지함 맨 위·알림 센터에 배치 |
| 입력 | 정확 | 틀린 공유 2~3회 | 표기 변형 인정, 기본 반응 짧게 |

## 5. 원본에 없는 것

- 실제 이용자의 연령 분포·성별·직업·소득·지역·플랫폼 기기 보유율.
- 접근성 요구가 있는 플레이어의 별도 페르소나(접근성 요구는 [`../00-foundation/REQUIREMENTS.md`](../00-foundation/REQUIREMENTS.md) REQ-N-010~014로 다룬다).
- 마케팅용 구매자 페르소나.

## 확인 사항

- **Q-OPEN-16:** 원본은 "숙련/일반" 두 스킬 기준과 이상철이라는 서사 인물만 제공한다. 실제 이용자 인구통계·접근성 페르소나는 원본에 없어 만들지 않았다. 필요하면 P7 플레이테스트 결과로 보강한다.
- **Q-OPEN-17:** "일반 플레이어 165분"은 계산 기준이며, 실제 중앙값 목표는 140~190분이다. 페르소나 문서에서는 계산값과 검증 목표를 구분해 표기했다.
