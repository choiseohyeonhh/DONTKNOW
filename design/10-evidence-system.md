# 10. 단서 원장 (v6.2)

> 단서 ID `E-xx`는 이 문서가 단일 출처다. v6.2에서 **카드·수집·강도는 폐기**했다. 단서는 폰 안의 데이터 그 자체다. 이 문서는 "어떤 데이터가 어떤 행동(V)·반응의 근거가 되는가"의 원장이다. 행동 증명은 11, 흔적은 19 문서.

## 1. 원칙

1. **무엇이 단서인지 표시하지 않는다.** 반짝임·배지·효과음 없음. 핵심 데이터는 노이즈 속에 있다(노이즈 70% 이상).
2. **메타데이터는 직접 열어야 보인다.** 정보(i)를 열지 않으면 시각·위치·보낸 기기·받은 경로를 모른다.
3. **플레이어의 기억이 유일한 수첩이다.** 지워진 것은 지워진 것이다. 남기고 싶으면 폰의 방법으로 남긴다: 스크린샷, 동기화 끄기, 남에게 공유(보낸 메시지는 남는다), 경찰에게 메일.
4. **게임 내부 기록:** 게임은 플레이어가 어떤 데이터를 열었는지(`seen`)와 정보(i)를 열었는지(`inspected`)를 조용히 기록한다. 이 기록은 **화면에 나오지 않고**, 힌트 단계 선택과 엔딩 후 "다시 보기" 통계에만 쓰인다. 판정에는 쓰지 않는다(판정은 행동으로만, 11 문서).

## 2. 보존 수단

| 수단 | 효과 | 한계 |
|---|---|---|
| 먼저 읽기 | 플레이어가 안다 | 원본이 지워지면 공유할 수 없다 |
| 스크린샷 | 사진으로 남음(공유 가능) | 원본 메타데이터 없음(스크린샷 시각만). 사진 동기화가 켜져 있으면 도현이 보고 지울 수 있음 |
| 동기화 끄기(18 문서 2절) | 그 앱은 원격 삭제가 닿지 않음 | 도현의 새 데이터도 안 들어옴 |
| 공유(메시지·DM·메일) | 보낸 메시지에 사본이 남음 | 상대에게 흔적 |
| 경찰 메일 | 외부 보존 = 엔딩 플래그 | 온라인, 첨부 크기 |

**소실 사건:** 원격 삭제(EV-04/05/07/09), 원격 지우기(EV-08, 즉시 엔딩), 블링크 60초, 실장의 흔적 정리(EV-22/23).
