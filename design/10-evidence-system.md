# 10. 단서 수집과 증거 관리 시스템

> 증거 ID `E-xx`는 이 문서가 단일 출처다. 질문·모순·동일성 판정에서 어떻게 쓰이는지는 11 문서.

## 1. 원칙

1. **무엇이 단서인지 표시하지 않는다.** 모든 항목(메시지 한 통, 사진 한 장, 거래 한 줄, 지도 핀 하나)을 수첩에 붙일 수 있다. 핵심 증거에 반짝임·배지·효과음이 없다.
2. **카드는 원본의 사본이다.** 수첩 카드는 아버지가 손으로 옮겨 적은 것(손글씨 + 작은 스케치/폴라로이드 인쇄)이다. 원본이 지워져도 카드는 남는다.
3. **메타데이터는 직접 열어야 카드에 들어간다.** 사진을 정보(i)를 열지 않고 붙이면 카드에 시각·위치가 없다. 정보를 연 뒤 붙이면 카드에 적힌다. 플레이어의 관찰이 카드의 품질을 정한다.
4. **수량 제한 없음.** 쓸모없는 카드가 쌓이는 것도 수사다. 단서 탭에서 정리(핀·폴더·버리기) 가능.

## 2. 카드의 구조

```
┌─────────────────────────────┐
│ [앱 도장] 루프 · seoa.film     │  ← 출처 앱과 계정
│  ┌───────┐                  │
│  │ 사진   │ 3/14 21:40        │  ← 정보(i)를 열었을 때만
│  │ 인쇄   │ 홍대입구역          │
│  └───────┘                  │
│ "스토리. 홍대. 혼자 술"          │  ← 아버지 손글씨 요약(자동 생성 문구)
│                    [강/약]    │  ← 증거 강도(4.3)
└─────────────────────────────┘
```

| 필드 | 설명 |
|---|---|
| `src` | 원본 항목 ID(앱 데이터의 고유 ID) |
| `evidence` | 증거 ID(E-xx) — 핵심 항목만 갖는다. 노이즈 항목은 없음(판정에 안 쓰임) |
| `facets` | 카드에 담긴 측면: `time`, `place`, `person`, `amount`, `account`, `text` — 플레이어가 정보를 열었는지에 따라 달라짐 |
| `strength` | `strong`(원본 존재 / 스크린샷) / `weak`(원본 소실 후 손글씨만, 또는 블링크 베껴 적기) |
| `note` | 아버지 손글씨 요약(데이터에 미리 작성) |

## 3. 수집 수단

| 수단 | 방법 | 카드 강도 | 대가 |
|---|---|---|---|
| 수첩에 붙이기 | 길게 누르기 → 붙이기 | strong(원본이 살아 있는 동안) | 없음 |
| 스크린샷 | 제어 센터 / 버튼 조합 | strong(영구, 단 원본 메타는 없음 — 스크린샷 시각만) | 블링크에서 찍으면 실장에게 알림 |
| 베껴 적기 | 블링크 메시지 길게 누르기 → "수첩에 베껴 적기"(3초 연출) | weak | 60초 타이머 안에 해야 함 |
| 메일로 보내기 | 공유 → 메일 → 김태윤 | (카드 아님) 외부 보존 = 엔딩 플래그 | 온라인 필요 |

## 4. 증거 강도와 소실

### 4.1 소실 사건
원격 삭제(EV-04/05/07/09)·원격 지우기(EV-08)·블링크 60초로 원본이 사라질 수 있다.

### 4.2 소실 후 카드
- 붙여 둔 카드: 남는다. 강도가 `strong → weak`로 바뀐다. 카드 귀퉁이에 "원본 없음" 손글씨.
- 스크린샷: 사진첩에 남는다(단, 원격 지우기 시 함께 사라짐 → 붙여 둔 스크린샷 카드는 weak로 남음).

### 4.3 강도의 쓰임
- **질문 판정(Q):** weak 카드도 쓸 수 있다. 단 각 질문에 "strong 1장 이상" 규칙이 있는 경우가 있다(11 문서 판정표 `minStrong`).
- **NPC에게 보내기:** weak 카드는 "말로 전하기"가 되어 반응이 약해진다(예: 지훈에게 3/15 톡 원본 대신 손글씨를 보이면 "그거… 아저씨가 어떻게 알아요" 정도로 덜 무너진다).
- **엔딩:** 경찰에 보내는 증거는 원본(파일) 필요. 녹음은 원본 없이는 엔딩 A·C의 "실장 체포" 조건을 못 채운다.

## 6. 단서 탭(수첩) 정리 기능

- 정렬: 붙인 순 / 시간순(카드의 시각 기준) / 출처 앱별.
- 핀: 중요 카드 상단 고정. 폴더: 플레이어가 이름 없이 색 탭으로 묶음(손글씨 라벨 자동: "돈", "사람", "장소" 등 아버지 말투 3종 중 선택).
- 카드 → 검색: 카드 안 단어(이름·번호·장소)를 길게 누르면 폰 검색으로 보낸다.
- 카드 → 원본 열기: 원본이 살아 있으면 해당 앱 항목으로 이동.
