# 11. 추리 및 가설 검증 시스템 — 아빠의 수첩

> 판정 ID(`C-xx` 모순, `I-xx` 동일성, `Q-xx` 질문, `F` 결론)는 이 문서가 단일 출처다.
> 원칙(01 기둥 P2): **게임은 연결을 제안하지 않는다. 플레이어가 제안하고, 게임은 맞는지만 말한다.**

## 1. 수첩의 다섯 탭

| 탭 | 무엇을 하나 | 시작 상태 |
|---|---|---|
| **질문** | 열린 질문 목록. 각 질문에 카드를 넣어 답을 제출 | Q-01, Q-02 두 개만 적혀 있음(아버지 글씨) |
| **단서** | 붙인 카드 전부. 정리·검색 연결 | 인수증(E-01)과 첫 장 메모 |
| **사람** | 인물 페이지. 계정 카드를 사람에게 "이 사람 거다"로 묶기(동일성) | 이도현, 정지훈, 한서아(경찰에게 들은 이름) |
| **시간표** | 3/6~3/17 날짜 줄. 시각이 있는 카드가 자동으로 그 자리에 놓인다. 두 카드를 이어 "모순" 제출 | 3/14 18:52 마지막 메시지, 21:22 CCTV, "서아: 10시까지 같이"(진술 카드) |
| **내 폰** | 아버지 자신의 폰. 기능은 **도현에게 톡 보내기** 하나(고정 문장 3개) | 잠김 — DH-2 단계에서 열림(12 문서) |

- **시간표의 자동 배치는 연결이 아니다.** 카드가 제 시각에 놓이는 건 메타데이터의 사실일 뿐, 둘이 모순인지 판단하는 건 플레이어다. 겹쳐 보이도록 배치되지만 색·선·경고는 없다.
- **진술 카드:** 사람들이 한 말(경찰을 통해 들은 말, 대화에서 들은 말)도 카드다. 출처 도장이 "말"이다. 진술 카드는 모순 판정의 한쪽이 되기 위해 존재한다.

## 2. 연결 세 종류

| 연결 | 조작 | 판정 대상 | 성공 시 |
|---|---|---|---|
| **모순** | 시간표·단서에서 카드 A를 카드 B 위로 끌어 "안 맞는다" | `C-xx` | 거짓말한 사람의 페이지에 손글씨 "거짓말" + 그 사람과의 대화 단계 변화 |
| **동일성** | 사람 탭에서 카드(계정·번호·사진 속 물건)를 인물에게 끌어 "이 사람이다" | `I-xx` | 계정이 인물 페이지에 묶이고, 그 계정의 콘텐츠가 그 사람의 행동으로 인정됨 |
| **답** | 질문 칸에 카드 1~3장을 넣고 "이거다" | `Q-xx` | 수첩에 아버지의 결론 한 줄 + 새 질문 또는 새 접근 |

- 제출에는 비용이 없다. 대신 **틀린 제출은 아버지의 짧은 반박**으로 돌아온다(4절). 같은 질문 오답 3회 → 힌트 ① 즉시.
- **부분 정답:** 필요한 측면(time/place/person…) 중 일부만 맞으면 "반은 맞다"류 문장 + 부족한 측면 이름("시간이 비어 있다")을 준다. 무엇을 넣어야 하는지(어떤 앱)는 말하지 않는다.

## 3. 판정 엔진 규칙

```
판정(제출 카드들, 대상 판정 정의):
  for 각 허용 조합 set in 정의.sets:
     if set의 모든 요구 증거(또는 대체 증거 중 하나)가 제출 카드에 있고
        제출 카드들이 요구 측면(facets)을 갖고 있고
        strong 카드 수 ≥ 정의.minStrong:
          → 성공
  if 요구 증거 일부 포함:
     → 부분(부족한 facet 이름 반환)
  else → 실패(정의.miss 문장 중 하나)
```

- 제출 카드 중 관계없는 카드가 섞여 있어도 실패하지 않는다(과잉 제출 허용). 단 3장 상한.
- 카드의 `facets`는 플레이어가 정보(i)를 열고 붙였는지에 따라 다르다(10 문서 1절 3). **메타데이터를 안 본 카드는 시간 측면이 없다** → "시간이 비어 있다".

## 5. 특수 연출 — Q-04 "나다"

- 성공 순간 화면: 수첩이 넘어가 **첫 장**이 다시 펼쳐진다. 아버지의 손글씨 줄 맨 아래에 새 줄이 천천히 써진다: `- 한결캐피탈. 내 빚.`
- 다음 줄은 쓰다 멈춘다: `- 도현이가` (지운 자국)
- 효과음 없음, 독백 없음(P5). 이 장면 이후 수첩 **내 폰** 탭의 고정 문장에 하나가 추가된다: "한결 거 아빠가 알아" — 아직 보낼 수 없음(DH-3 단계 이후 가능, 12 문서).

## 6. 결론 (F) — 엔딩 직전 빈칸 채우기

수첩 마지막 장 "결론". 질문 Q-02·Q-03·Q-05 성공 후 열린다. 빈칸에 카드나 인물을 넣는다.

```
도현이는 [ 장소 ] 에 [ 스스로 / 누가 데려가서 ] 있다.
도현이를 쫓는 건 [ 인물 ] 이다.
도현이가 숨은 건 [ 이유 ] 때문이다.
도현이는 [ 시각 ] 에 [ 행동 ] 하려고 한다.
```

| 빈칸 | 정답 | 받는 것 |
|---|---|---|
| 장소 | 청운고시원(304) | Q-07 결과 카드 |
| 스스로/데려감 | 스스로 | 선택(두 단어 중) |
| 인물 | 강민석 | Q-06 인물 / "모름" 가능 |
| 이유 | **아버지(빚)·아버지의 안전** 또는 **실장의 위협** | 카드: E-60(위협) 또는 Q-04 결과(빚) — 둘 다 넣으면 "둘 다"(정답 등급 최고) |
| 시각·행동 | 3/18 09:00 자수 | Q-08 결과 |

- 결론은 **확정하지 않아도 엔딩에 갈 수 있다**(09:00 마감). 확정하면 그 시점에 마지막 행동 선택(12 문서 6절)으로 넘어간다.
- 결론 판정은 맞다/틀리다를 즉시 보여 주지 않는다(Obra Dinn식). 엔딩 결과로만 드러난다.
