# 07. SNS 수사 시스템 — 루프(Loop)

> 게임의 수사 축 중 가장 넓다. 원칙: **공개된 관계와 실제 상호작용은 다르다.** 플레이어는 게시물을 읽는 게 아니라 계정과 계정 사이의 흔적(누가, 언제, 어디서, 무엇에 반응했나)을 대조한다.

## 1. 루프의 기능 (가상 SNS)

| 기능 | 사양 | 수사적 쓰임 |
|---|---|---|
| 프로필 | 이름·소개·게시물·팔로워/팔로잉·하이라이트·**가입일**(프로필 → "계정 정보") | 급조 계정 판별 |
| 게시물 | 사진/글, 위치 태그, 사람 태그, 좋아요 수·목록, 댓글, **편집됨 표시 + 편집 기록** | 시각·장소·관계 |
| 스토리 | 24시간 노출. 위치·멘션 스티커. 본인 계정에서는 **보관함**에 영구 보관 + **조회자 목록** | 누가 지켜봤나 |
| 하이라이트 | 스토리를 묶어 프로필에 고정 | 타인의 지난 스토리 열람 경로 |
| 장소 페이지 | 위치 태그 장소별 공개 게시물 모음 | 같은 장소, 다른 사람 |
| 검색 | 계정 / 태그 / 장소. 온라인 필요 | 연결 시험 |
| DM | 대화, **초안**(보내지 않은 메시지), 공유 게시물 | 보내지 못한 말 |
| 활동 기록 | 내가 누른 좋아요(시각), 팔로우·언팔로우 이력(날짜), 검색 기록 | 새벽 3시의 좋아요 |
| 계정 전환 | 로그인 계정 목록 + "최근 로그인한 계정" | 부계정의 존재 |
| 친한 친구 | 본인 계정 설정. 목록 열람 가능 | 진짜 관계 |
| 보관 | 내 게시물 숨기기(본인만 열람) | 지우진 못한 것 |

## 6. 설계 규칙

1. 모든 계정은 **자기 계정의 논리대로** 산다. 사건과 무관한 게시물이 대부분(노이즈 70% 이상). 단서는 노이즈 속에 있다.
2. 시각은 루프 UI에서 상대 시각("3일 전")으로, 길게 눌러 정보에서 **절대 시각**으로 보인다. 플레이어가 정보를 열어야 한다.
3. 타인 계정의 비공개 정보(타인의 DM, 비공개 계정)는 볼 수 없다. 도현 계정으로 볼 수 있는 것만.
4. 좋아요·조회자 목록은 **순서가 시간순**이다(LUMA 루프 규칙). 목록 위치 자체가 시각 단서.
5. 이름 마스킹 규칙: 하린 글의 "이*현"은 이도현·이수현·이지현 모두 가능 → 계좌번호 4자리까지 맞춰야 I-04 성립(오판 방지).
