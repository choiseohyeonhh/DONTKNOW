## 5. 위치 추리 (Q-05, Q-07)

### Q-05 "3/14 밤 9시 도현은 어디 있었나" — 답: 리버뷰타워
- 경로 A: 택시 영수증(출발 21:05 리버뷰타워)
- 경로 B: 버스트 사진 메타(20:02 리버뷰 B2) + 음성 메모 시각(20:09~20:51)
- 경로 C: 지갑 하차 19:52 리버뷰역 + 건강 20:09~20:51 정지
- 판정: 두 경로 이상이면 성립.

### Q-07 "도현은 지금 어디 있나" — 답: 청운고시원 304호
- 필요한 구성 요소 3종 중 3종 모두:
  1. **장소 특정**(고시원이라는 것): 메일 입실 안내 / 지도 최근 검색 / 캘린더 3/1 / Wi-Fi CHEONGUN_3F / 최근 삭제 사진 중 하나
  2. **현재성**(지금 거기 있다는 것): 찾기 슬레이트 반경(성원구청역 일대) / 택시 하차 성원구청역 2번 출구 + 3/16 입실 예정 / 도현 메시지 속 단서(EV-16: "여기 와이파이 느려") 중 하나
  3. **호실**: 계약서 PDF "304" / 메일 본문 "304호"
- 구성 요소 1·2만 맞히면 판정은 "부분 성립": 수첩 "청운고시원. 몇 호인지는 모른다" → 엔딩 판정에서 위치 정확도 "근접"(12 문서). 엔딩 A는 정확도 "정확" 필요.
