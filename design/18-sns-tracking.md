# 18. SNS 추적 강화 (v6.1)

> 07 문서(루프 기본 기능)를 확장한다. v6.0에서 SNS는 "글 몇 개 읽기"였다. v6.1에서는 **계정을 따라가 사람과 조직을 찾아내는 추적**이 4장 전체를 이루는 필수 경로다.
> 원칙 셋: ① 계정은 사람이 아니다 — 같은 사람의 여러 계정, 여러 사람이 쓰는 계정을 플레이어가 구분한다. ② 플랫폼을 건넌다 — 루프·튜브·모아에 같은 사람이 다른 얼굴로 산다. ③ **상대도 지운다** — 실장은 경계하면 자기 흔적을 지운다. 읽는 순서가 전략이다.

## 1. SNS 수사 도구 (루프 신규 기능)
