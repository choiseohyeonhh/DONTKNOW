# 04. 핵심 게임플레이와 플레이 루프

## 1. 폐기하는 것

- **세션 레일(S1~S14)**, "대화 → 선택지 → 다음 세션"
- **KNOW 자동 지급**: 무엇을 봤는지가 아니라 **무엇을 증명했는지**로 진행한다
- 대면 장면, 길찾기 이동, 장소 일러스트 화면

## 2. 핵심 루프

```
     ┌────────────────────────────────────────────────────────┐
     ▼                                                        │
 [탐색] 앱을 열고, 검색하고, 메타데이터를 들춘다                     │
     │                                                        │
 [발견] 이상한 것: 시각이 안 맞는 사진, 모르는 계정, 숫자 메모          │
     │                                                        │
 [수집] 길게 눌러 "수첩에 붙이기" → 증거 카드                          │
     │                                                        │
 [연결] 수첩에서 카드 두 장을 잇는다: 모순 / 같은 사람 / 이 질문의 답       │
     │                                                        │
 [가설] 질문 칸에 카드를 넣는다 ("도현은 3/14 21시에 어디 있었나?")       │
     │                                                        │
 [검증] 게임이 판정: 맞으면 수첩에 아버지의 결론 한 줄 + 새 조사 경로      │
     │       틀리면 "시간이 안 맞는다" 같은 짧은 반박, 페널티 없음         │
     │                                                        │
 [새 정보] 새 검색어·새 접근 권한·NPC 반응·실시간 사건 ───────────────┘
```

**루프 한 바퀴 목표 시간:** 3~8분. 한 바퀴마다 최소 한 번 "앱 두 개를 오가는" 행동이 들어가야 한다(01 기둥 P1·P2).

### 2.1 무엇이 "진행"인가

진행은 세 가지 축으로만 일어난다. 셋 다 플레이어 행동의 결과다.

| 축 | 예 | 정의 문서 |
|---|---|---|
| **접근(Access)** | 잠금 해제, 온라인 연결, 은행 비밀번호, 부계정 로그인 | 12 `G-xx` |
| **증명(Proof)** | 수첩의 연결·질문 판정 성공 | 11 `C-xx` `I-xx` `Q-xx` |
| **사건(Event)** | 실시간 삭제, 도현의 메시지, 실장의 반응 — 플레이어 행동이 트리거 | 12 `EV-xx` |

> 컷신이나 시간 경과만으로 열리는 것은 없다. 예외는 09:00 예약 메일 발송(마감)뿐이다.

## 3. 접근 단계 (정보의 층)

정보는 "어디에 있느냐"로 층이 나뉜다. 이 층이 곧 이야기의 속도 조절 장치다. 자유 탐색이지만 층을 넘으려면 앞 층에서 무언가를 알아내야 한다.

| 층 | 이름 | 열리는 조건 | 볼 수 있는 것 |
|---|---|---|---|
| T0 | **잠금화면** | 시작 | 분실 모드 문구, 쌓인 알림 미리보기(3/15 03:58 이전), 응급정보, 위젯(캘린더·배터리), 카메라(새로 찍기만) |
| T1 | **기기 안** | 잠금 해제(G-01) | 오프라인 앱 전부: 사진(로컬), 메모, 캘린더, 음성 메모, 건강, 지갑, 설정(Wi-Fi 목록·중요 위치·기기 정보), 메시지·톡(로컬 캐시), 메일(캐시), 루프(캐시 피드) |
| T2 | **온라인** | 집 Wi-Fi 연결(G-02) | 동기화된 새 메시지, 루프 실시간(검색·타인 프로필·장소 페이지), 메일 서버, 찾기, 예약 메일 — **그리고 실시간 삭제가 시작된다** |
| T3 | **잠긴 금고** | 각각 별도 열쇠 | 은행(G-03), 부계정(G-04), 블링크 미열람 메시지(G-05), 사진 원본(G-07), 잠긴 메모(G-06) |
| T4 | **살아 있는 사람** | 도현이 말을 걸어옴 / 플레이어가 NPC에게 증거를 보냄 | 대화로 얻는 확인. 정답이 아니라 **반응**이다 |

## 4. 온라인/오프라인 딜레마 (v6 고유 시스템)

폰을 온라인에 두면 새 정보가 들어오지만, 도현과 실장에게 플레이어의 존재가 보이고 원격 삭제가 진행된다. 오프라인이면 안전하지만 반쪽만 볼 수 있다.

| 상태 | 얻는 것 | 잃는 것 |
|---|---|---|
| 오프라인(Wi-Fi 끔 / 비행기 모드) | 로컬 데이터 보존. 삭제 명령이 도착하지 않음. 게임 시계 정상 | 루프 검색·장소 페이지·타인 프로필, 메일 서버, 찾기, 메시지 송수신 |
| 온라인 | 위 전부 | 도현의 원격 삭제가 적용됨. 블링크 읽음이 실장에게 전송됨. 플레이어의 접속이 슬레이트에 보임 |

**보존 수단 (플레이어가 스스로 찾아야 함, 튜토리얼 없음):**
1. **스크린샷**(측면 버튼 조합 / 제어 센터 버튼) — 화면을 사진으로 남긴다. 단, 지워진 원본의 "메타데이터"는 스크린샷에 없다(스크린샷 자체의 시각만).
2. **수첩에 붙이기** — 카드는 아버지의 손글씨 사본이다. 원본이 지워져도 카드는 남는다. 단, **원본이 지워진 카드는 질문 판정에 "약한 증거"로만 쓰인다**(11 문서 4.3).
3. **비행기 모드** — 삭제 명령을 멈춘다(오프라인 동안만).
4. **시러스 ID 비밀번호 변경**(설정 → 시러스 ID → 암호 변경, 기기 비밀번호 필요) — 슬레이트가 로그아웃되어 삭제·원격 지우기가 영구히 멈춘다. **대가:** 도현은 "누군가 내 계정을 빼앗았다"고 확신하고 연락을 끊는다(12 문서 분기).
5. **도현에게 정체를 밝힘** — 도현이 삭제·원격 지우기를 멈춘다. 가장 어렵고 가장 좋은 해법.

### 4.1 위기 이벤트: "10분"

첫 온라인 후 도현이 보내는 메시지(EV-06): **"이 폰 가지고 있는 사람. 10분 안에 대답 없으면 원격으로 지웁니다."**

- 게임 내 시각으로 60분(실시간 10분). 화면에 타이머는 없다. 메시지의 수신 시각과 상태바 시계로 플레이어가 계산한다.
- 해법(어느 것이든 위기 해소, 결과는 다르다):

| 해법 | 결과 | 이후 |
|---|---|---|
| 답장: "누구세요" / 침묵 외의 대답 | 도현이 질문을 이어 간다(12 문서 대화 상태 DH-1) | 대화 진행 |
| 답장: "도현이 아빠다" | 도현이 믿지 않는다 → "아빠면 아빠 폰으로 톡 보내 봐"(DH-2). 수첩의 **내 폰** 탭에서 아버지 폰으로 톡을 보내면 도현의 슬레이트에 도착 → 지우기 취소 | 최선 |
| 비행기 모드 유지 | 지우기 명령이 대기열에 남음. 다시 온라인 되는 순간 실행 | 오프라인 플레이 강제. 남은 온라인 정보 포기 |
| 시러스 비밀번호 변경 | 지우기 취소, 도현 로그아웃 | 도현과의 직접 연락 경로 소실 → 엔딩 A 불가(C/D로) |
| 아무것도 안 함 | **원격 지우기 실행.** 폰 초기화 연출 → 수첩만 남는다 | 이후 수첩 카드만으로 진행. 엔딩 A 불가, 녹음을 미리 보존하지 않았다면 D |

> **원격 지우기는 게임 오버가 아니다.** 수첩이 남는다. 이건 "지우기 전에 붙잡아라"는 주제의 가장 강한 플레이 형태다. 단, 엔딩이 제한된다.

## 5. 시간

| 항목 | 규칙 |
|---|---|
| 시작 | 3/17(화) 21:10 |
| 흐름 | 폰 화면을 보고 있을 때 실시간 1분 = 게임 6분. **수첩을 열면 멈춘다**("생각하는 시간") |
| 마감 | 3/18(수) 09:00 예약 메일 발송 → 엔딩 판정 시작 |
| 조기 결말 | 플레이어가 수첩 "결론"을 확정하고 행동을 고르면 그 시각에 엔딩으로 간다 |
| 옵션 | 접근성 설정 "시간 흐름 끄기": 시계가 행동 단위로만 움직인다(앱 전환 1회 = 1분) |
| 상태바 | 실제 시계를 표시. 시간 단서(사진 시각, 메시지 시각)와 같은 형식 |

**본편 페이싱 목표:** 실시간 약 120분 = 게임 12시간. 수첩 체류 시간은 시계에서 빠지므로 생각하는 플레이어가 손해 보지 않는다.

## 6. NPC와 연락하기 (제한된 대화)

- 연락 수단: 톡(지훈·서아·아버지 자신에게도), 루프 DM(하린·서아·사칭 계정), 메일(김태윤·고시원), 메시지(도현의 슬레이트, 후반), 블링크(실장).
- **모두 온라인에서만.** 회선은 정지 상태라 전화는 톡 음성통화만 가능.
- 보낼 수 있는 것:
  1. **기본 문장 4개:** "누구세요" / "아저씨다"(지훈·서아용) / "도현이 아빠입니다"(그 외) / "이거 뭐냐"(카드와 함께)
  2. **증거 카드**(수첩에서 첨부) — 상대에 따라 반응이 다르다. 반응표는 12 문서 5절.
- **대화는 정보 공급원이 아니다.** NPC는 플레이어가 이미 증명한 것을 확인해 주거나, 다음에 볼 곳의 방향을 줄 뿐이다. 새로운 사실을 통째로 주지 않는다(P1).
- **정체 공개:** 첫 메시지에 "아저씨다/도현이 아빠입니다"를 보내지 않으면, 상대는 도현이 보낸 줄 안다. 이걸 이용할 수도 있지만(서아는 도현인 줄 알면 더 말한다) 대가가 있다(사칭 계정에게 도현인 척하면 실장이 위치를 떠본다 → 위험).

## 7. 막힘 방지

| 장치 | 규칙 |
|---|---|
| **이중 경로(P4)** | 필수 질문 Q-01~Q-07은 각각 서로 다른 앱 2개 이상의 증거 조합으로 답할 수 있다(11 문서 판정표) |
| **아버지의 혼잣말 힌트** | 같은 질문에 진전이 없으면 수첩 여백에 아버지 메모가 생긴다. 3단계: ① 방향("택시는 어디서 탔을까") ② 앱("영수증 같은 건 메일로 오지 않나") ③ 위치("메일 받은편지함, 3월 14일 밤") |
| 힌트 타이밍 | 마지막 판정 성공 후 게임 내 90분(실시간 15분) 무진전 시 ①, 이후 60분마다 다음 단계 |
| 검색 | 어떤 앱에서든 위로 끌어 **검색**: 플레이어가 입력한 단어로 폰 전체 검색(이름·번호·장소·금액). 수첩 카드에서 단어를 길게 눌러 검색으로 보낼 수 있다 |
| 오답 | 페널티 없음. 같은 오답 3회 시 힌트 ① 즉시 |

## 8. 실패와 엔딩

- 게임 오버 없음. 원격 지우기, 위치 유출, 마감 경과 모두 **엔딩 분기 조건**이다.
- 엔딩 판정은 12 문서 6절. 엔딩 후 "다시 보기"에서 놓친 증거 수와 질문 판정 결과를 보여 준다(정답 공개는 하지 않음 — 2회차 동기).

## 9. 한 판의 예시 흐름 (설계 검증용 서사)

1. 21:10 폰이 켜진다. 분실 모드 문구에 지훈 번호. 알림 미리보기: 은행 "…지급정지…", 경찰 "[성원경찰서] 이도현님…", 지훈 "야 비번 아직도 아빠 생일이면 바꿔라 ㅋㅋ".
2. 인수증의 아버지 생일 → 680403. 잠금 해제. 수첩: "내 생일이었다."
3. 사진첩·메모·메일을 뒤진다. 택시 영수증 메일: 3/14 21:05 리버뷰타워 → 성원구청역. 수첩 Q-01 판정 → "폰은 택시에 두고 내린 거다. 누가 뺏은 게 아니다."
4. 설정에서 Wi-Fi를 켠다 → 집 Wi-Fi 자동 연결 → 알림 폭포(내가 보낸 톡 6통이 읽지 않음으로). 그 사이 메모 하나가 사라진다(EV-04).
5. 3분 뒤 메시지: "10분 안에 대답 없으면…" 플레이어는 비행기 모드를 켤지, 답할지 고민한다.
6. "도현이 아빠다" → 도현은 믿지 않는다. 폰을 가진 사람은 누구든 그렇게 말할 수 있다. **"아빠면 아빠 폰으로 나한테 톡 보내 봐."** → 플레이어는 수첩의 **내 폰** 탭(아버지 자기 폰, 기능은 톡 보내기 하나)을 처음 쓴다 → 아들 폰 톡에 "이상철: 아빠다" 가 도착(다중기기 동기화) → 도현: "…지우는 거 멈출게. 근데 나 찾지 마."
   - 이 장면은 "두 번째 경로로 신원을 확인한다"는 2단계 인증의 원리를 그대로 이야기로 만든 것이다.
   - 덧붙여 플레이어는 여기서 하나를 눈치챌 수 있다: 아버지가 3/14~3/17에 보낸 톡 6통이 **아직도 읽지 않음**이다. 슬레이트에서도 같은 톡이 보였을 텐데, 도현은 열지 않았다. 아들도 "모르고 싶었다".
7. 이후 서아 거짓말, 지훈 DM, 하린 글, 은행, 한결… 순서는 플레이어 마음대로.
