### 2.8 남은 열린 문제
1. ×4 시계의 체감은 플레이테스트 전엔 확정 불가(17 문서 6절).
2. 보수 97분은 합격선 대비 여유 8%뿐. 숙련 테스터 실측이 가장 먼저 필요하다.
3. 직접 입력 낱말 사전의 커버리지(조사·오타). P2에서 실제 입력 로그로 보강.
4. 반응 대화 분량: NPC 7명 × 상태 × 입력 조합. 기본 반응으로 덮이는 비율이 30%를 넘으면 "말이 안 통한다"는 체감 → 콘텐츠 단계에서 상위 입력 빈도 기준으로 채운다.
