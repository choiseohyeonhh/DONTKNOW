# ERROR_HANDLING — 게임 오류와 "오류처럼 보이는 연출"의 구분

> **역할:** 콘텐츠 로드 실패, 세이브 손상·버전 불일치, localStorage 불가·용량 초과, 알 수 없는 입력, 자산 누락, 렌더 예외의 처리 정책과 화면 문구를 고정한다. 게임 속 "오류처럼 보이는" 연출(서비스 없음·원격 삭제·원격 지우기)과 실제 오류를 구분하는 규칙을 정한다.
> **단일 출처:** 이 문서(오류 코드·화면 문구·복구 정책·연출 구분). 세이브 스키마·마이그레이션은 [DATABASE_SCHEMA](../04-tech/DATABASE_SCHEMA.md) 4절, 상태 저장 시점은 [STATE_MANAGEMENT](../04-tech/STATE_MANAGEMENT.md) 6절, 게임 내 시스템 문구는 [SYSTEM_SHELL_SPECIFICATION](../03-features/SYSTEM_SHELL_SPECIFICATION.md)이 단일 출처다.
> **참조:** [SYSTEM_ARCHITECTURE](../04-tech/SYSTEM_ARCHITECTURE.md) 4절, [MAIL_AND_CLOUD_SPECIFICATION](../03-features/MAIL_AND_CLOUD_SPECIFICATION.md), [TRACES_AND_REACTIONS](../01-product/TRACES_AND_REACTIONS.md), [API_SPECIFICATION](../04-tech/API_SPECIFICATION.md) 7절.
> **적용 버전:** v6.2 (2026-11).

## 1. 원칙

1. **플레이를 멈추지 않는다.** 복구 가능한 오류는 현재 화면만 다시 열고 진행은 보존한다.
2. **원시 오류를 보여 주지 않는다.** 스택 트레이스·콘솔 메시지·영문 예외를 플레이어에게 노출하지 않는다.
3. **연출과 오류를 섞지 않는다.** 게임 속 "서비스 없음"·"삭제됨"은 오류가 아니다. 실제 오류는 다른 화면 문법을 쓴다.
4. **세이브를 먼저 지키고, 그다음 복구한다.** 손상 가능성이 있으면 덮어쓰기 전에 백업한다.
5. **외부로 보내지 않는다.** 오류 로그는 메모리·로컬에만. 네트워크 전송 없음.
6. **오류도 재현 가능해야 한다.** 오류 코드·컨텍스트를 남겨 디버그 패널에서 확인한다.

## 2. 오류 코드

| 코드 | 상황 | 심각도 | 플레이 지속 | 사용자 노출 |
|---|---|---|---|---|
| `E-CONTENT` | `window.__CONTENT__` 없음·스키마 실패 | 치명 | 불가 | 전체 화면 |
| `E-SAVE-CORRUPT` | 세이브 JSON 파손·체크섬 불일치 | 높음 | 가능(복구) | 시트 |
| `E-SAVE-VERSION` | 세이브 스키마가 미래 버전 | 높음 | 불가(해당 세이브) | 시트 |
| `E-SAVE-MIGRATE` | 과거 세이브 마이그레이션 실패 | 높음 | 가능(백업) | 시트 |
| `E-SAVE-UNAVAILABLE` | localStorage 접근 불가(프라이빗·차단) | 높음 | 가능(메모리) | 시트 |
| `E-SAVE-QUOTA` | 용량 초과 | 중간 | 가능(저장 제한) | 시트 |
| `E-SAVE-WRITE` | 저장 쓰기 실패(기타) | 중간 | 가능 | 토스트 |
| `E-STATE` | 상태 커밋·직렬화 실패 | 중간 | 가능(롤백) | 토스트 |
| `E-RENDER` | 렌더·morph 예외 | 중간 | 가능(화면 재시도) | 토스트/시트 |
| `E-ASSET` | 자산 키 누락·디코딩 실패 | 낮음 | 가능(플레이스홀더) | 없음(디버그만) |
| `E-CLOCK` | 시계 역행·비정상 | 낮음 | 가능 | 없음(디버그만) |
| `E-TEST` | 테스트 훅 오용 | 낮음 | 가능 | 없음(디버그만) |
| — | 알 수 없는 입력 | 오류 아님 | 가능 | 없음(기본 반응) |

## 3. 오류별 정책과 화면 문구

### 3.1 `E-CONTENT` — 콘텐츠 로드 실패

- **감지:** `hydrateContent()`가 `window.__CONTENT__` 부재·필수 배열 누락·ID 중복·스키마 실패를 반환.
- **행동:** 게임을 시작하지 않는다. 저장을 건드리지 않는다.
- **화면(전체):**

```text
폰을 켤 수 없습니다.
잠시 후 다시 시도해 주세요.

[다시 시도]
```

- 재시도는 페이지 리로드 1회. 같은 오류면:

```text
폰을 켤 수 없습니다.
이 게임을 다시 열어 주세요.
```

- **복구:** 빌드 산출물 교체. 디버그 모드에서 `__errors.last()`에 원인 표시.
- **금지:** 빈 홈 화면을 보여 주거나 일부 앱만 열어 주지 않는다.

### 3.2 `E-SAVE-CORRUPT` — 세이브 손상

- **감지:** `JSON.parse` 실패, 필수 키 누락, 체크섬 불일치.
- **행동:** 손상 세이브를 `dontknow.v6.backup.<epoch>`에 복사. 자동 저장 → 슬롯 1→2→3 순으로 복구 시도.
- **화면(시트):**

```text
저장된 진행을 읽지 못했습니다.
자동 저장을 복구했습니다.
```

- 모든 슬롯이 손상이면:

```text
저장된 진행을 읽지 못했습니다.
새로 시작할 수 있습니다. 기존 저장은 백업해 두었습니다.

[새로 시작] [닫기]
```

- **복구:** 새 게임. 이전 저장은 백업 키에 남는다(용량 허용 시).
- **금지:** 손상 세이브를 자동으로 덮어쓰지 않는다. 백업 없이 삭제하지 않는다.

### 3.3 `E-SAVE-VERSION` — 버전 불일치

| 상황 | 행동 | 화면 |
|---|---|---|
| 세이브 `schemaVersion` > 현재 | 읽지 않는다. 백업. | `이 저장은 최신 버전에서 만들어졌습니다. 이 버전에서는 열 수 없습니다.` |
| 세이브 `schemaVersion` < 현재 | 마이그레이션 체인 실행 | 성공: 조용히 진행. 실패: `E-SAVE-MIGRATE` |
| `contentVersion` 불일치 | 항목 ID 유효성 검사. 없는 ID는 버린다 | 경고 로그만. 화면 문구 없음(진행 지속) |
| `appVersion` 불일치 | 마이그레이션·검증 | 위와 같음 |

- 미래 버전 화면:

```text
이 저장은 최신 버전에서 만들어졌습니다.
이 버전에서는 열 수 없습니다.

[새로 시작] [닫기]
```

- **금지:** 미래 버전 세이브를 억지로 읽어 상태를 깨뜨리지 않는다.

### 3.4 `E-SAVE-MIGRATE` — 마이그레이션 실패

- **행동:** 원본 백업. 이전 슬롯으로 복구 시도. 모두 실패하면 새 게임 제안.
- **화면:**

```text
저장을 업데이트하지 못했습니다.
이전 저장을 백업해 두었습니다.

[이전 저장 불러오기] [새로 시작]
```

- **기록:** 어떤 단계에서 실패했는지 `context.fromVersion`·`toVersion`.

### 3.5 `E-SAVE-UNAVAILABLE` — localStorage 불가

- **감지:** `localStorage` 접근이 예외를 던지거나 `setItem`이 즉시 실패.
- **행동:** 메모리 저장으로 전환. 게임은 계속. 자동 저장·슬롯 비활성.
- **화면(시트, 최초 1회):**

```text
이 브라우저에서는 진행을 저장할 수 없습니다.
창을 닫으면 진행이 사라집니다.

[계속] [새로 시작]
```

- **복구:** 일반 브라우저 창·시크릿 아님·저장 공간 허용 안내. 페이지 새로고침 시 진행 소실 경고.
- **금지:** 저장 실패를 게임 속 "동기화 실패" 연출로 바꾸지 않는다.

### 3.6 `E-SAVE-QUOTA` — 용량 초과

- **감지:** `QuotaExceededError` 또는 저장 크기 > 2MB.
- **행동 순서:**
  1. 오래된 백업 키 삭제(최근 1개만 유지).
  2. `log`를 최근 100개로 축소.
  3. 미디어 썸네일 캐시(저장 대상 아님) 정리.
  4. 다시 저장.
  5. 실패하면 자동 저장 중지, 수동 슬롯만 허용.
- **화면:**

```text
저장 공간이 부족합니다.
오래된 기록을 정리하고 다시 저장했습니다.
```

- 5단계까지 실패:

```text
저장 공간이 부족합니다.
이번 진행은 자동으로 저장되지 않습니다.
```

- **금지:** 사용자 확인 없이 수동 슬롯을 삭제하지 않는다.

### 3.7 `E-SAVE-WRITE` — 기타 저장 실패

- **행동:** 1회 재시도. 실패 시 토스트.
- **화면(토스트):** `진행을 저장하지 못했습니다.`
- **복구:** 다음 자동 저장 시점에 재시도. `__errors`에 기록.

### 3.8 `E-STATE` — 상태 커밋 실패

- **감지:** 커밋 중 예외, 직렬화 불가 값, 정의되지 않은 키.
- **행동:** 커밋 롤백. 상태는 이전 값 유지. 게임 계속.
- **화면(토스트):** `진행을 저장하지 못했습니다. 현재 화면은 계속 사용할 수 있습니다.`
- **디버그:** 어떤 경로에서 실패했는지 `context.path`.

### 3.9 `E-RENDER` — 렌더 예외

- **감지:** 화면 렌더 함수·`morph` 예외.
- **행동:** 현재 화면만 `setHtmlOnce`로 재시도. 1회 실패 시 셸로 복귀.
- **화면(토스트):** `화면을 다시 불러왔습니다.`
- 반복 실패:

```text
화면을 열 수 없습니다.
잠시 후 다시 시도해 주세요.

[다시 시도] [홈으로]
```

- **금지:** 흰 화면·빈 화면을 방치하지 않는다.

### 3.10 `E-ASSET` — 자산 누락·디코딩 실패

- **행동:** 플레이스홀더(`--lm-bg-tertiary`) + `alt` 텍스트. 레이아웃 유지. 진행 계속.
- **화면 문구:** 없음. 디버그 패널에만 표시.
- **복구:** 빌드 재실행. 자산 참조 린터(L16)가 사전에 막는다.

### 3.11 `E-CLOCK` — 시계 비정상

- **감지:** `gameMin` 감소, NaN, 음수 누적.
- **행동:** 마지막 정상 값으로 복구. `paused` 유지. 디버그 로그.
- **화면 문구:** 없음. 게임 속 시계는 계속 표시.

### 3.12 알 수 없는 입력 — 오류가 아니다

- **정의:** 사전에 없는 직접 입력, 정의되지 않은 추천 문장, 매칭되지 않는 공유.
- **행동:** 인물별 기본 반응. 페널티·오류 문구 없음([12](../01-product/PROGRESSION_AND_ENDINGS.md) 5절).
- **예:** `"무슨 말이에요?"`, `"아빠 그게 뭐야"`, `"그거 왜 봐요"`.
- **금지:** "인식할 수 없습니다", "다시 입력하세요" 같은 시스템 문구를 띄우지 않는다.

## 4. 게임 속 "오류처럼 보이는" 연출 vs 실제 오류

### 4.1 구분 규칙

| 구분 | 게임 연출(픽션) | 실제 오류 |
|---|---|---|
| 소유자 | 게임 세계(앱·시스템) | 게임 엔진 |
| 문구 출처 | 콘텐츠 JSON·캐논 | 이 문서 |
| 화면 문법 | 앱 크롬·상태바·알림·시스템 문구 | 중립 시스템 시트·토스트 |
| 버튼 | 세계 안 행동(확인·닫기·다시 시도 없음) | `다시 시도`·`확인`·`홈으로` |
| 진행 영향 | 이야기 상태를 바꾼다 | 진행을 보존한다 |
| 오류 코드 | 없음 | `E-*` (디버그에만) |
| 예 | "서비스 없음", "1개 항목이 다른 기기에서 삭제됨", "지우는 중…" | `E-SAVE-QUOTA`, `E-RENDER` |

### 4.2 대표 연출

| 연출 | 화면 | 실제 의미 | 오류 아님 |
|---|---|---|---|
| **서비스 없음** | 상태바 회선 | 분실 정지. 전화·문자 불가([05](../03-features/SYSTEM_SHELL_SPECIFICATION.md)) | 재시도 버튼 없음. Wi-Fi로 우회 |
| **동기화 삭제** | "1개 항목이 다른 기기에서 삭제됨" 3초 + 행 0.4초 페이드 | 원격 삭제 적용([05](../03-features/SYSTEM_SHELL_SPECIFICATION.md)) | 사라진 것이 정상 |
| **원격 지우기** | 흰 화면 + "지우는 중…" 8초 → "안녕하세요" 1분 | EV-08. 초기 설정 화면 1분 뒤 엔딩 판정([09](../03-features/MAIL_AND_CLOUD_SPECIFICATION.md)) | 취소·재시도 없음 |
| **블링크 캡처 알림** | "상대방이 화면을 캡처했습니다" | TR-06 게임 규칙 | 실제 감지 아님 |
| **앱 잠김** | 잠금 화면·암호 입력 | 게이트 G-xx | 오류 아님 |
| **빈 화면** | "메시지가 없습니다" | 콘텐츠 상태 | 오류 아님 |
| **발신 실패** | "전송 실패" 말풍선 | 오프라인 등 게임 규칙 | 실제 네트워크 오류 아님 |

### 4.3 우선순위

- 실제 오류가 게임 연출과 동시에 발생하면 **실제 오류를 먼저 알린다.** 단, 이야기 상태(엔딩·삭제·흔적)는 이미 커밋된 것을 되돌리지 않는다.
- 실제 오류 문구에는 앱 이름·캐논 숫자를 넣지 않는다. 예: "블링크 오류" 금지. "화면을 열 수 없습니다" 허용.
- 게임 연출 문구에는 `E-*` 코드를 넣지 않는다.

## 6. 오류 로그

```js
window.__errors = {
  list(): ErrorEntry[],
  last(): ErrorEntry | null,
  clear(): void
};
```

```json
{
  "code": "E-SAVE-QUOTA",
  "message": "저장 공간이 부족합니다.",
  "at": "2026-11-08T10:31:00.000Z",
  "gameMin": 128,
  "context": { "slot": "auto", "bytes": 524288, "prunedLogs": 400 },
  "recoverable": true
}
```

| 규칙 | 내용 |
|---|---|
| 버퍼 | 최근 50개. 메모리만 |
| 전송 | 없음 |
| 화면 | 일반 모드에서는 숨김. `?debug=1` 패널에 표시 |
| 저장 | 세이브에 오류 로그를 넣지 않는다 |
| 개인정보 | 없음. 플레이어 입력 원문을 넣지 않는다(길이·해시만) |

## 7. 개발자 행동

- 새 오류 경로를 만들면 이 문서에 코드·문구·복구를 추가한다.
- 오류 화면 문구를 코드에 하드코딩하지 않는다. 이 문서의 문구를 `content` 또는 오류 모듈 상수로 둔다(오류는 예외적으로 코드 상수 허용).
- 테스트: `crisis.js`에서 저장 손상·용량 초과·localStorage 불가를 강제로 재현한다.
- 배포 전 `__errors`가 비어 있는지 확인한다(정상 플레이 1회).

## 확인 사항

- `Q-OPEN-Q07`: 실제 오류 화면을 게임 세계의 LUMA 시스템 UI로 보여 줄지, 중립 시트로 보여 줄지 이 문서는 "중립 시트"로 정했다. 완전 몰입을 위해 LUMA 시스템처럼 보이게 하는 대안이 있으나, 픽션과 혼동될 수 있어 추천하지 않는다.
- `Q-OPEN-Q08`: `E-SAVE-UNAVAILABLE`에서 "계속"을 선택한 뒤 새로고침하면 진행이 사라진다. 이때 이탈 방지 경고(`beforeunload`)를 쓸지 결정이 필요하다. 이 문서는 "경고 문구 1회"만 하고 브라우저 경고는 쓰지 않는다.
- `Q-OPEN-Q09`: localStorage 백업을 몇 개까지 유지할지(기본 1개)는 용량 정책과 함께 확정해야 한다.
- 외부 오류 제보 채널은 두지 않는다. 필요하면 배포 페이지에 정적 안내만 둔다(Q-OPEN-032 결정).
