## 4. NPC 상태와 반응표

**공통 데이터 규칙:** 반응은 `(인물, 상태, 입력)` → `응답 묶음 + 상태 변화 + 생성 단서`. 입력은 추천 문장 ID / 공유된 단서 ID / 사전 낱말(11 문서 3절) / 흔적 ID. 정의되지 않은 입력에는 인물별 기본 반응. 응답은 03 문서 앎 매트릭스를 어길 수 없다.

### 4.1 도현 (DH)

| 상태 | 진입 | 도현의 행동 | 플레이어가 할 수 있는 것 |
|---|---|---|---|
| DH-0 모름 | 시작 | 없음 | — |
| DH-1 의심 | EV-03 | EV-04~09 진행, 경계 0에서 시작 | 답장, 공유 |
| DH-2 대화 | 도현 메시지에 답장 | 삭제·지우기 일시 정지. "누구세요?" → "아빠다" 계열엔 **"아빠면 지금 내 방 사진 찍어 보내. 책상 서랍 열고."** | 카메라 → 서랍 사진 전송(V-04) |
| DH-3 확인 | V-04 | 삭제·지우기 **취소.** 도현이 아빠 톡방을 연다 → 6통의 "1"이 한꺼번에 사라진다. 잠시 뒤 "…지우는 거 멈출게. 근데 나 찾지 마. 내일 다 끝나" | 공유하면 짧게 답함(녹음·실장·서아) |
| DH-4 열림 | DH-3 + V-13 | "…언제부터 알았어" / "녹음 폰에 있어. 그거 있으면 그 사람 잡혀" / EV-16 | 위치 공유 요청 수락(EV-33) |
| DH-X 단절 | 시러스 암호 변경·기기 제거 / 슬레이트 지우기 / 경계 ≥ 3(DH-1·2) | 연락 끊음. 경계 3이면 즉시 EV-08 | 없음 |

- **경계:** DH-1·2에서만 누적. TR-10 +1, TR-12 +1, EV-14 +1(DH-1), TR-11 +1, EV-18 +2, EV-27 +2, 도현인 척 지훈·서아에게 메시지(그들이 도현에게 알림) +1, 은행 화면 스크린샷 동기화 +1. **방 사진 동기화 −1**, EV-30 이후 −1.
- **F-MOVED(도주):** DH≤2에서 해담·207·성원구청로 31을 도현에게 입력하거나 EV-27이 일어나면, 도현은 게임 60분 뒤 **성원스파(24시 찜질방, 성원구청역 1번 출구)**로 옮긴다. 이후 한끼 07:10 주문(EV-26)의 배송지가 성원스파로 바뀌고, 스크린 타임·지도(슬레이트) 기록도 갱신된다 → 두 번째 기회. 이때 택시 도착지는 "성원스파", 호실 입력 대신 "카운터"(최종 장면에서 자동).
- **도현의 대답 원칙:** 위치를 끝까지 직접 말하지 않는다. "와이파이 느려"(E-91)까지.

**도현 반응표(발췌, 전체는 콘텐츠 데이터):**
