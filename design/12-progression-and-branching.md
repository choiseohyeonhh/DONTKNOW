## 4. NPC 상태

### 4.1 도현 (DH) — 핵심 상태 기계

| 상태 | 진입 | 도현의 행동 | 플레이어가 보낼 수 있는 것 |
|---|---|---|---|
| DH-0 모름 | 시작 | 없음(폰이 오프라인) | — |
| DH-1 의심 | EV-03 | EV-04~09 진행. 경계 0에서 시작 | 기본 문장, 카드 |
| DH-2 대화 | 플레이어가 도현 메시지에 답장 | 삭제·지우기 일시 정지. "누구세요" → 응답에 따라 | "도현이 아빠다" → 도현: "아빠면 아빠 폰으로 톡 보내 봐" → 수첩 **내 폰** 탭 열림 |
| DH-3 확인 | 내 폰에서 톡 보냄 | 삭제·지우기 **취소.** 도현이 슬레이트에서 아빠 톡방을 연다 → 이 폰의 아빠 톡방에서 3/14부터 쌓인 톡 7통의 "1"이 **한꺼번에 사라진다**(읽음). 대사 없이 이 화면이 먼저 오고, 잠시 뒤 "…나 찾지 마. 내일 다 끝나" | 카드 보내기 가능. 도현은 녹음·실장 질문에 짧게 답함 |
| DH-4 열림 | DH-3 + **F-DEBT-SEEN** + 내 폰 문장 "한결 거 아빠가 알아" 보냄 | 도현 무너짐: "…언제부터 알았어" / "녹음 폰에 있어. 그거 있으면 그 사람 잡혀" / EV-16 | 마지막 행동 "지금 갈게" 가능 |
| DH-X 단절 | 시러스 암호 변경 / 슬레이트 지우기 / 경계 ≥ 3(DH-1·2에서) | 연락 끊음. 경계 3이면 즉시 EV-08 발동 | 없음 |

- **경계:** DH-1·DH-2에서만 누적. EV-10 +1, EV-14 +1(DH-1일 때), EV-15 +1, EV-18 +2, 사칭 계정처럼 도현인 척 서아·지훈에게 메시지(그들이 도현에게 알림) +1.
- **"아빠" 의심 경로:** EV-19. 플레이어가 그때 "어"/"아빠다"로 답하면 DH-2를 건너뛰고 증명 요구로 간다.
- **도현의 대답 원칙:** 03 문서 앎 매트릭스. 도현은 자기 위치를 끝까지 직접 말하지 않는다(엔딩 A도 아버지가 **찾아내야** 한다). E-91이 마지막 현재성 단서.

## 5. NPC 대화 데이터 규칙

- 대화는 `(인물, 상태, 보낸 것)` → `응답 묶음 + 상태 변화 + 생성 카드` 표다. 보낸 것은 기본 문장 ID 또는 증거 ID.
- 정의되지 않은 카드를 보내면 인물별 기본 응답(지훈 "그게 뭔데요?", 서아 "…이게 뭐예요?", 도현 "그거 왜 봐").
- 응답은 03 문서 앎 매트릭스를 어길 수 없다. 응답이 새 사실을 통째로 주지 않는다 — 방향만(04 문서 6절).
