## 2. 플레이어에게 전달되는 형태

### 2.1 S3 담임 문자 (EV.S03.02, KX-01)

```
아버님, 말씀드린 결석 날짜입니다.
4/8 4/22 4/29
5/13 5/27
6/10 6/24
7/8 7/15
8/19 8/26
9/9 9/23
10/14 10/28
11/4 11/18
12/2 12/16
전부 병결로 처리됐습니다.
```

- 요일을 쓰지 않는다. 담임은 "전부 화요일"이라는 걸 의식하지 못했다(알았다면 의심했을 것).
- 메시지 앱에서 다시 열 수 있다(S9 대조용).

### 2.2 S9 최 약사

- "늘 화요일 낮이었어요. 평일 대낮에 교복 입은 애가 오니까 기억이 나요." (`narrative/characters/pharmacist.md`)
- 화요일이라는 말을 들은 뒤 플레이어가 담임 문자를 다시 열면 → KX-12 → 독백 MO.06 "…같은 날이다."
- 플레이어가 날짜의 요일을 직접 계산하지 않아도 되도록, 메시지 앱의 날짜 길게 누르기 → "2025년 4월 8일 화요일" 팝업(실제 폰의 날짜 인식 기능 흉내). [설계] 이 기능은 이 문자에서만이 아니라 모든 메시지 날짜 문자열에 범용으로 둔다(특정 단서만 하이라이트하지 않기 위해).

### 2.3 선택지 (S9)

- `KX-01 && active(S09)`: 아버지 선택지 "늘 화요일이었다고요?" → 약사 "…네. 늘요." → KX-12 (문자 재열람 없이도 얻는 경로).
