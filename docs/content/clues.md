## 2. 실물 아이템 연출 규칙

| 규칙 | 내용 |
|---|---|
| 획득 표시 | 없음. "획득했습니다" 토스트 금지 |
| 상호작용 | 장면 화면에서 오브젝트 탭 → 확대 뷰(일러스트 1장) → 닫기 |
| 확대 뷰 | 영수증·포스트잇·쪽지는 손에 든 1인칭 시점. 손은 아버지의 손(50대, 굵은 마디) |
| 재열람 | 실물은 재열람 불가. 필요한 건 폰에 흔적이 남게 설계(영수증 → 사진 자동 저장) |

## 3. 영수증 상세 `IT.receipt`

| 항목 | 표시 |
|---|---|
| 상호 | 새봄약국 |
| 주소 | 성원시 ○○로 1XX (일부 찢김) |
| 일자 | 2026-03-03 (화) |
| 금액 | 보임(일반적인 약제비 수준) |
| 품목·처방 정보 | **찢겨서 없음**(콘텐츠 가이드라인) |
| 환자명 | 찢김 |

- 일자 3/3(화): 도현이 손 떼기 직전까지 루트가 돌았다는 흔적. 도현이 입학한 다음 날 화요일. 도현은 이날 대학 수업이 있었다 → 이날은 도현이 동행하지 않았다(준호 혼자?). [결정 필요] 이 날짜가 "J 혼자 보내지 말 것"과 충돌하는 의미를 만든다 — 도현이 처음으로 준호를 혼자 보낸 날. 추천: 유지하되 아무도 설명하지 않는다(발견하는 플레이어만 아프다). 반대라면 날짜를 2026-02-24(화)로.

## 4. 사진 자동 저장(영수증)

- S8에서 영수증을 확대한 뒤 닫으면 아버지가 폰으로 찍는 셔터음 + `PH.f.receipt_saebom`이 사진첩에 추가. 이유: 실물은 사라지고 플레이어가 약국 이름을 다시 볼 곳이 필요(5.6 300초 독백 "약국 이름이 뭐였지"와 연결).
- 이 촬영은 S11 카메라 기능(`ui/father-phone/camera.md`)과 같은 연출 언어 — 아버지는 중요한 걸 "찍어 둔다"(채무조정 서류도 그랬다). 찍고 보지 않는 습관이 S8에서는 보는 쪽으로 바뀐다.
