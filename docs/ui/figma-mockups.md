## 컴포넌트
`알림 카드/아버지폰`, `말풍선/수신(아버지폰)`, `선택지 버튼` (파일 하단 "재사용 컴포넌트" 영역).

## 한계
- 디자인 변수(토큰)는 만들지 않았다. 색은 `visual-style.md` 2장 값을 직접 썼다. 구현 단계에서 변수로 올린다.
- 01은 알림 카드 2개만 둔다(3개면 가족 얼굴을 가린다). 지훈 문자는 10초 뒤 도착하는 별도 알림으로 처리.
- 03의 인터폰은 `scene_entrance_in_b` 이미지 일부라 우측에서 잘려 있다. 실제 구현에서는 `ART.scene.intercom` 프레임을 별도로 얹는다.
- 02 하단 입력창은 문장이 두 줄로 줄바꿈된다(마지막 수정은 육안 확인 전).
