# 전화 앱

> 근거: bible 5.1(부재중 47의 원천), 10.2, 7장 각 통화 세션.

## 1. 탭 구성

| 탭 | 내용 | 기본 진입 |
|---|---|---|
| 최근기록 | 수신·발신·부재중 통합, 최신순 | 부재중 배지 > 0이면 이 탭 |
| 연락처 | 연락처 앱과 동일 목록(바로가기) | 배지 0이면 이 탭(아버지 습관 — `narrative/characters/father.md` 2장) |
| 키패드 | 숫자 패드 | 직접 입력 발신(112, 알게 된 번호) |

## 2. 최근기록 행

```
[↙ 빨강] 010-XXXX-5521          11월 12일 >
[↙ 빨강] 정지훈(도현친구) (2)    3월 15일 >
[↗]      도현                     3월 15일 >
```

| 요소 | 규칙 |
|---|---|
| 아이콘 | 부재중 ↙(빨강 글자), 수신 ↙(검정), 발신 ↗ |
| 이름 | 저장명 > 알게 된 번호 라벨 > 번호 |
| 묶음 | 같은 번호 연속 → `(n)` |
| 미확인 | 미확인 부재중 행은 이름이 빨강 + 굵게. 확인 후 일반 빨강 |
| 우측 `>` | 상세 열기 = 그 번호 부재중 "확인"(배지 감소) |

## 3. 상세 화면

- 번호, 저장명, 그 번호와의 통화 이력(일시·방향·길이).
- 버튼: [전화] [문자] (+ 미저장 번호면 [연락처에 추가] **비활성** — 아버지는 저장하지 않는다. 게임 중 연락처 추가는 이야기 사건으로만)
- 특수 처리:
  - 0091 상세(K-09 전): 번호만. K-09 후: 동일하게 번호만(라벨 없음) → KX-05 획득만.
  - 031-XXX-0112(경찰 대표, S5 후): 상세 하단에 작은 회색 "성원경찰서"(통신사 발신자 정보 표시 흉내) → KX-06.
  - 한결캐피탈(차단): 최근기록에 나오지 않음(차단 번호 기록은 설정 > 차단 목록 > 기록).

## 4. 발신 흐름

```
[발신] → "연결 중…"(1s) → 신호음(2~6s, 대상별) → 결과
결과: 연결(대화 트리) / 신호 가다 끊김 / 전원 꺼짐 안내 / 없는 번호 / 차단 확인 시트
```

| 대상 | 결과 | 비고 |
|---|---|---|
| 도현 | 전원 꺼짐 안내음 + 자막 "전원이 꺼져 있어 연결할 수 없습니다" | 엔딩 A 전까지 항상 |
| 0091 | 신호 6초 → 끊김(3회째부터 즉시) | |
| 0091(엔딩 A 06:00 이후) | 없는 번호 안내 | ISSUE-06 |
| 112 | 키패드에 1-1-2 입력 후 [발신] 탭 → 독백 "…" 후 발신 취소 | |
| 기타 | 허브 테이블(`systems/progression.md` 6장) | |

## 5. 통화 화면

| 요소 | 사양 |
|---|---|
| 상단 | 상대 이름/번호, 통화 시간(실시간 mm:ss) |
| 중앙 | 자막 영역(상대 대사 줄 단위 누적, 최근 4줄) |
| 하단 | 아버지 선택지(대화 트리의 choice) / 선택지 없을 땐 [스피커] [키패드](비활성) [종료] |
| 녹음 인물 | 자막 + 음성 |
| 종료 | 아버지가 누르면 `onHangup` 노드. 세션 진행 중 통화를 끊으면 다시 걸 수 있음(같은 트리 재시작 또는 이어서 — 트리별 지정) |

## 6. 착신 화면

| 요소 | 사양 |
|---|---|
| 잠금 상태 | 풀스크린. 이름/번호, [받기] [거절] 큰 버튼 |
| 사용 중 | 상단 큰 배너 |
| 거절 | 대상별: 지훈(S1 넛지) → 다시 문자 / 김 형사(S4 종료) → 30초 뒤 재착신 / 0091(S12 종료) → 20초 뒤 재착신 + 문자 "아버님, 받으세요." / 103호 → 부재중 |
| 무응답 | 실시간 15초 후 부재중 처리(거절과 동일 후속) |
