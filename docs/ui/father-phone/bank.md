# 은행 앱

> 근거: bible 5.1(은행: 아버지 계좌, 잔액 적음), K-20(대조). [ISSUE-01] 추천안: 은행 앱은 **아버지 본인 계좌 출금 내역**만 보여준다.

## 1. 화면

| 화면 | 내용 |
|---|---|
| 홈 | 계좌 카드 1개: 성원은행 입출금, 잔액 **412,730원**. [거래내역] [이체](비활성) [대출·채무 조회] |
| 거래내역 | 최신순. 필터: 전체/입금/출금. 기간: 1개월/3개월/전체 |
| 대출·채무 조회 | 탭 시 "조회 권한이 없습니다(채권 이전 계좌)" (AV-07) |

## 2. 거래내역 행

```
03.05  자동이체 한결캐피탈        -800,000     412,730
01.05  자동이체 한결캐피탈   출금실패(잔액부족)
```

- 실패 행은 회색 + "출금실패(잔액부족)".
- 기간 "전체"로 보면 2024-03부터의 한결 자동이체 25회(성공 20 / 실패 5).
  - 성공: 2024-03~08 6회 + 2024-10, 11, 2025-01~06, 08~10, 12, 2026-02, 03 = 20회.
  - 실패: 2024-09, 2024-12, 2025-07, 2025-11, 2026-01 = 5회.
- 그 외 거래(급여 10일, 보험 1일, 카드대금 15일, 통신비 20일, 관리비 25일)는 데이터로 일일이 쓰지 않고 **월 반복 생성 규칙**으로 채운다(금액 고정, 2024-03~2026-03). 필터 기본값은 "전체" — 한결 행만 골라 보여주지 않는다(특정 단서를 하이라이트하지 않는 원칙).
- 잔액 정합: 급여일 직전 잔액이 80만 미만이 되는 달 = 실패 5개월이 되도록 생성 규칙의 카드대금을 그 달만 늘린다(데이터 검증 스크립트가 실패 월과 잔액을 교차 확인).

## 3. 서사 기능

- 플레이어가 S11에 은행 앱을 열면: **아버지가 낸 건 80만, 그것도 다섯 번은 실패.** 같은 달 한결 문자는 "250만, 입금자 이도*".
- 은행 앱은 S11 필수 항목이 아니다(K-20의 대체 경로 KX-15). 열지 않아도 K-20은 메모 + 한결 스레드로 성립.
- 은행 앱은 아버지가 잔액(한결)을 끝내 직접 볼 수 없는 구조다. 숫자는 아들의 메모에서만 본다(AV-07).

## 4. 초기 진입(S11 전)

- 열람 가능. 대출·채무 조회 탭만 AV-07(독백 "…나중에." — 단, AV-01을 이미 겪었으면 독백 없이 조회 불가 메시지만).
