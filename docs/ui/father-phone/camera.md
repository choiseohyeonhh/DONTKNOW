# 카메라 앱 [ISSUE-16 신설]

> bible에는 없는 앱이다. 엔딩 A의 배경화면 교체(S14-6)를 물리적으로 성립시키기 위한 최소 기능.

## 1. 기능

- 셔터 버튼 하나. 전/후면 전환 없음, 설정 없음, 줌 없음.
- 무엇을 비추나: 카메라 앱을 열면 **현재 장면**이 뷰파인더에 보인다.
  - 집(S10 이후): 거실 테이블 위 옛 폰. 옛 폰 화면에는 **옛 폰에서 마지막으로 보고 있던 화면**이 렌더된다.
  - 그 외 장소: 장면 일러스트를 약간 다른 프레이밍으로.
- 촬영 → 셔터음 → 사진첩에 `PH.f.cam_*` 저장(모아레 필터, 2~3° 기울어짐).

## 2. 핵심 사용 (S11)

1. 옛 폰에서 잠든 아버지 사진(`PH.o.sleeping_father`)을 띄운다.
2. 기기 탭으로 아버지 폰 전환 → 카메라 → 뷰파인더에 옛 폰 화면 속 그 사진 → 촬영.
3. 사진첩 → 그 사진 → [배경화면으로 설정] → `FX-07`.

- 유도 없음. 넛지 없음(S11은 조용해야 한다). 이 행동은 **선택**이다(bible: "눌렀을 경우에만").
- 발견 가능성 확보: 사진 뷰어에서 "배경화면으로 설정" 메뉴가 카메라 사진에만 있다는 걸 플레이어가 알아야 한다 → S8 영수증 자동 촬영(`PH.f.receipt_saebom`)을 사진첩에서 열면 같은 메뉴가 보인다. 그때 한 번 본 메뉴가 S11에서 기억나게.

## 3. 기타 촬영

- 옛 폰의 메모·메시지를 찍을 수도 있다. 저장만 되고 아무 효과 없음(수첩화 금지 — 찍어도 K를 주지 않는다).
- 대면 장면 중 카메라: 비활성(상대 앞에서 찍지 않는다).
