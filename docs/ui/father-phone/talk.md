# 톡 앱 (메신저)

> 근거: bible 5.1("프로필 열람, 대화 / 아버지 프로필에 생일 노출"), 7장 S3(서연 톡, 경비실 톡).
> 이름은 가칭 "톡". 특정 실제 메신저의 UI·색(노랑 등)·아이콘 모방 금지.

## 1. 탭

| 탭 | 내용 |
|---|---|
| 친구 | 맨 위 **내 프로필** → 친구 목록(소수) |
| 채팅 | 대화방 목록 |

## 2. 내 프로필 (PIN 해제 경로의 핵심)

| 요소 | 값 |
|---|---|
| 이름 | 이상철 |
| 사진 | 기본 실루엣 |
| 상태메시지 | 없음 |
| 생일 | **1968년 4월 3일** (프로필 카드 하단 작은 케이크 아이콘 + "1968년 4월 3일") [ISSUE-34] |

- 플레이어가 아버지 생일을 모를 수 있다는 전제(5.7). PIN이 `680403`이라 **연도까지** 보여야 한다 → 프로필 생일을 "1968년 4월 3일"로 표시(연도 공개 설정) [ISSUE-34]. 이걸로 bible 5.7 해제 경로 ①②의 "아버지 톡 프로필"이 그대로 성립.

## 3. 친구 목록 (초기)

| 친구 | 비고 |
|---|---|
| 도현 | 프로필 사진 없음, 상태메시지 없음, 생일 비공개. 대화방 없음(부자는 톡을 안 한다) |
| 성원아파트 관리사무소 | 공지 채널 |

게임 중 추가: 한서연(S3), 성원아파트 경비실(S3 종료).

> 도현 프로필: 탭하면 빈 프로필. 배경 사진 없음. "대화하기" 버튼은 있음 → 누르면 빈 대화방, 입력창 비활성. 3년 침묵의 시각화. 발견형.

## 4. 대화방

| 방 | 세션 | 내용 |
|---|---|---|
| 한서연 | S3 | 서연 먼저: "안녕하세요 도현이랑 같은 반이었던 한서연이에요" / "김쌤한테 연락받았어요" / "도현이 폰 두 개 썼어요" / "하나는 진짜 옛날 폰이요" / "쉬는 시간마다 그거 보고 있었어요" → K-07 / 아버지 선택지("알려줘서 고마워요" / "혹시 다른 건 없었어요?") / 서연 "음 그게 다예요" / "도현이 찾으면 저한테도 연락 주세요" |
| 성원아파트 경비실 | S3 종료, S4·S8 넛지 | "[경비실] 이상철 님, 손님 한 분이 댁 앞에서 기다리고 계십니다" 등 |
| 성원아파트 관리사무소 | 초기 | 공지(엘리베이터 점검 3/20 등), 답장 불가 |

- 톡 버블 연출은 메시지 앱과 동일 규칙. 색만 다름.
