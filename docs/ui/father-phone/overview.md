# 아버지 폰 — 잠금화면·홈·상태바

> 근거: bible 5.1, 12.1, 7장 S1. 앱별 상세는 같은 폴더의 각 문서.

## 1. 상태바 (항상 표시)

| 위치 | 요소 |
|---|---|
| 좌 | 게임 시계 `02:47` (24h, 큰 글씨) |
| 우 | 신호, 배터리(게임 내내 41% → S13 12% → 엔딩 A 새벽 5%로 서서히 감소, [설계] 하루의 소모를 보이는 장치), 무음 아이콘 없음 |

## 2. 잠금화면

| 요소 | 사양 |
|---|---|
| 배경 | `phone.wallpaper` (기본 2019 가족 사진) |
| 시계 | 큰 글씨 + "3월 18일 수요일" |
| 알림 요약 | **부재중 47 / 메시지 23** 두 줄(S1, bible) — 숫자는 현재 배지 값 |
| 알림 목록 | 최신 알림 카드(게임 중 수신분). 초기엔 요약 두 줄만 |
| 잠금 해제 | 위로 쓸기(비밀번호 없음 — 아버지는 잠금 설정을 안 했다) |
| 길게 누르기 | 게임 메뉴(`ui/meta-screens.md` 3장) |

- 잠금화면은 S1의 첫 화면이자, 엔딩 A 마지막 화면(배경화면 변경 확인, bible S14-6).
- 시간 점프 후에도 잠금화면으로 돌아온다(폰을 내려놨다가 다시 드는 리듬).

## 3. 홈 화면

### 3.1 배치 (iOS 홈: 4열 그리드 + 독)

```
[톡]     [연락처]  [사진]   [길찾기]
[은행]   [메모]    [설정]   [ (빈칸) ]
                 [검색]
독: [전화] [메시지] [카메라]
```

- 9개 + 카메라(ISSUE-16) = 10개. "홈 화면 앱 수 최소"(5.1).
- 배지: 전화(부재중 수), 메시지(미읽 수), 톡(미읽 수). 빨간 원 + 흰 숫자, 3자리까지.
- 독에는 3개만(4칸 중 하나 비움). 위젯 없음. 배경은 잠금화면과 같은 톤다운 사진(살짝 어둡게).

### 3.2 기기 탭 (S10 이후)
- 화면 최하단 가장자리에 두 개의 작은 탭: `아버지 폰` | `도현 폰`. 현재 기기는 진하게.
- S10 이전엔 표시하지 않는다.

### 3.3 대면 장면 중
- 장면 화면 우하단에 폰 아이콘. 탭하면 폰이 아래에서 올라옴(장면은 어둡게 뒤에). 닫으면 대화 재개.
- 대면 중 잠기는 기능: 전화·문자 발신(`systems/dialogue.md` 6장).

## 4. 앱 공통

| 규칙 | 내용 |
|---|---|
| 뒤로 | 상단 좌측 큰 "<" + 화면 왼쪽 가장자리 스와이프 |
| 홈으로 | 하단 홈 바 위로 쓸기 / 데스크톱은 하단 홈 버튼 |
| 스크롤 | 관성 스크롤. 긴 스레드(한결 34건) 스크롤바 표시 |
| 타이핑 | 없음. 입력창을 탭하면 선택지 시트가 올라온다(대화 중일 때만). 대화 없을 땐 입력창 비활성("…") |
| 롱프레스 | 메시지 날짜 → 요일 팝업(`content/absence-dates.md` 2.2). 그 외 컨텍스트 메뉴 없음 |
