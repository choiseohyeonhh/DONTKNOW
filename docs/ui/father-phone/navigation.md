# 길찾기 앱 (네비)

> 로직은 `systems/navigation.md`. 이 문서는 화면.

## 1. 첫 화면

| 요소 | 사양 |
|---|---|
| 상단 | 검색창 "어디로 갈까요?" |
| 본문 | 즐겨찾기(집) / 최근 목적지(등록된 장소, 최근 이동 순) |
| 배경 | 어두운 지도(현재 위치 흰 점) |

- 등록된 장소가 없으면(S2 전) 집과 성원경찰서(3/15 기록)만.

## 2. 검색

- 검색창 탭 → 화면 키보드(이 게임에서 유일한 텍스트 입력) [결정 필요: `systems/navigation.md` 2장].
- 입력 중 자동완성: **등록된 장소의 별칭만** 후보로 뜬다.
- 엔터/검색 → 결과 없음이면 독백 "…어디였더라."(MO.09), 특수 오답은 전용 독백.
- 대안 UI(텍스트 입력 없이): 검색창 탭 → 등록 장소 목록이 그대로 펼쳐짐. 이 경우 "어디였더라" 연출은 미등록 장소가 없으므로 사라진다. → 텍스트 입력 유지 추천(5.5 연출 보존).

## 3. 장소 카드

| 요소 | 사양 |
|---|---|
| 이름 | 장소명 |
| 정보 | 소요 시간(게임 분), 도착 예정 시각 |
| 약국만 | "영업 중 · 19:00 종료" |
| 버튼 | [안내 시작] |

## 4. 이동 화면

`ui/scenes/travel.md`.

## 5. 이동 불가 시

- [안내 시작] 탭 → 독백(MO.16 "…지금은." 등) → 버튼이 잠시 눌린 채 복귀. 경고 팝업 없음.
