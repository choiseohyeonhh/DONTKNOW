# 설정 앱 (게임 세계 안의 설정)

> 근거: bible 10.1("한결캐피탈: 저장되어 있지만 차단 목록에 있음 — 설정에서 확인 가능, 발견형 디테일").
> 게임 자체 설정(음량 등)과 분리. 이건 **아버지 폰의 설정**이다.

## 1. 메뉴

| 항목 | 동작 |
|---|---|
| 디스플레이 | "글자 크기: 최대", "화면 모드: 라이트" — 표시만, 변경 불가 |
| 배경화면 | 현재 배경화면 미리보기. 변경은 사진 앱에서만 |
| 알림 | "모든 알림 켜짐" 표시만 |
| **차단 목록** | 아래 2장 |
| 휴대전화 정보 | 기종명(가공), 소프트웨어 버전 오래됨 — 배지 동작 설정 근거 |

## 2. 차단 목록

```
차단된 번호
한결캐피탈   070-XXXX-3301     2023. 8. 14. 차단
```

- 행 탭 → 상세: [차단 해제] 버튼 → 시트 "차단을 해제하시겠습니까?" [해제](비활성 회색) [취소] (AV-03).
- 상세 하단 "차단된 기록": 2023-08 ~ 2026-03 차단된 통화 n건(숫자만, 예: 38건). [설계] 부재중 47과 별개로, 아버지가 아예 **들리지도 않게** 만든 목소리의 양.
- 엔딩 A 이후 연출 없음(엔딩에서 이 화면을 다시 보여주지 않는다). 해제 버튼 활성은 엔딩 A 크레딧 이후 세이브에서만(2회차 시작 전 타이틀로 돌아가므로 실질적 의미 없음 — 기록으로만). [결정 필요] 추천: 해제 불가 유지. 엔딩 A의 "상환 일정 상담 요청" 문자가 해제의 대체 행위다.
