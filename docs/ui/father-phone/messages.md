# 메시지 앱 (SMS)

> 근거: bible 5.1(미읽 23), 7장 S1(자동 닫힘), S10·S11(한결 스레드), 12.1(선택지 기반 입력).

## 1. 목록 화면

| 요소 | 사양 |
|---|---|
| 정렬 | 최신 메시지 순(`content/father-phone-data.md` 4.8) |
| 행 | 발신자(저장명/번호), 미리보기 1줄, 날짜, 미읽 수 배지 |
| 미읽 | 발신자 굵게 + 우측 숫자 |
| 상단 메뉴 `⋮` | S11 전: "설정"만 / S11 후: "모두 읽음"(회색, AV-04), "설정" |
| 검색 | 없음 |

## 2. 스레드 화면

| 요소 | 사양 |
|---|---|
| 헤더 | 발신자, [전화] 아이콘(저장/알게 된 번호만) |
| 버블 | 수신 좌측 흰색, 발신 우측 연파랑. 큰 글씨 |
| 날짜 구분선 | 날짜가 바뀔 때 "2025년 11월 25일 화요일" (요일 포함 — 이 구분선만으로도 결석일 요일 대조가 가능하도록) |
| 진입 위치 | 가장 최근 메시지(하단). 위로 스크롤해 과거 |
| 입력창 | 대화 진행 중: 탭하면 선택지 시트. 그 외: 비활성 회색 "…" |
| 답장 불가 스레드 | 광고, 대학교: 입력창 없음("발신 전용") |

## 3. 선택지 시트(문자 전송)

1. 입력창 탭 → 하단 시트에 선택지(최대 4).
2. 선택 → 입력창에 한 글자씩 타이핑(120ms/자) → 자동 전송.
3. 전송 버블 아래 "전송됨" → NPC "입력 중…" → 답장.
4. 선택지 시트는 닫을 수 있다(나중에 답장). 닫으면 유휴 시계 계속.

## 4. 특수 연출

### 4.1 AV-01 자동 닫힘 (한결 스레드, S1~S9 첫 열람)
```
스레드 열림 → 최근 메시지 보임(1.2s) → 독백 "…나중에." → 앱이 0.35s에 걸쳐 저절로 닫힘 → 홈
```
- 다시 열면 닫히지 않는다. `FX-02`.
- 플레이어가 1.2초 안에 스크롤을 시작해도 닫힌다(아버지가 이긴다, 한 번은).

### 4.2 S10 한결 알림 (EV.S10.02)
- 옛 폰 음성메모 종료 5초 후, 아버지 폰 쪽 알림 띠(옛 폰 화면 상단): `1600-XXXX  [한결캐피탈] 2월 상환금 2,500,000원 입금 확인…`
- 이건 새 메시지가 아니다 — **아버지 폰이 미읽 알림을 다시 띄우는 것**(실제 폰의 "읽지 않은 메시지 리마인더" 기능). 탭 → 기기 전환 → 스레드 열림. 자동으로 닫히지 않는다.

### 4.3 S11 한결 스레드 스크롤
- 34건, 2024-08부터. 날짜 구분선 19개월치. 스크롤바가 길고 천천히 내려간다.
- 탭 가능한 링크 없음. 금액 숫자는 tabular-nums로 세로 정렬.

### 4.4 엔딩 A 답장 (bible S14-4)
- 한결 스레드 입력창이 이때만 활성. 탭하면 선택지 1개: "상환 일정 상담 요청드립니다. 이상철입니다." → 타이핑 → 전송.
- 답장 없음. 전송됨 표시만.
