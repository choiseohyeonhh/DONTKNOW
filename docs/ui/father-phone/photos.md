# 사진 앱

> 근거: bible 5.1("대부분 오래됨, 아들과의 마지막 사진 2022"), 7장 S9(사진 제시), S11(채무조정 서류), S14(배경화면).

## 1. 구성

| 화면 | 내용 |
|---|---|
| 그리드 | 최신순, 4열(큰 썸네일). 사진 수가 적다(초기 6장) — 스크롤이 거의 없다는 것 자체가 정보 |
| 뷰어 | 한 장 전체 화면, 하단에 촬영 일시 |
| 뷰어 메뉴 | 조건부 액션(아래) |

## 2. 뷰어 액션

| 액션 | 노출 조건 | 동작 |
|---|---|---|
| 보여주기 | 대면 장면 중 + 대화 트리가 `requestItem` 대기 | 장면으로 돌아가며 사진을 상대에게 내미는 컷 → 트리 진행(S9 `FX-05`) |
| 배경화면으로 설정 | 카메라로 찍은 사진(`PH.f.cam_*`)만 | 시트 "잠금화면 배경으로 설정할까요?" [설정] [취소] → `FX-07` |
| 삭제·공유·편집 | 없음 | |

- "보여주기"는 S9 외에도 대면 장면에서 `requestItem`이 열려 있으면 가능(현재는 S9만 사용). 대화와 무관한 사진을 보여주면 상대 반응 1줄 후 원래 대기로(예: 최 약사 "…이건 뭐예요?").

## 4. 채무조정 서류 사진 (S11)

- 비스듬히, 흐리게. "채무조정 신청서", 서명란에 아버지 서명, "확정 잔여원금 80,000,000원" 칸이 읽힐 듯 말 듯.
- 확대(핀치) 가능 — 게임 전체에서 핀치 줌이 허용되는 유일한 화면 종류(사진 뷰어). 확대하면 숫자가 읽힌다. 아버지는 찍기만 하고 확대해 본 적이 없다.
