# 연락처 앱

> 근거: bible 5.1("등록된 사람 + 새로 알게 된 번호가 자동 추가 / 번호를 '알아야' 걸 수 있음"), 10.1.

## 1. 목록

| 섹션 | 내용 |
|---|---|
| 내 정보 | 이상철(톡 프로필과 연동) |
| 연락처 | 가나다순. 초기 7명 + 게임 중 추가 |
| 기타 번호 | 이름 없이 알게 된 번호(0091, 경찰 대표번호) [ISSUE-25] |

- 상단 검색 없음(연락처가 적다 — 아버지의 세계가 좁다).
- 즐겨찾기 없음.

## 2. 자동 추가 규칙

| 대상 | 계기 | 표시 |
|---|---|---|
| 차유진 | K-08(S4 종료, 쪽지) | "차유진" |
| 준호 | KX-03(지훈이 번호 보내줌) | "준호" (아버지가 성을 모름 — 저장명은 이름만) |
| 한서연 | 톡 친구 추가(S3) | 연락처에는 추가 안 됨(톡에만) |
| 010-5XXX-0091 | K-09 | 기타 번호, 라벨 없음 |
| 031-XXX-0112 | KX-06 | 기타 번호, 라벨 없음 |

- 추가 시 알림·토스트 없음. 연락처를 열면 그냥 있다.
- 아버지가 직접 추가하는 UI 없음.

## 3. 연락처 상세

- 이름, 번호, [전화] [문자] [톡](톡 친구인 경우).
- 한결캐피탈: 이름 옆 작은 차단 아이콘. [전화] → 차단 확인 시트(AV-03).
- 도현: [전화] → 전원 꺼짐. [문자] → 스레드(입력 비활성).

## 4. "번호를 알아야 걸 수 있다"

- 키패드 직접 입력은 가능하지만, 게임 내 의미 있는 번호는 전부 이야기 속에서 알게 된 번호다. 키패드로 임의 번호를 걸면 "없는 번호입니다" 안내(모든 미정의 번호 공통).
- 알게 된 번호를 키패드로 쳐도 연락처로 건 것과 동일하게 동작.
