# 오버레이 (알림·독백·다이얼로그)

> 레이어 정의는 `systems/architecture.md` 5장.

## 1. 알림 배너 (레이어 3)

| 종류 | 모양 | 탭 동작 | 소리/진동 |
|---|---|---|---|
| 문자 | 앱 아이콘 + 발신자 + 첫 줄 미리보기 | 해당 스레드 열기 | HP.sms |
| 톡 | 동일(톡 아이콘) | 대화방 | HP.sms |
| 착신 | 풀스크린 착신 화면(잠금 상태) / 상단 큰 배너(사용 중) | 받기/거절 | HP.call |
| 부재중 | 배너 없음(전화를 안 받아서 생기는 것 — 게임 중 플레이어가 거절했을 때만 배너) | | |
| 네비 | 경로 안내 시트("경로 안내를 시작할까요?") | 시작/닫기 | 없음 |
| 길찾기 앱 알림(S9 넛지) | 앱 아이콘 + "저장한 장소 '새봄약국' 영업 종료까지 1시간 30분" | 네비 | HP.sms |

- 표시 4초. 연속 배너는 최소 4초 간격.
- 잠금화면 상태에서는 잠금화면 알림 목록에 쌓인다(최신 위).
- 옛 폰을 보고 있을 땐 상단 얇은 띠(아버지 폰 색) + 진동음.

## 2. 독백 배너 (레이어 3, 특수)

| 항목 | 사양 |
|---|---|
| 위치 | 알림 배너와 같은 자리 |
| 모양 | 아이콘 없음, 발신자 없음, 반투명 회색 배경, 텍스트 `--muted` |
| 표시 | 2.5~3초 후 페이드 |
| 소리/진동 | **없음**(유일) |
| 알림 목록 | 남지 않음 |
| 탭 | 무반응 |

## 3. 시스템 확인 다이얼로그 (레이어 4)

용도: F-03 2단계 확인, 세이브 삭제 확인.

| 항목 | 사양 |
|---|---|
| 모양 | 대화창 위 흰 카드(대면 장면이면 장면을 어둡게) |
| 버튼 | 2개, 세로 배치(가로 배치 시 실수 탭 위험). 위험한 선택(말한다)이 위 |
| 입력 잠금 | 열린 뒤 2초간 버튼 비활성(옅게) |
| 텍스트 | 김 형사 대사가 카드 안 인용으로 들어감. "확인"이라는 시스템 단어는 쓰지 않는다 — 버튼 텍스트도 아버지의 말("말한다" / "아니다, 됐습니다") |

## 4. 시트 (하단)

- 네비 경로 시작, 차단 해제 확인(AV-03: [취소]만 활성), 사진 "보여주기"(S9), "배경화면으로 설정"(카메라 사진).
- 높이 최대 40%. 바깥 탭으로 닫힘(경로 시작 시트 제외 — S12→S13은 닫아도 다시 뜸).

## 6. 토스트

- **사용하지 않는다.** "저장됨", "획득", "새 목적지" 등 모든 시스템 토스트 금지. 저장 실패 같은 기술 경고만 타이틀 화면에서.
