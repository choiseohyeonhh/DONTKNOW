# 옛 폰 — 앱

> 데이터: `content/old-phone-data.md`. 모든 앱은 **읽기 전용**(서비스 없음, 편집 불가).

## 1. 메시지

| 화면 | 사양 |
|---|---|
| 목록 | 맨 위 `[초안] 아빠, 나 사실...`(빨간 [초안]) → 형 → 준호 → 유진 누나 (최신순, 초안은 항상 맨 위) |
| 스레드 | 작은 버블, 다크. 진입 시 최신 메시지 위치. 날짜 구분선 |
| 초안 스레드 | 메시지 없음. 입력창에 `아빠, 나 사실...` + 커서 깜빡임. 전송 버튼 탭 → "메시지를 보낼 수 없습니다"(서비스 없음). 입력창 텍스트는 편집 불가 |
| 형 스레드 | 열면 K-21·K-22. 최상단 스크롤 → KX-20 |
| 준호 스레드 | KX-22 |
| 유진 스레드 | KX-21 |

- 옛 폰 메시지에는 답장 입력창이 없다(초안 제외).
- 스크롤 위치는 스레드별로 기억.

## 2. 메모

| 화면 | 사양 |
|---|---|
| 목록 | "남은 거"(2/25) · "4월 일정"(2025/4/5) · "자취" · "4/3" — 수정일 순 |
| 본문 | 고정폭 숫자(tabular-nums), 줄 간격 촘촘. 다크 |
| "남은 거" | 22줄(제목·목표 포함). 한 화면에 다 보이지 않는다 — 스크롤해야 마지막 줄이 나온다. 마지막 줄 `대학 가기 전에 반은 하고 싶었는데`는 맨 아래, 숫자 줄보다 한 줄 띄움 |
| "4월 일정" | 표 정렬. 마지막 줄 한 칸 띄움 |
