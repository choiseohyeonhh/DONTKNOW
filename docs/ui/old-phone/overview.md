# 옛 폰 — 개요·홈

> 근거: bible 5.7, 12.2. 로직은 `systems/old-phone-device.md`, 데이터는 `content/old-phone-data.md`.

## 1. 첫인상 설계

전환 순간 플레이어가 느껴야 할 것: **"정리된 사람의 폰."** 아버지 폰과 모든 축에서 반대.

| 축 | 연출 |
|---|---|
| 밝기 | 다크, 화면 전체 휘도 낮음 |
| 정보 밀도 | 작은 글씨, 여백 많음 |
| 소음 | 알림 0, 배지 0, 상태바에 "서비스 없음" |
| 질서 | 앱 5개 한 줄, 폴더 없음, 위젯 없음 |
| 시간 | 12시간제 |

## 2. 상태바

`오후 7:41`(좌) · `서비스 없음` · 배터리(충전 중 표시 → 이후 고정 63%)

## 3. 홈

```
[메시지] [메모] [음성메모] [사진] [계산기]
```

- 배경: 단색 거의 검정(#0E0F11). 배경 사진 없음.
- 시계 위젯 없음.
- 앱 아이콘: 단색 라인 아이콘, 라벨 작게.
- 길게 누르기·설정 진입 없음(설정 앱 없음 — 도현이 지웠다).

## 5. 아버지 폰과의 공존

- 하단 기기 탭(아버지 폰 | 도현 폰).
- 아버지 폰 알림은 옛 폰 화면 상단의 얇은 띠로 표시(탭하면 전환).
- 데스크톱 넓은 화면: 나란히 보기 옵션(P2).
