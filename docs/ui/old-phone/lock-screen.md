# 옛 폰 — 잠금화면과 PIN

> 로직: `systems/old-phone-device.md` 3~4장.

## 1. 순서

```
봉투 열기(장면) → 꺼진 폰 확대 뷰 → [전원] 탭 → 배터리 0% 아이콘 깜빡
→ [충전] (충전기 꽂는 컷 2초, AU.sfx.charger) → 부팅 로고(가공) 3초 → 잠금화면
```

## 2. 잠금화면

| 요소 | 사양 |
|---|---|
| 배경 | 검정 |
| 시계 | 작게 `오후 7:12` + "3월 18일 수요일" |
| 알림 | 없음 |
| 하단 | "PIN을 입력하세요" + 6칸 점 |
| 키패드 | 0~9, 지우기. 작은 키 |
| 힌트 영역 | 3회 실패 후 키패드 위 작은 회색: `힌트: 아빠` |

## 3. 입력 반응

| 상황 | 반응 |
|---|---|
| 숫자 탭 | 점 채움, 키패드 음(작게) |
| 6자리 오답 | 점 좌우 흔들림(HP.error), 점 초기화 |
| 1회 실패 + K-05 | 독백 MO.13 "…가족 생일." |
| 3회 실패 | 힌트 노출(이후 상시) |
| 5회 실패 | 독백 MO.07 "…내 생일은 기억할까." |
| 10회 실패 | 30초 입력 지연 1회("30초 후 다시 시도") — 이후 지연 없음 |
| 정답 680403 | HP.heavy(진동 한 번) → **정적 2초**(입력 무시, 화면 그대로) → 홈 페이드 인. 독백 없음 |

## 4. 플레이어 보조 경로(정보 위치)

| 정보 | 위치 |
|---|---|
| 아버지 생일 1968-04-03 | 톡 > 내 프로필(`ui/father-phone/talk.md` 2장 결정 사항) |
| "가족 생일" 습관 | S2 지훈(K-05) 또는 S10 PIN 화면 180초 지훈 넛지 |
| "아빠" | 3회 실패 힌트 |

## 5. 금지

- 힌트 텍스트에 숫자·날짜 노출 금지.
- 실패 횟수 카운터 표시 금지(실제 폰도 안 보여준다).
- "정답!" 같은 성공 피드백 금지 — 정적 2초가 피드백이다.
