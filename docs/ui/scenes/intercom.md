# 인터폰 (S8)

> 근거: bible 7장 S8. 민재의 얼굴은 인터폰 화질로만.

## 1. 진입

1. 집 도착(16:10 앵커) → 초인종 연타(AU.sfx.doorbell_spam, HP.door) → 현관 장면.
2. 현관 장면에서 벽의 인터폰 패널이 밝아져 있다. 탭 → 인터폰 화면.

## 2. 화면

```
┌─────────────────────┐
│ ● 현관 카메라  16:10 │
│ ┌─────────────────┐ │
│ │  (민재 영상)     │ │  ← ART.video.intercom_minjae
│ │  흑백·노이즈     │ │
│ └─────────────────┘ │
│ [통화] [문 열기] [종료]│
└─────────────────────┘
```

| 버튼 | 동작 |
|---|---|
| 통화 | 인터폰 음성 대화(인터폰 경로). 대사는 영상 아래 자막 |
| 문 열기 | 현관 장면으로 돌아가 문이 열림(문 열기 경로, FX-04) |
| 종료 | 인터폰 끔 → 문 두드림 계속 → 10초 후 다시 인터폰 밝아짐(회피 불가: 이 장면은 피할 수 없다) |

## 3. 두 경로

| | 인터폰 | 문 열기 |
|---|---|---|
| 민재 음성 | AU.voice.minjae_s08_intercom | AU.voice.minjae_s08_door |
| 영수증 | 민재 도주 후 현관 앞에서 발견(현관 장면 오브젝트) | 대화 중 민재 주머니에서 떨어짐 → 자동 |
| 화면 | 인터폰 영상 | 현관 틈의 팔·소매 |
| 위험감 | 낮음 | 높음(문 틈 흔들림 HP.door) |
| 정보 | 동일(K-15, K-16) | 동일 |

## 4. 종료 연출

- 이웃 문 열리는 소리(AU.sfx.neighbor_door) → 민재 발소리 멀어짐.
- **현관 정적 5초**: 입력 무시, 독백 없음, 환경음만(bible).
- 이후 입력 재개. 인터폰 경로면 현관 바닥에 영수증 오브젝트(하이라이트 없음).
- 1분 후 RE.02 유진 문자.
