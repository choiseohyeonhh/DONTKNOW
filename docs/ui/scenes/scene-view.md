# 장면 화면 (대면 대화)

> 근거: bible 12.3, 7장 대면 세션(S3, S4, S5, S6, S8, S9, S13). 로직은 `systems/dialogue.md` 6장.

## 1. 레이아웃 (세로)

```
┌───────────────────────┐
│ 상태바(아버지 폰 시계) │
│                       │
│   장면 일러스트        │  ← 화면 높이 60~65%
│   (1인칭, 미세 모션)    │
│                       │
├───────────────────────┤
│ 화자명                │
│ 대사 (최대 3줄)        │  ← 대사창
│                    ▼  │
├───────────────────────┤
│ 선택지 1               │  ← 선택지 표시 시 대사창 아래로 펼침
│ 선택지 2               │
│                  [📱] │  ← 폰 꺼내기
└───────────────────────┘
```

- 상태바는 장면에서도 보인다(게임 시계 = 하루가 저문다).
- 대사창 배경: 반투명 검정, 흰 글씨. 화자명 굵게.
- 탭: 다음 줄. 줄 표시 중 탭하면 즉시 완성(타자 효과 0.03s/자, 아버지 폰과 달리 빠름).

## 2. 인물 표현 규칙 (12.3)

| 인물 | 장면에서 보이는 것 |
|---|---|
| 담임 | 책상 위 손, 출석부를 넘기는 손 |
| 윤 선생님 | 머그를 쥔 두 손 |
| 유진 | 현관문 너머 어깨 아래, 가방끈 쥔 손 |
| 김 형사 | 책상 너머 손, 서류, 펜 |
| 장 사장 | 담배 든 손, 모니터를 가리키는 손가락 |
| 민재 | 인터폰 화면(`intercom.md`) / 문 열기 시 현관 틈의 팔·땀 젖은 소매 |
| 최 약사 | 카운터 너머 손, 영수증을 쥐는 손 → 사진 보고 멈추는 손 |
| 형 | 차 옆 뒷모습, 손. S13 내내 정면 금지 |

- 얼굴은 절대 그리지 않는다. 표정 연기는 손과 대사 리듬이 담당.

## 3. 장면 전환

- 같은 장소 내 컷 전환: 0.5s 디졸브(교무실 → 복도 → 상담실).
- 장소 도착: 이동 화면 → 0.8s 페이드 인.
- 대화 중 효과 컷: `effects: [{scene: ...}]`.

## 4. 아이템 확대 뷰

- 장면 오브젝트 탭 → 아버지 손에 든 1인칭 확대 이미지(전체 화면) → 바깥 탭 닫기.
- 확대 뷰 열람이 K 트리거일 수 있다(영수증 K-16, 봉투 K-18).
