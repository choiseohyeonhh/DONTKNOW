# 이동 화면

> 근거: bible 5.5("어두운 지도, 경로 선, 점 이동. 무음 + 간헐적 깜빡이 소리. 이동 중 리액티브 문자 가능"). 로직: `systems/navigation.md`.

## 1. 화면

```
┌─────────────────────┐
│ 상태바 13:15         │
│ 하루마트 성원역점     │
│ 도착 13:30 · 15분     │
│                     │
│   ·───────●──────·  │  ← 어두운 지도, 주황 경로선, 흰 점
│                     │
│                     │
└─────────────────────┘
```

| 요소 | 사양 |
|---|---|
| 지도 | ART.ui.map_dark, 가공 도로망 |
| 경로선 | 나트륨 주황 #E39A3B, 2px |
| 점 | 흰색, 경로 따라 이동(실시간 3~5초) |
| 상단 | 목적지명, 도착 예정(게임 시계), 남은 분 |
| 상태바 시계 | 이동 동안 출발 → 도착 시각으로 롤링 |
| 소리 | 무음 + 깜빡이 2회(출발·도착 직전) |

## 2. 이동 중 상호작용

- 화면 탭 → 폰 홈(이동은 계속, 상단에 "안내 중" 띠).
- 이동 중 문자 수신 가능. 배너 탭 → 스레드. 답장 가능(아버지가 신호 대기 중에 친다).
- 이동 중 전화 착신 가능. 받으면 이동 일시정지(통화 끝나면 재개).
- 이동 중 발신: 가능(허브). [결정 필요] 운전 중 통화 — 현실 고려하면 막아야 하나 아버지 캐릭터상 자연스럽다. 추천: 허용.

## 3. 도착

- HP.arrive + 0.8s 페이드 → 장면 화면.
- 도착 장소에 고정 이벤트가 있고 시각이 이르면: 상태바 시계 롤링(1.5s) 후 이벤트.
