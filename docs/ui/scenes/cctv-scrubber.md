# CCTV 스크러버 (S6)

> 근거: bible 7장 S6("플레이어가 CCTV를 직접 스크럽. 정지 화면이 아닌 흐름으로 보면 의미가 바뀐다. '기록은 전부를 말하지 않는다'의 첫 체험").

## 1. 진입

- S6 대화에서 "제 아들입니다." 이후 장 사장이 모니터를 돌려줌 → 계산대 모니터 확대 → 스크러버 UI.

## 2. 화면

```
┌───────────────────────────┐
│ CAM 02  2026-03-14  19:05:30 │  ← 타임코드(실시간 갱신)
│ ┌───────────────────────┐ │
│ │   흑백 저화질 영상      │ │  ← ART.video.cctv_full (2분)
│ └───────────────────────┘ │
│ ◀◀  ▶/❚❚  ▶▶              │
│ ├──────●────────────────┤ │  ← 타임라인 드래그
│ 19:05:30          19:07:30 │
└───────────────────────────┘
```

| 조작 | 사양 |
|---|---|
| 드래그 | 타임라인 자유 탐색(앞뒤) |
| 재생 | 1× |
| ◀◀ ▶▶ | 5초 단위 |
| 확대 | 없음(저화질 그대로) |

## 3. 경찰 정지 화면과의 관계

- 타임라인 위에 작은 눈금 3개: 19:05, 19:06, 19:07(S5에서 본 정지 화면 시점). 표시만, 설명 없음.
- 15초 구간(19:06:05~19:06:20)은 **눈금 사이**. 하이라이트 없음.

## 4. 15초 구간 내용

| 시각 | 화면 |
|---|---|
| 19:06:05 | 남자(뒷모습)가 도현의 어깨를 잡는다 |
| 19:06:08 | 남자가 고개를 숙여 도현 귀에 무언가 말한다 |
| 19:06:12 | 도현이 움찔한다(어깨가 튐) |
| 19:06:16 | 도현이 고개를 숙인다 |
| 19:06:20 | 남자가 손을 뗀다 |
| 19:07:00 | 도현이 차에 탄다(스스로) |

## 5. K-12 트리거

- 19:06:05~19:06:20 구간이 **재생(1×) 또는 드래그로 연속 표시된 누적 시간 ≥ 12초** → `seen(IT.cctv_full)`.
- 그 뒤 장 사장의 증언 노드가 열린다("내가 담배 피우러 나와 있었거든…") → K-12.
- 넛지: `systems/idle-nudge.md` S6(교내) 행.

## 6. 화질 원칙

- 얼굴 식별 불가(12.3). 도현의 얼굴도 CCTV에서는 뭉개진다 — "도현은 끝까지 사진 속에서만 얼굴이 보인다".
- 차량 번호판 식별 불가.
