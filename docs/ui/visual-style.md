# 비주얼 스타일

> 근거: bible 5.1 UI 원칙, 12.1~12.3. 두 개의 폰이 곧 두 사람이다. 대비를 디자인 시스템 레벨에서 고정한다.

## 1. 두 폰의 대비

| 항목 | 아버지 폰 | 도현의 옛 폰 |
|---|---|---|
| 모드 | 라이트 | 다크 |
| 글자 | 최대(본문 22px 기준) | 작음(본문 14px) |
| 아이콘 | 기본, 큼, 라벨 큼 | 미니멀, 작음, 라벨 작음 |
| 홈 | 앱 9개 + 폴더 없음, 배치 정돈 안 됨(한 칸 비어 있음) | 앱 5개, 한 줄, 완벽 정렬 |
| 배지 | 정리 안 됨(47, 23) | 0 |
| 시계 | 24시간제 | 12시간제 |
| 색온도 | 중성~약간 따뜻 | 차갑게(파랑 쪽 3~5% 시프트) |
| 배경화면 | 2019 가족 사진 | 단색(거의 검정) |
| 키보드/키패드 | 큰 키 | 작은 키 |

## 2. 디자인 토큰 (CSS 변수 세트 2개)

```
--font-body        father: 22px / old: 14px
--font-title       father: 28px / old: 17px
--line-height      father: 1.45 / old: 1.35
--bg               father: #F4F3F0 / old: #0E0F11
--fg               father: #141414 / old: #D9DDE3
--muted            father: #6B6B6B / old: #7C838C
--accent           father: #2F6FDE (기본 파랑, 평범) / old: #8FA3BF
--badge            father: #E5483B / old: (없음)
--bubble-in        father: #FFFFFF / old: #1C1E22
--bubble-out       father: #DDE8FB (노란 버블 금지 — 특정 메신저 연상) / old: #2A3442
--radius           father: 18px / old: 12px
--tap-min          father: 56px / old: 44px
```

> 특정 실제 OS·메신저(iOS, One UI, 카카오톡) 모방 금지. "평범한 오래된 안드로이드 런처" 정도의 익명성.

## 3. 장면 팔레트 (12.3)

| 이름 | 값 | 쓰임 |
|---|---|---|
| 형광 백색 | #E8EEF0 | 경찰서, 편의점, 약국, 교무실 |
| 나트륨등 주황 | #E39A3B | 밤 거리, 네비 경로선, 주차장 일부 |
| 새벽 청회색 | #4A5866 | 집 새벽, 엔딩 A 새벽 |

## 4. 타이포

- 한글: 시스템 산세리프(애플 SD 산돌고딕 Neo / Noto Sans KR 폴백). 웹폰트 최소화(초기 로드 목표).
- 숫자: 탭 숫자(tabular-nums) — 한결 문자 금액, 메모 "남은 거"의 자릿수가 세로로 맞아야 스크롤 연출이 산다.
- 독백: 같은 폰트, 이탤릭 금지, 색만 `--muted`.

## 5. 모션

| 상황 | 모션 |
|---|---|
| 앱 열기/닫기 | 0.2s 확대/축소(평범) |
| AV-01 자동 닫힘 | 플레이어 입력 없이 0.35s 닫힘 — **평소보다 살짝 느리게**(누군가 닫는 느낌) |
| 기기 전환 | 0.4s 크로스페이드 + 색온도 |
| 시간 점프 | 상태바 숫자가 빠르게 롤링, 화면 어두워졌다 밝아짐 2.5s |
| 정적 연출(PIN 2초, 민재 5초) | 모든 모션 정지, 입력 무시 |
| 진동 시각화 | 0.5~2px 흔들림(`systems/audio-and-haptics.md` 패턴) |

## 6. 접근성

- 게임 내 텍스트 크기 배율 0.85 / 1.0 / 1.15(아버지 폰 기준 이미 큼). 옛 폰은 배율 적용하되 "작다"는 대비 유지(최소 13px).
- 대비비: 본문 4.5:1 이상(독백 `--muted`도 3:1 이상).
- 모든 음성에 자막(끌 수 없음).
- 흔들림 연출 끄기 옵션(전정 민감) — 진동 시각화·장면 흔들림 off.
- 스크린리더: 버튼 라벨 제공. 장면 일러스트는 alt 텍스트(간결한 묘사).
