# 스틸컷 시네마틱

> 근거: bible 12.3(1인칭 정지 이미지, 얼굴 금지), 2.3(인물은 모르는 것을 말하지 않는다), `ui/overlays.md` 5장(풀스크린 연출), `ui/meta-screens.md` 1장(첫 실행 흐름), `sessions/S01.md` 2장, `S02.md` 5장, `S14.md`.
> 구현: `prototype/tutorial/app.js`의 `CINE`, `playCine()` (CN-00, CN-01).

## 1. 정의

**폰을 내려놓은 시간.** 게임은 아버지의 폰 화면이 전부다. 시네마틱은 아버지가 폰을 내려놓고 고개를 든 순간에만 나온다. 그래서 문법이 고정된다.

```
폰 화면 → (폰을 내린다) 스틸컷 1~4장 → (폰을 든다) 폰 화면
```

- 시작: 폰 화면이 아래로 빠지고 스틸이 드러난다. 끝: 스틸 위로 폰(잠금화면)이 올라온다.
- 스틸컷은 정지 일러스트 + 느린 카메라(켄 번스: 6초에 확대 3~8%, 미세 이동). 컷 사이 1.2초 크로스페이드.
- 사운드는 환경음만. 음악 없음(`systems/audio-and-haptics.md`).

## 2. 규칙

| 규칙 | 내용 |
|---|---|
| 글 | 시각·날짜 스탬프 + **상황 자막**(v5.4). 자막은 3인칭 내레이션, **사실만**(날짜, 장소, 누가 없는지, 무슨 일이 있었는지). 컷당 최대 2줄, 한 줄 30자 안팎. 인물 대사·속마음 해석 금지. 독백은 이미 캐논에 있는 MO만 |
| 자막이 하면 안 되는 것 | KNOW를 주거나 앞당기기 / 아버지의 회피·빚을 서술하기(플레이어가 폰에서 **발견**해야 한다, S1 목표) / 다음 행동을 명령하기("~하라"). 다음 목적지를 사실로 말하는 건 된다("성원고로 간다") |
| 정보 | 시네마틱으로 KNOW를 주지 않는다. 플레이어가 폰에서 찾을 것을 미리 보여주지 않는다 |
| 인물 | 얼굴 금지(12.3). 손·뒷모습·실루엣만. 도현은 사진 속에서만 얼굴이 보인다 |
| 오독 금지 | 컷 안의 사물이 캐논과 어긋나면 안 된다. 예: 현관 컷에 도현 운동화가 보이면 "아들이 집에 있다"로 읽힌다 → 쓰지 않는다 |
| 소재 | 약물은 추상도 유지. 시네마틱에 약·거래 장면 없음 |
| 입력 | 탭 = 아직 안 나온 자막을 모두 띄움 → 한 번 더 탭하면 다음 컷. 우상단 `건너뛰기` = 전체 건너뛰기. 슬롯에 따라 막는다(아래 표의 "건너뛰기") |
| 시계 | 시네마틱 동안 게임 시계는 흐르지 않는다. 시간 점프가 있는 슬롯만 시계 롤링 컷을 쓴다(= FS.timejump 흡수) |
| 접근성 | `흔들림 연출 끄기` 또는 시스템 동작 줄이기 → 카메라 이동 없이 크로스페이드만 |
| 길이 | 슬롯당 8~16초. 자막이 있는 컷은 읽을 시간만큼 늘어난다(자막 한 줄 = 1.2초 + 글자당 60ms). 프롤로그 최대 24초 |

### 3-1. 자막 원고

> 기준: 처음 켠 사람이 폰 화면을 보기 전에 **누구의 폰이고, 무슨 일이 있었고, 지금이 언제인지**를 안다. 그 이상은 주지 않는다.

| 슬롯 | 컷 | 자막 |
|---|---|---|
| CN-00 | ① 검정 | (중앙) 2026년 3월 18일 수요일 |
| CN-00 | ② 복도 | 토요일 저녁, 늦는다는 문자를 끝으로 아들 도현은 집에 돌아오지 않았다. / 스무 살. 대학에 들어간 지 2주 만이었다. |
| CN-00 | ③ 방문 | 나흘째 되는 밤. 아버지 이상철은 아들 방 앞에 서 있다. / 손에 쥔 폰이, 지금 그가 가진 전부다. |
| CN-01 | ① 방문 03:30 | 그 뒤로도 잠은 오지 않았다. |
| CN-01 | ② 롤링 | (자막 없음) |
| CN-01 | ③ 아침 복도 08:40 | 아침이 왔다. 방문은 여전히 닫혀 있다. / 도현이 3년을 다닌 학교, 성원고로 간다. |
| CN-02 | ① 현관 | **없음.** 정적이 연출이다 |
| CN-03 | ① 셔터 ② 벤치 | 그날 약국은 평소보다 일찍 셔터를 내렸다. |
| CN-04 | ① 거실 테이블 | 저녁 7시 10분. 집에 돌아왔다. |
| CN-05 | ① 형광등 ② 뒷모습 | 밤 11시. 성원 공영주차장 지하 3층. |
| CN-E* | 엔딩별 | `sessions/S14.md`의 시간 자막("3일 뒤", "한 달 뒤")만. 엔딩에서 상황을 설명하지 않는다 |

- 매트릭스 확인: CN-00의 정보(이름, 나이, 입학 2주, 토요일 저녁 마지막 문자, 나흘)는 전부 아버지가 아는 사실이고, 폰의 도현 스레드("오늘 좀 늦어. 먼저 자", 3/14 토)로 플레이어가 바로 확인할 수 있다. 실종 신고, 경찰 분류, 빚은 말하지 않는다.
- "토요일 저녁" — 3/14는 토요일. 마지막 문자 18:52 ✓.
- CN-01 ③의 "성원고로 간다"는 S2 종료 독백 "성원고."와 네비 등록의 사실 확인이다(명령형 아님).

> CN-02는 "시네마틱"이라기보다 입력이 막힌 정지 화면이다. 같은 플레이어를 쓰되 건너뛰기를 숨기고 탭을 무시한다.
> 대화 장면(S3 교무실, S5 경찰서 등) 진입은 시네마틱이 아니다. 장소 도착 0.8초 페이드(`ui/scenes/scene-view.md` 3장)를 유지한다. 시네마틱이 잦으면 "폰을 내려놓는 순간"의 무게가 사라진다.

## 4. 첫 실행 흐름 (갱신)

```
콘텐츠 고지(1회) → 타이틀 → [시작] → CN-00 프롤로그 → 잠금화면 02:47 (S1)
```

- 콘텐츠 고지 문구는 `ui/meta-screens.md` 1.1 그대로. 고지와 타이틀은 시네마틱이 아니다(검은 배경 텍스트).
- S1의 실시간 10초 타이머(EV.S01.01)는 **CN-00이 끝나고 잠금화면이 올라온 순간**부터 센다.

## 5. 데이터 형식 (구현 기준)

```js
CINE['CN-01'] = {
  skip: true,
  cuts: [
    { img: 'hall_night', origin: '47% 74%', from: 'scale(2.35)', to: 'scale(1.7)', dur: 4200, stamp: '03:30',
      cap: ['그 뒤로도 잠은 오지 않았다.'] },
    { roll: ['03:30', '08:40'], dur: 2600 },
    { img: 'hall_night', filter: 'morning', from: 'scale(1.0)', to: 'scale(1.05)', dur: 4200, stamp: '08:40',
      cap: ['아침이 왔다. 방문은 여전히 닫혀 있다.', '도현이 3년을 다닌 학교, 성원고로 간다.'] },
  ],
  end: 'phone_up',
};
```

| 필드 | 뜻 |
|---|---|
| `img` | 스틸 에셋 키 |
| `origin` / `from` / `to` | 켄 번스 기준점과 시작·끝 변환 |
| `filter` | 같은 그림의 시간대 보정(임시). 신규 에셋이 오면 제거 |
| `text` / `stamp` | 화면 중앙 날짜 / 좌하단 시각 스탬프 |
| `cap` | 상황 자막 줄 배열. 하단에 한 줄씩 페이드인: 첫 줄 0.8초, 다음 줄은 앞 줄 읽을 시간(1.2초 + 글자당 60ms) 뒤, 최소 1.4초 간격. 컷 길이는 `max(dur, 마지막 줄 읽을 시간 끝 + 1초)` |
| `roll` | 시계 롤링 컷(시작, 끝) |
| `dur` | 컷 길이(ms). 탭하면 즉시 다음 컷 |
| `end` | `phone_up`: 끝에 잠금화면이 아래에서 올라온다 |
