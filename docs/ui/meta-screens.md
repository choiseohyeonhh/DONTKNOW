# 메타 화면 (타이틀·설정·크레딧·디버그)

## 1. 첫 실행 흐름

```
콘텐츠 고지(1회) → 타이틀 → [시작] (= 오디오 언락) → 검은 화면 2초 → 잠금화면 02:47 (S1)
```

### 1.1 콘텐츠 고지
- 검은 배경, 작은 흰 글씨: "이 게임에는 약물 범죄, 채무, 실종을 다루는 내용이 포함되어 있습니다."
- 아래: "소리를 켜고, 이어폰을 권합니다. 약 2시간 30분."
- [계속] 1개. 메타 세이브에 확인 기록, 이후 생략.

### 1.2 타이틀
- 검은 배경 위 "DONTKNOW". 부제 없음.
- 버튼: [시작] / [이어하기](세이브 있을 때) / [세션 선택](엔딩 1회 이상) / [설정]
- 하단 소문자: "홈 화면에 추가하면 전체 화면으로, 저장이 유지됩니다."(iOS Safari에서만)
- 타이틀 배경: 아주 옅게 잠금화면 배지 숫자 "47"이 보였다 사라짐(2회차부터는 0091 끝자리) [설계, P2].

## 2. 설정

| 항목 | 값 |
|---|---|
| 텍스트 크기 | 작게 / 기본 / 크게 |
| 음량 | 전체 / 음성 / 효과·환경 |
| 진동음 | 켜기/끄기 |
| 실제 진동 | 켜기/끄기(지원 기기만 표시) |
| 흔들림 연출 | 켜기/끄기 |
| 처음부터 | 확인 2회 |
| 모든 기록 삭제 | 확인 2회 |
| 크레딧 | |

- 게임 중 설정 진입: 아버지 폰의 **설정 앱이 아니라** 화면 우상단 바깥(데스크톱) 또는 잠금화면 길게 누르기(모바일) → 게임 메뉴. 아버지 폰 설정 앱은 게임 세계의 일부(차단 목록 등)로 분리.

## 3. 게임 메뉴 (일시정지)

- [계속] [설정] [타이틀로]
- 메뉴가 열리면 실시간 타이머 정지.

## 4. 엔딩 후

1. 엔딩 시퀀스 → 타이틀 카드 "DONTKNOW"(엔딩 공통, bible 7장 S14-7)
2. 크레딧(스크롤, 텍스트만). 엔딩 A는 크레딧 중 후일담 문자 배너(`systems/branching-and-endings.md` 4장)
3. 크레딧 후: 엔딩 A만 3초 검은 화면 + 경찰서 자동문 소리(bible)
4. 타이틀로 복귀. 엔딩 기록(메타 세이브).
5. **엔딩 목록 화면 없음**("엔딩 4개 중 1개" 같은 수집 UI 금지 — A를 정답처럼 보이게 만든다, 8.3). 세션 선택만 해금.

## 5. 세션 선택 (클리어 후)

- S1~S14 목록, 각 세션 제목(7장)만. 그 세션 시작 체크포인트에서 재개.
- 체크포인트는 **그 회차에 실제로 지나간 상태**. 다른 분기를 보려면 그 이전 세션에서 다시 선택해야 한다.

## 6. 디버그 패널 (`?debug=1`, 개발 빌드)

| 탭 | 기능 |
|---|---|
| 상태 | K/KX/F/FX/v 토글, 분기 코드, 세션 상태 |
| 시간 | 게임 시계 설정, 실시간 배속(넛지 ×10) |
| 큐 | 리액티브·고정 이벤트 대기열, 즉시 발화, 취소 |
| 점프 | 세션 시작으로 이동(필요 K/F 자동 세팅 프리셋: 캐논 경로/최소 경로) |
| 엔딩 | 현재 상태로 `resolveEnding` 미리보기, 전 조합표 |
| 로그 | 액션 로그 보기·내보내기·불러와 재생 |
| 검증 | 막힘 방지 불변식(`systems/progression.md` 5장) 실시간 체크 결과 |
