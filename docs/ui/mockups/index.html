아버지의 폰, 아들의 폰

DONTKNOW UI 시안 5종. 아버지 폰은 밝고, 글자가 크고, 정리되지 않았다. 도현의 옛 폰은 어둡고, 작고, 한 줄도 어긋나지 않는다. 두 폰의 차이가 두 사람의 차이라는 원칙(visual-style 1장)을 화면마다 지켰다.

폰 UI는 Noto Sans KR, 장면 대사만 Noto Serif KR. 폰 안의 글과 사람의 목소리를 서체로 나눈다.
