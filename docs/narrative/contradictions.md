# 6대 모순 — 구현 매핑

> 근거: bible 4장. 각 모순의 "주장"이 어느 세션·대화 노드에서 나오고, "해소"가 어떤 K·아이템으로 일어나는지를 구현 단위로 매핑한다.
> 원칙: 모순은 정답 판정이 없다. 해소는 **플레이어 머릿속**에서 일어나고, 시스템은 K 획득과 선택지 개방으로만 그 결과를 기록한다.

## 공통 규칙

- 주장 대사는 반드시 **원문 그대로**(bible 4장 문구) 한 번은 등장시킨다. 플레이어가 나중에 "그 사람이 그렇게 말했었지"를 떠올릴 수 있게.
- 해소 순간에는 **독백을 붙이지 않는다**(설명 금지). 예외는 bible에 명시된 독백만.
- 각 모순은 `v.contradiction_<n>_seen` 카운터로 노출 수를 기록(텔레메트리·QA용, 게임플레이 영향 없음).
