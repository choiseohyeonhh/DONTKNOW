# 대사 문체 가이드 (v5.4)

> 근거: bible 3장(인물 말투), 11장(대사 톤 샘플), 2.3(인물은 모르는 것을 말하지 않는다).
> v5.3까지의 대사는 소설 지문처럼 잘린 평서형("무슨 약? 무슨 소리야." "대학 친구들한테는 물어봤냐?" "그래, 지훈아. 무슨 일이냐")이 많아 사람 말로 들리지 않았다. v5.4에서 전 세션 대사를 이 가이드로 다시 썼다.
> 내용(누가 무엇을 아는가, K 획득 지점, 분기)은 하나도 바꾸지 않았다. **말하는 방식만** 바꿨다.

## 1. 대원칙

1. **소리 내어 읽었을 때 그 나이, 그 직업, 그 관계의 사람이 실제로 할 법한가.** 이게 유일한 기준이다.
2. 짧은 말 ≠ 잘린 말. 과묵한 인물도 어미와 물음표는 살린다. "무슨 약." → "무슨 약? 무슨 소리야."
3. **선택지 = 아버지가 실제로 치는 문장 / 하는 말 그대로.** 요약·지문 금지. "대학 친구들은." → "대학 친구들한테는 물어봤냐?"
4. 문자와 통화는 같은 내용이라도 **문장이 다르다.** 문자는 쪼개고 짧게, 통화는 말이 이어지고 고쳐 말한다. 한 노드에 두 버전을 둔다(`m:` 문자 버블들 / `c:` 통화 한 줄).
5. 정보 전달용 대사는 "누가 묻지도 않았는데 정리해서 말하는" 형태를 피한다. 사람은 생각나는 순서로, 덧붙이며 말한다("아 그리고", "근데", "그게…").
6. 감정은 여전히 **설명하지 않는다.** 문장 길이, 끊김, 정적으로 보여준다(bible 11장 유지).

## 3. 선택지 작성 규칙

- 선택지 버튼 텍스트 = 보내지는 문자 / 하는 말. 문자 모드와 통화 모드에서 같은 선택지라도 문장이 다를 수 있다.
- 길이: 문자 22자, 통화 28자 안팎. S13 ①만 예외(유지).
- 행동 선택지는 괄호: "(전화한다)", "(사진을 보여준다)", "…"(말하지 않는다).
- 같은 지점의 선택지끼리 말투 높낮이가 튀지 않게(한쪽만 문어체 금지).

## 4. 그대로 둔 것

| 항목 | 이유 |
|---|---|
| 아버지 독백 한 줄들("…나중에." "성원고." "2년." "준호." "중3?") | 말이 아니라 속생각. 짧은 명사형이 맞다 |
| 도현 음성메모 전문, 엔딩 A 통화, 포스트잇 "버리라고 했는데 못 버렸어요." | 이미 구어이고 `[CANON] 수정 금지` |
| 형의 캐논 대사(첫인사, 고백, 독백, 제안, "봐요. 아버님은 아직도 몰라요.") | 형은 원래 다듬어진 말을 하는 인물. 문체가 성격이다 |
| 옛 폰 메시지(형·준호·유진 스레드) | 당사자끼리의 짧은 반말 문자라 이미 자연스럽다 |
| 시스템 문자(한결, 은행, 대학교, 광고) | 사람 말이 아니다 |

## 5. 검수 체크리스트

- [ ] 소리 내어 읽었을 때 걸리는 데가 없다
- [ ] 아버지 선택지에 "~니." "~는." 같은 잘린 평서형이 없다
- [ ] 문자 버블에 소설식 따옴표 인용("내일 끝난다"고)이 없다 → 풀어서 쓴다
- [ ] 인물이 모르는 것을 말하지 않는다(2.3) — 문장을 늘리다 정보가 새지 않았는지 다시 확인
- [ ] 마약 소재는 "약 / 그거 / 그 일"(민재 예외)
