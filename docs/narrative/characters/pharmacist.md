# 최미경 — 최 약사

> 근거: bible 3.7, 7장 S9. 아버지의 거울. "알 수 있었는데 안 알려고 했던 어른."

## 1. 기본

| 항목 | 값 |
|---|---|
| 나이 | 56 |
| 장소 | 새봄약국. 평일 마감 19:00 [ISSUE-14] |
| 등장 | S9 대면 |
| 증언의 성격 | 도현에 대한 변호 + 자기 자신에 대한 고발 |

## 2. 기억하는 것 (매트릭스)

| 기억 | 확실도 | 대사 근거 |
|---|---|---|
| 2025년 봄부터 1년 가까이 | 확실 | "작년 봄부터였으니까… 1년 가까이 됐네요." |
| 같은 학생이 여러 병원 처방전을 번갈아 | 확실 | (수법 디테일 없이) "처방전이 매번 다른 데서 왔어요." |
| 수령자 = 작은 애, "준호"로 불림 | 확실(호칭은 들은 것) | "준호라고 불렀던 것 같아요." |
| 사진 속 학생(도현)이 거의 매번 동행, 밖에서 대기, 시계를 자주 봄 | 확실 | "꼭 일정표 있는 사람처럼." |
| 늘 **화요일 낮** | 확실 [ISSUE-15] | "늘 화요일 낮이었어요. 평일 대낮에 교복 입은 애가 오니까 기억이 나요." |
| 1월 어느 밤, 벤치에서 혼자 울던 도현 | 확실 | "1월이었나, 문 닫을 때쯤이었는데요. 저 앞 벤치에서 혼자 울고 있더라고요. 들어오라고 할까 하다가… 안 했어요." |
| 도현의 이름 | 모름 | "이 학생"으로만 |
| 유통망·형·유진 | 모름 | 언급 금지 |

> "1월 밤"은 겨울방학이라 화요일 낮 규칙과 충돌하지 않는다(방학 중엔 시간대가 바뀌었다). 이 설명은 대사로 하지 않는다.

## 3. 3단계 구조와 태도

| 단계 | 태도 | 아버지 입력 |
|---|---|---|
| 경계 | 영수증을 보고 굳음. "죄송한데 그건 개인정보라 말씀 못 드려요." | 압박 / 사진 |
| 증언 | 사진에 손이 멈춤. 천천히. 손님이 빠질 때마다 말이 길어짐 | 짧은 추궁 |
| 자백 | 아버지의 "그걸 다 보시고도, 왜 신고를 안 하셨습니까."에 대한 대답 | |

자백 대사(원문 유지):
> "확인 전화 한 통이면 됐어요. 근데 안 했어요. 내 일 아니라고 생각했고… 매출도 있고요. …아버님도 모르셨잖아요. 저도 몰랐던 걸로 했어요. 그렇게 하면 편하니까."

## 4. 압박 경로 [ISSUE-08]

- 압박 1회: 방어적. "경찰이요? …그럼 경찰한테 말할게요." 정보 최소. 사진 선택지는 남는다(회복 가능).
- 압박 2회: "이제 그만 가 주세요." 세션 종료. `KX-17a`(수령자 준호, 화요일)만 획득. K-17 미획득. 자백 없음.
- 압박 경로에서도 "준호"라는 이름과 화요일은 나온다(진행 보장). 나오지 않는 것은 **도현의 눈물과 약사의 자백**.

## 5. 금지

- 처방 내용, 약 이름, 조제 절차 언급 금지.
- 최 약사가 "신고하겠다"고 약속하는 대사 금지(그녀의 아크는 증언까지).
