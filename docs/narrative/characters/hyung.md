## 3. 말투

- 의외로 정중한 존댓말. "아버님"을 문장마다 붙이다시피 한다.
- 협박을 배려 형태로: "아버님 건강 챙기세요. 도현이가 걱정해요."
- 웃음이 섞인 말투가 기본. **웃음을 멈추는 순간**이 두 번 있다: K-22 제시 시, 고백(①) 시.
- 거짓말: "유진? 처음 듣는 이름인데요." / "도현이가 먼저 왔어요."(반만 진실) / "옛날 폰? 그거 없앴는데."(진실이라고 믿고 있음 — 엄밀히는 거짓 아님)

## 4. S13 동기와 목표

- 22:40에 전화하는 이유(분기별) [ISSUE-06 관련]:

| S12 결과 | 형이 받은 신호 | 형의 판단 |
|---|---|---|
| A-2 | 유진 보고 "아버님 아무것도 모르세요" | 침묵 거래를 마무리할 때. 얕봄 |
| A-1, A-3 | 유진 연락 두절 | 뭔가 새고 있다. 직접 확인해야 한다 |
| B-2 | 준호 잠적, 준호 어머니 수소문 | 아버지가 준호를 건드렸다 |
| B-3 | 준호 경찰 연행 정보 | 시간이 없다 |
| 공통 | 아버지가 하루 종일 움직였다(감시) | 오늘 밤 안에 정리 |

- S13 목표: 아버지가 무엇을 아는지 파악 → 침묵을 사는 것.

## 5. 미화 방지 규칙 (13.2-2)

1. 형의 독백(2단계) 직후 반드시 거래 제안(3단계)을 붙인다. 독백과 제안 사이에 플레이어 입력을 넣지 않는다 → 고백조차 협상 도구였을 가능성.
2. 엔딩 A에서 형의 놓아줌은 계산과 병존한다 [ISSUE-06]: 06:00 이후 0091 결번.
3. 형에게 동정적 BGM 금지. S13은 환기팬 소리만.
4. "붙잡는 게 사랑이 아닌 건 알아요"는 원문 유지. 형은 자기 통제를 안다. 그래서 더 나쁘다.

## 6. 캐논 대사 (원문 유지)

- "아버님, 처음 뵙겠습니다. 도현이가 말 많이 했어요. 아, 좋은 말은 아니고요."
- "도현이가 먼저 왔어요. 고2 때, 준호 빼달라고. 그리고 이번엔 그만두겠다고. 그래서 붙잡았어요. 2년을 데리고 있었는데, 문자 한 통으로 끝내자는 게 말이 됩니까."
- 독백 2문단(7장 S13) 전문.
- 제안: "아버님 빚, 남은 3천 제가 정리해 드릴게요. 도현이가 모아둔 자취 보증금도 그대로 두고요. 학교도 계속 다니게 하고요. 대신 아버님은 아무것도 모르는 걸로 하세요. 지금까지처럼. 2년 반 동안 잘 하셨잖아요."
- 3/15 부재중 언급: "그날 받으셨으면 얘기가 달랐을 텐데."(10.2) — 1단계 또는 3단계 직전, K-09 보유 + `KX-05`(0091 부재중 발견) 여부와 무관하게 1회.

## 7. 형이 아는 것 / 모르는 것 (매트릭스 요약)

- 안다: 도현의 모든 것(빚, 상환, 보증금, PIN), 유진의 역할, 준호, 아버지의 회피 2년 반.
- 모른다: 옛 폰이 아버지에게 갔다는 것(K-18 제시 전까지), 음성메모·초안, 아버지가 경찰에 무엇을 말했는지(F-03 여부는 형이 추정만 함 — F-03 상태에서 형의 첫 대사 변형: "경찰서 다녀오셨다면서요. 그래도 혼자 오셨네요.").
