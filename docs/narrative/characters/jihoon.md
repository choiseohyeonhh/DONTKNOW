# 정지훈 — 지훈

> 근거: bible 3.9, 7장 S1·S2, 5.6. 튜토리얼 가이드이자 막힘 방지 장치. 거의 유일하게 거짓말하지 않는 인물.

## 1. 기본

| 항목 | 값 |
|---|---|
| 나이 | 스무 살, 동갑, 성원고 동기, 재수생(성원역 근처 재수학원) |
| 생활 | 새벽까지 깨어 있음 → 02:47 연락 가능 |
| 연락처 | "정지훈(도현친구)" 2년 전 저장. 3/15 부재중 2, 문자 1(미읽) |
| 결함 | 작은 회피자. "집에 무슨 일 있나 보다" 하고 묻지 않았다 |
| 약속 | 도현이 "말하지 말라고" 했다 → 4일 망설임 |

## 2. 말투

- 아저씨에게 예의 바르지만 급하다.
- **문자를 여러 개로 쪼갠다**(한 버블 = 한 생각, 버블 간격 0.6~1.2초).
  > 아저씨 자고 계세요 / 도현이가 말하지 말라고 했는데요 / 저 할 말 있어요
- 통화에서는 말이 빠르고 자기 말을 정정한다.
  > "아저씨 근데 이거 제가 말했다고 하면 안 돼요… 아 아니다 해도 돼요. 도현이만 찾으면."

## 4. 넛지 역할 (5.6)

- 지훈은 유휴 90초 넛지의 기본 발신자다. 넛지 문장은 **지훈이 알 수 있는 범위**에서만 쓴다.
  - 가능: "아저씨 혹시 준호한테 연락해보셨어요?" "학교는 가보셨어요?" "경찰은 뭐래요?"
  - 불가: "약국 가보세요" (지훈은 약국을 모른다) → 이 구간 넛지는 김 형사나 독백이 담당.
- 지훈의 문자에 아버지가 답장하면 짧은 대화가 이어진다(`HUB.jihoon.*`).

## 5. F-04 경로

K-15 이후 허브에서 아버지가 "도현이가 약을 팔았다더라." 선택 → F-04. 지훈 반응:
> "…아저씨 그거 누가 그래요" / "도현이 그런 애 아니에요" / "아저씨까지 그러면 안 되잖아요"

F-04는 김 형사 경로와 달리 확인 다이얼로그 없음(사적 단정). 그 뒤 지훈의 문자가 줄어든다: 이후 지훈 넛지 발신자 비중을 김 형사·독백으로 이동.
