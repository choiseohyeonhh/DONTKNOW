## 3. 플레이어와의 비대칭

- 아버지는 빚을 알지만 플레이어는 모른다. **게임은 처음부터 빚을 설명하지 않는다.**
- 독백·선택지에서 S10 전까지 "빚", "채무", "한결"이라는 단어를 아버지가 먼저 쓰지 않는다. 예외: S1 한결 문자를 열었을 때의 독백 "…나중에."(대상이 무엇인지 말하지 않음).
- S10 이후 선택지에서 처음으로 빚을 지칭할 수 있다. S13 ①이 최초의 "소리 내어 말하기".

## 4. 말투

- 짧다. 감정 단어 거의 없음.
- 존댓말/반말 경계 엄격:

| 상대 | 말투 | 예 |
|---|---|---|
| 지훈(아들 친구) | 반말, 다정하지 않음 | "도현이 아빠다. 늦은 시간에 미안하다." |
| 준호(아랫집 아이) | 반말 | "말해. 안 혼낸다." |
| 유진(22) | 존댓말(처음 보는 성인) → 의심 시 반말로 흔들림 가능 | "고마워요, 연락 줘서." |
| 김 형사 | 존댓말 | "도현이 아빠입니다. 잠깐 시간 되십니까." |
| 담임·상담교사·약사·장 사장 | 존댓말 | "제 아들입니다." |
| 형 | 반말(나이·분노). S13 내내 | "네가 먼저 불렀잖아. 18시 39분에." |
| 민재 | 반말, 단문 | "무슨 약." |

- 선택지 길이: 20자 내외. S13 ①만 예외.
- 물음표를 잘 쓰지 않는다. 의문도 평서형 어미로("무슨 약." "왜 신고 안 하셨습니까.").

## 5. 독백 (잠금화면 알림 형태)

- 형식: `…` 로 시작하는 한 줄, 15자 이내 권장.
- bible 확정 독백: "…나중에."(S1), "성원고."(S2), "2년."(S3), "준호."(S6), "중3?"(S7), "…같은 날이다."(S9 대조), "…내 생일은 기억할까."(PIN 5회 실패), 유휴 300초 독백(예: "그 영수증… 약국 이름이 뭐였지.").
- 독백 금지 구간: S8 민재 이후 정적 5초, S11 전체, S13 전체.
- 전체 목록과 트리거는 `systems/avoidance-and-monologue.md`.

## 6. S13 ① 대사(캐논, 원문 유지)

> "그 빚, 내가 숨긴 거다. 도현이가 갚은 거 오늘 알았다. 3년 동안 아무것도 안 물어본 건 나다. 그러니까 이번엔 내가 갚는다. 도현이 데려와."
> "그리고 내일 아침 아홉 시에, 도현이랑 같이 경찰서 간다. 걔가 한 일은 걔가 말해야 한다. 나는 옆에 있을 거다."

두 번째 문단은 ① 선택 시 **자동으로 이어지는** 대사다(별도 선택지 아님). 이게 엔딩 A를 형의 자비가 아니라 아버지의 결단으로 만든다(7장 S13 트루 루트 보강).
