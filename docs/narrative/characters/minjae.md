# 오민재 — 민재

> 근거: bible 3.6, 7장 S8. 형의 공작이 형의 단서가 되는 아이러니의 운반자.

## 1. 기본

| 항목 | 값 |
|---|---|
| 나이 | 26 |
| 정체 | 유통망 최하단 구매자 |
| 등장 | S8 단 1회. 인터폰 화면 + (문 열기 시) 현관 |
| 육성 | 실제 녹음(인터폰 음질 필터) |
| 기능 | 아버지에게 "내 아들이 가해자"라는 공포 → 김 형사에게 말 못 하게 만드는 장치(형의 의도) |

## 2. 말투

- 현재형·과거형 혼용. 같은 말 반복. 문장 단위가 아니라 덩어리로 터진다.
  > "줘. 도현이가 준대. 도현이가 줬어. 줘!"
- "마약"이라는 단어를 쓸 수 있는 유일한 인물. 단, S8에서도 1회 이하. 기본은 "약".
- 욕설은 거칠어도 짧게, 텍스트에서는 1회 이하.

## 3. S8 대사 축

1. 인터폰: "도현이 있어요? 도현아! 나와 봐!"
2. "도현이가 나한테 약을 줬어! 줘야 돼, 도현이가 준대!"
3. (아버지 "무슨 약? 무슨 소리야.") → "유진이가 그랬어. 그 집 가서 말하라고. 아니, 유진이가 아니라…"
4. 이웃 문 열리는 소리 → 도주

## 4. 민재가 아는 것 / 모르는 것

- 안다: "도현이"라는 이름, "유진이", 이 집 주소(유진이 알려줌).
- 모른다: 도현의 얼굴(인터폰에 아버지가 보여도 아들인지 아버지인지 판별 못 함), 형, 도현이 그만둔 것(그래서 현재형).
- 영수증: 본인이 받은 약봉투에 붙어 있던 새봄약국 영수증. 의도치 않게 떨어뜨림.

## 5. 연출 규칙

- 얼굴은 인터폰 화질로만. 땀, 흔들리는 프레이밍.
- 민재 퇴장 후 현관 정적 5초, **독백 없음**.
- 민재를 괴물로 그리지 않는다. 그도 이 구조의 바닥에 있는 사람이다. 퇴장 직전 한 줄(선택): "…도현이가 준댔는데." 작게.
