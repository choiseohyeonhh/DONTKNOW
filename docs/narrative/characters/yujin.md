# 차유진 — 유진

> 근거: bible 3.4, 4장 모순 3·6, 7장 S4·S12. 형의 감시자. 옛 폰을 버리지 못한 순간 이미 형을 배신했다.

## 1. 기본

| 항목 | 값 |
|---|---|
| 나이 | 22 (2023년에 19) |
| 역할 | 신입 모집·감시. 준호를 끌어들인 장본인 |
| 겉 | "도현이 여자친구"라며 나타난 침착한 대학생 |

| 아크 | 감시자 → 배신자 → 도피자(A-3 캐논) / 자수자(A-1) / 잔류자(A-2) |

## 2. 말투 규칙 (성우·텍스트 연출 공통, 필수)

| 상태 | 문장 | 예 |
|---|---|---|
| 거짓말 `[LIE]` | 길다. 쉼표·접속어 많음. 매끄럽다. 디테일이 지나치게 정확 | "도현이가 요즘 집 얘기를 자주 했어요, 숨이 막힌다고, 아버님이랑 대화가 없다고, 저한테만 그런 얘기를 한다고요." |
| 진실 `[TRUE]` | 짧다. 한 문장, 10자 내외 | "좋아했어요. 진짜로." |
| 흔들림 | 한 박자 늦는다 → 텍스트 연출: 타이핑 표시 2초 추가 후 짧은 문장 | (K-06 의심 선택지 이후) "…네?" |

텍스트 UI에서 리듬 차이를 느끼게: 거짓 문장은 한 버블에 길게, 진실 문장은 버블을 분리해 짧게.

## 4. S12 분기 대사 기준

| 코드 | 핵심 |
|---|---|
| A-1 자수 | "…나가고 싶었어요. 도현이가 같이 나가자고 했었는데." → "내일 그 형사님한테 갈게요." 진실 문장만 짧게 이어진다 |
| A-2 잔류 | 거짓 리듬 유지. "아버님, 저도 걱정돼서 그래요, 혹시 뭐 알게 되신 거 있으면, 저한테 먼저…" 형에게 보고 |
| A-3 도피(캐논) | "그거, 제가 둔 거 맞아요." / "도현이 좋아했어요, 진짜로." / "…저 이제 도망갈 거예요. 죄송해요." / 핵심: "형이 다 지우라고 했는데, 안 보낸 문자가 하나 있더라고요. '아빠, 나 사실.' 그거 보고 못 지우겠더라고요. 저는… 그런 거 보낼 사람이 없어서." → 번호 해지 |

## 5. 유진이 아는 것 / 거짓말 목록

| 주장 | 진실 | 표기 |
|---|---|---|
| "도현이 여자친구예요." | 아님 | LIE |
| "준호가 문제였어요." / "준호가 도현이를 이용했어요." | 유진이 준호를 끌어들였다 | LIE |
| "도현이는 도망친 거예요. 아버님한테서요." | 형에게 붙잡혀 있다 | LIE |
| "도현이가 요즘 집에 있으면 숨이 막힌다고 했어요." | 도현은 아버지를 원망하지 않았다. 다만 대화가 없었던 건 사실 | PARTIAL |
| "도현이한테 연락 오거나 뭐 생각나시면 여기로 연락 주세요. 저도 도현이 물건 중에 뭐 나오면 바로 연락드릴게요." | 옛 폰을 이미 갖고 있다 | PARTIAL |
| "경찰서에 다녀왔어요"(S4에서 먼저 말하지 않음) | 아침에 경찰서에서 "가출 암시" 진술 | 은폐 |

## 6. 금지

- S4에서 형, 약, 약국을 언급하지 않는다.
- 유진은 민재가 언제 갈지 안다(본인이 보냄). S8 이전 허브 대화에서 민재 관련 암시 금지.
- 유진이 우는 장면 금지(텍스트 "…"로만).
