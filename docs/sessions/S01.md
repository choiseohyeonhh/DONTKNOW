### 3.1 부재중 목록 (플레이어가 열면)
- 구성(`content/father-phone-data.md` 2장): 대부분 모르는 번호, 3/16·17 경찰 대표번호 2(미저장 — 플레이어는 경찰인지 모름), 103호 1, 배차실 3, 지훈 2, 0091 1. **도현 0건.**
- 발신 기록에는 도현에게 건 6통(3/14~15, 전부 전원 꺼짐)이 섞여 있다 [ISSUE-18].
- 아버지가 "47"을 하나하나 확인하지 않아도 진행된다.

### 3.2 메시지 23건 (플레이어가 열면)
- 맨 위권에 도현 스레드: 마지막 "오늘 좀 늦어. 먼저 자"(3/14 18:52) [ISSUE-31].
- 한결 1600-XXXX 스레드(미읽 11)를 열면 **AV-01**: 1.2초 후 독백 "…나중에." → 메시지 앱 저절로 닫힘 → `FX-02`. 다시 열면 닫히지 않는다(bible). 다시 열어 보는 것은 **선택적 복선**.
- 스팸·대학교 안내도 열 수 있다. 이벤트 없음.

### 3.3 지훈 문자 (EV.S01.01)
```
지훈: 아저씨 자고 계세요
지훈: 도현이가 말하지 말라고 했는데요
지훈: 저 할 말 있어요
```
- 버블 간 1초, HP.burst. 잠금 상태면 잠금화면 알림, 사용 중이면 배너.
- 이 스레드에는 3/15 "아저씨 도현이 집에 있어요?"(미읽)가 위에 있다 → 지훈은 이미 사흘 전에 물었다.
