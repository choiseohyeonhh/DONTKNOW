## 엔딩 B — "면회실" (B / B+ / B-silent)

| # | 장면 |
|---|---|
| B1 | 자막 "3일 뒤". 3/21(토). 김 형사 문자: "아버님, 아드님 찾았습니다. 서로 와 주셔야겠습니다." |
| B2 | (텍스트 컷) 마약수사계가 형의 오피스텔을 급습. 도현은 구조되지만 동시에 피의자로 입건. 형: FX-03 또는 F-03 → 검거 / D-3 && !FX-03 → 도주. 김 형사 문자 한 줄로만 |
| B3 | 진술실 유리창 너머(`ART.scene.interrogation_glass`). 구치소가 아니다. 도현이 아버지를 본다 |
| B4 | 도현(실제 녹음, 유리 너머 먹먹): "…아빠는 몰라도 됐는데." |
| B5 | 아버지: **선택지 없음. 아버지는 말하지 못한다.** 5초 정적 |
| B+ | (K-19 && K-20, B-silent 아님) 선택지 하나가 생긴다: **"나도 너한테 말 안 한 거 있어."** → 도현이 처음으로 고개를 든다(실루엣 각도) → 컷 |
| B-silent | (F-03 + ④) S13 말미에 스피커폰 장면이 있었다. 진술실에서 도현은 고개를 들지 않는다. B4 대사 없음. 선택지 없음. 컷 |
| B6 | 타이틀 → 크레딧 |

- 성격: 정의로운 선택이 관계를 잃게 만드는 엔딩. **배드 엔딩이 아니다.** 아들은 살았고, 법은 작동했고, 아버지는 여전히 아들에게 자기 빚을 말하지 못했다(B+ 제외).
- 처벌 수위 묘사 생략. 유리창에서 끊는다(13.1).
- 도현이 성인 피의자라는 무게(범행 대부분은 미성년 시기라는 아이러니)는 대사로 설명하지 않는다.
