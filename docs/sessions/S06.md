| 비트 | 내용 | 효과 |

| b01 | 장 사장, 처음엔 귀찮아함. "아, 그거 경찰한테 다 얘기했는데…" | |
| 선택 | `CH.S06.01` **"그 애가 제 아들입니다."** / `CH.S06.02` "잠깐이면 됩니다. 부탁드립니다." | 01 → 태도 변화. 02 → "지금 좀 바빠서 그러는데…" 후 01만 남음 |
