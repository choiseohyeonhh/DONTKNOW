## 3. 준호 (B 분기)

| 코드 | 조건 | 흐름 |
|---|---|---|
| **B-3 붙잡힘** | F-03 && F-02 | 준호에게 걸면 받지 않음 → `RE.13` 김 형사 문자 "박준호 학생 저희가 먼저 데려왔습니다." 준호가 모든 걸 도현 탓으로 진술(후일담 비표시, 엔딩 B 무게) |

| **B-2 도피**(캐논) | F-02 | 아버지가 걸면 짧게 받음: "아저씨도 신고하셨다면서요. …저 살고 싶어요." 끊김. 이후 꺼짐. `RE.12`: S13 이동 중 103호 착신 "도현이 아버지… 우리 준호가 집에 안 들어와요." |

- B-2의 "아저씨도 신고하셨다면서요"는 원망이 아니라 체념의 톤.

## 4. 종료 — 22:40 형의 착신

- 분기 확정 후 20초 → 시계 22:40 점프 → **저장되지 않은 번호로 전화. 010-5XXX-0091.**(K-09 있으면 "기타 번호"로 이미 알고 있지만 이름이 없다 [ISSUE-25])
- 받으면(형 음성, 전화 대역):
  > 형: "아버님. 이제 얼굴 한번 봬야죠. 성원 공영주차장, 지하 3층. 열한 시요. 혼자 오세요." (F-03이면: "경찰서 다녀오셨다면서요. 그래도 혼자 오세요.")
- 거절하면 20초 뒤 재착신 + 문자 "아버님, 받으세요."
- 통화 후 네비 "성원 공영주차장" 등록 + 시트. **플레이어가 눌러야 출발**(망설임을 준다).
- `S12 done`. 김 형사·지훈 허브는 **출발 시트를 누르는 순간 잠김**(F-03·F-04 마지막 기회는 이 시트 앞까지).
