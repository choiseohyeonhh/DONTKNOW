# S2. 지훈 (8분)

> 근거: bible 7장 S2, 3.9, 5.2(K-01~05). 1막. 튜토리얼 가이드.

## 1. 개요

| 항목 | 값 |
|---|---|
| 시각 | 02:50 ~ 03:30 (고정) |
| 장소 | 집(통화/문자) |
| 채널 | 문자로 시작 → 플레이어가 전화 걸기 선택 가능(통화가 더 많은 정보) |
| 획득 | K-01, K-02, K-03 (문자·통화 공통) / K-04, (K-05), KX-02, KX-04 (통화 전용) |
| 플래그 | `FX-01`(통화 선택 시), `v.s2_mode` |

## 2. 진입

- S1 종료 = 지훈 스레드 열림. 입력창이 활성(처음으로 "선택지 시트"를 보는 순간 — 튜토리얼).
- 첫 선택지(문자):
  - `CH.S02.01` "무슨 일이니." → 문자 모드 진행
  - `CH.S02.02` [전화 걸기] (스레드 헤더 전화 아이콘에 미세 강조 없음 — 선택지 시트 안에 "(전화한다)"로 제공) → 통화 모드, `FX-01`
- 아버지 첫 대사 톤(11장): 통화 시 "도현이 아빠다. 늦은 시간에 미안하다."

## 3. 비트 — 공통 노드 (문자·통화 동일 내용, 렌더만 다름)

| 노드 | 지훈 | K |
|---|---|---|
| `#why` | "4일 참았는데 도저히 못 참겠어요." | |
| `#change` | 3월 초부터: 점심 안 먹음, 폰 자주 봄, 웃음이 줄었다 | **K-01** |
| `#tomorrow` | 3/13 밤 재수학원 앞으로 찾아옴: "내일 끝난다." 무슨 뜻이냐니까 "대학 오기 전에 끝냈어야 했던 거"라고만. "대학 생활 어떠냐"엔 웃기만 | **K-02** |
| `#junho` | "아랫집 고2요. 요즘 둘이 자주 다녔어요." | **K-03** |
| `#hyung` | (통화만) "형이 어쩌고 하면서 통화하는 걸 들었어요. 친형 아니죠?" | **K-04** |

- 문자 모드: 지훈이 위 내용을 연발 버블로(한 버블 = 한 생각). `#hyung`은 문자에서 나오지 않는다 — 지훈이 "이건 전화로 말씀드릴게요"라고 쓰고, 아버지가 전화 선택지를 고르지 않으면 넘어간다.
- 통화 모드: 자막 + 아버지 선택지.
