## 4. 연출 규칙 (필수)

- 유진의 거짓말 문장은 **길고 매끄럽게**, 진실 문장은 **짧게**. 대면 대사창에서: 거짓 = 한 박스에 3줄 꽉, 진실 = 한 줄.
- 이 세션의 유진 대사엔 진실 문장이 거의 없다 — 리듬의 기준선을 여기서 학습시킨다. S12에서 짧은 문장이 나오면 플레이어가 차이를 느끼도록.
