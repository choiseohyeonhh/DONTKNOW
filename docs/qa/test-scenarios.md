# 테스트 시나리오

> 각 시나리오는 Playwright 자동 플레이(액션 로그 재생) 또는 수동 체크로 수행. 기대 결과는 상태(K/F/분기/엔딩)와 화면 둘 다 확인.
> 디버그 패널 점프 프리셋: `canon`(bible 캐논 경로), `min`(필수 K만), `max`(모든 선택 K).
