## 1. 라운드

| 라운드 | 빌드 | 인원 | 목적 |

| PT0 | M2 수직 슬라이스(S1~S2) | 3~5 | 폰 UI 학습 가능성, S1 회피 연출이 "발견"되는가 |

- 기기: iPhone(필수, Safari + 홈 화면 PWA), Android 1대, 데스크톱 1대.

## 3. 인터뷰 (플레이 직후, 10분)

| 질문 | 확인하려는 것(리스크) |
|---|---|
| 처음 30분 동안 무엇이 궁금했나요? | 1.5 "불안 + 안 읽은 게 왜 이렇게 많지" |
| 누구를 가장 의심했나요? 순서대로. | 1.5 의심의 이동(준호 → 유진 → 도현 → 형) |
| 약국 장면 후 도현에 대해 어떻게 생각했나요? / 옛 폰 이후엔? | 13.2-1 S9·S11 감정 분리("피해자" vs "나 때문") |
| 아버지가 2년 반 동안 몰랐다는 게 납득됐나요? | 13.2-6. "말이 안 된다" 20% 이상이면 `opt.extra_doubt_monologue` ON |
| 형에 대해 어떻게 느꼈나요? | 13.2-2 미화 여부("이해는 하되 용서는 안 한다") |
| "언제부터였지?"가 헷갈린 순간이 있나요? | 13.2-5 시간 계단이 공포로 작동했는가, 혼란이었는가 |

## 4. 관찰 체크(진행자)

- S1에서 자동 닫힘 후 다시 여는가(회피를 거스르는 첫 행동).
- S10 PIN 해제 순간 반응(정적 2초에 무슨 말을 하는가).
- S11에서 두 폰을 몇 번 전환하는가(`v.device_switches`), 같은 금액을 소리 내어 맞추는가.
- S13 ① 텍스트를 끝까지 읽는가(선택까지 시간).

## 5. 데이터 수집

- 플레이테스트 빌드는 종료 시 액션 로그 JSON 다운로드 버튼 노출.
- 로그 → 집계 스크립트(설계: `tools/analyze-logs`) → 지표 표 자동 생성.
- 개인정보: 로그에 기기 식별자·이름 없음.
