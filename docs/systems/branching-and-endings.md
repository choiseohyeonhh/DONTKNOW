# 분기와 엔딩 판정

> 근거: bible 8장, 7장 S12·S13, 5.3. 판정 우선순위는 [ISSUE-07], K-17 처리는 [ISSUE-08] 기준(v5.3 캐논, bible 8.1).

## 1. 분기 코드 판정

### 1.1 유진 — A 코드 (S12 유진 통화 종료 시)

| 순서 | 코드 | 조건 |
|---|---|---|
| 1 | A-2 잔류 | `F-01` |
| 2 | A-1 자수 | `K-17 && K-22 && KX-21 && FX-06 && !F-01` |
| 3 | A-3 도피(캐논) | 그 외 |

- FX-06 = S12 통화 중 선택지 "너도 나가고 싶었던 거 아니냐."를 고름. 선택지 노출 조건: `KX-21 && !F-01`(F-01이면 아버지는 유진을 의심하지 않으므로 이 질문을 할 근거가 없다).
- K-17, K-22가 없으면 FX-06을 골라도 A-3(유진은 아버지가 "다 안다"는 확신이 없어서 도망친다). 이때 유진의 대답: "…그런 거 없어요." 후 A-3 대사.

### 1.2 준호 — B 코드 (S12 준호 접촉 종료 시)

| 순서 | 코드 | 조건 |
|---|---|---|
| 1 | B-3 붙잡힘 | `F-03 && F-02` |
| 2 | B-1 보호 | `F-02b` (F-03 여부 무관 — F-03이면 B-1 변형: "경찰서에 같이 가요"가 이미 진행 중인 수사와 합류) |
| 3 | B-2 도피(캐논) | `F-02` |

F-02와 F-02b 중 하나는 반드시 있다(S7 필수 선택).

### 1.3 형 — D 코드 (S13 최종 선택)

| 선택 | 노출 조건 | 결과 코드 |
|---|---|---|
| ① 고백 | `K-19 && K-20` | D-1 (F-05) |
| ② 거래 수락 | 항상 | D-2 (F-06) |
| ③ 신고 통보 | `!F-03` | D-3 |
| ③' 이미 말했다 | `F-03` | (③의 F-03 변형) "이미 경찰에 다 말했다." → 형 "그럼 도현이도 같이 들어가겠네요." |
| ④ 단죄 | `F-04 \|\| !K-17` [ISSUE-08] | (C 경로) |

- ②는 F-03 상태에서 텍스트 변형: "…신고 취소하겠다." → 형 "이미 늦으셨어요."
- A-2(F-01)면 1단계 탐색에서 유진 관련 선택지(`CH.S13.01`)가 사라진다 [ISSUE-26].

## 2. 엔딩 판정표 (S13 종료 시, 위에서부터 첫 매치)

| 순서 | 조건 | 엔딩 | 변형 |
|---|---|---|---|
| 1 | `v.s13_choice == 4 && !F-03` | **END-C** "모르는 아버지" | |
| 2 | `F-03` | **END-B** "면회실" | ④였으면 `B-silent`, 그 외 `K-19 && K-20`이면 B+ 선택지 |
| 3 | `v.s13_choice == 3` | **END-B** | D-3, 형 도주(FX-03 있으면 검거). `K-19 && K-20`이면 B+ |
| 4 | `v.s13_choice == 1` | **END-A** "이제 알았어" | 후일담: A 코드·B 코드별 |
| 5 | `v.s13_choice == 2` | **END-D** "부를 때 와라" | |

> 판정은 순수 함수 `resolveEnding(state) → {ending, variant}`. 디버그 패널에 모든 조합의 결과표를 출력하는 기능을 둔다(QA용).

### 2.1 조합 검증 (전수)

| F-03 | F-04 | K-17 | K-19&20 | 선택 | 결과 |
|---|---|---|---|---|---|
| ✕ | ✕ | ○ | ○ | ① | A |
| ✕ | ✕ | ○ | ○ | ② | D |
| ✕ | ✕ | ○ | ○ | ③ | B+ |
| ✕ | ✕ | ○ | ✕ | ②/③ | D / B |
| ✕ | ✕ | ✕ | ○ | ① | A (④가 열려 있었지만 고르지 않음) |
| ✕ | ✕ | ✕ | 무관 | ④ | C |
| ✕ | ○ | 무관 | ○ | ① | A (F-04가 ①을 막지 않음, ISSUE-07) |
| ✕ | ○ | 무관 | 무관 | ④ | C |
| ○ | 무관 | 무관 | ○ | ①/②/③' | B+ |
| ○ | 무관 | 무관 | ✕ | ②/③' | B |
| ○ | ○ | 무관 | 무관 | ④ | B-silent |

※ F-03 상태의 ①: 선택지 텍스트는 원문 유지 + 두 번째 문단 변형("…경찰은 이미 안다. 걔가 한 일은 걔 입으로 말해야지. 나는 옆에 있을 거다.") → 형 "…" → B+ (경찰이 이미 움직이므로 형은 도현을 놓을 수 없다. 도현은 구조된다).

## 3. 엔딩 정의

| ID | 이름 | 성격 | 시퀀스 문서 |
|---|---|---|---|
| END-A | 이제 알았어 | 트루 | `sessions/S14.md` A |
| END-B | 면회실 | 정의가 관계를 잃게 만드는 엔딩. 배드 아님 | B |
| END-B+ | 면회실(변주) | B + 선택지 "나도 너한테 말 안 한 거 있어." → 도현이 고개를 든다. 컷 | B |
| B-silent | 면회실(F-03+④) | B인데 진술실에서 도현이 고개를 들지 않는다. B+ 선택지 없음 | B |
| END-C | 모르는 아버지 | 유일한 배드 | C |
| END-D | 부를 때 와라 | 가장 평화롭고 가장 끔찍한 | D |

## 5. 엔딩 B 형의 결말

| 조건 | 형 |
|---|---|
| F-03 && FX-03 | 검거 |
| F-03 && !FX-03 | 검거(마약수사계 단독) — 화면 밖, 자막 없음 |
| ③(D-3) && FX-03 | 검거 |
| ③(D-3) && !FX-03 | 도주 |

엔딩 B의 표현은 생략 원칙(13.1: 처벌 수위 묘사 생략, 진술실 유리창에서 끊는다). 형의 검거/도주는 김 형사 문자 한 줄로만 전한다.
