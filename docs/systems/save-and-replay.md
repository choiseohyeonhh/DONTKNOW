# 세이브와 회차

> 근거: 모바일 브라우저 특성(탭이 언제든 종료됨), 150분 플레이타임, bible 13.1(2회차 0091 하이라이트).

## 1. 저장 방식

| 항목 | 사양 |
|---|---|
| 저장소 | localStorage(`dontknow.save.v1`) — 스냅샷. 액션 로그는 IndexedDB(`dontknow.log`) |
| 자동 저장 | 모든 진행 기여 액션 직후(디바운스 1초) + `visibilitychange: hidden` 즉시 + 세션 시작/종료 시 체크포인트 |
| 수동 저장 | 없음. 슬롯 1개(자동) + 세션 체크포인트 14개(읽기 전용) |
| 이어하기 | 타이틀 "이어하기" → 마지막 스냅샷. 대화 중이었다면 마지막 선택지 직전 |
| 세션 선택 | 엔딩 1회 이상 본 뒤 해금. 체크포인트에서 재시작(그 시점의 K/F 상태 그대로) |

## 2. 스냅샷 내용

`systems/game-state.md` 전체 + `meta.savedAt`, `meta.schemaVersion`, `meta.canon`. 스키마는 `data/schema-save.md`.

## 3. 버전·마이그레이션

- `schemaVersion` 불일치 시 마이그레이션 함수 체인. 불가능하면 "이 저장 데이터는 이전 버전이라 처음부터 시작해야 합니다" + 체크포인트 중 가장 가까운 세션 시작점 제안.
- 콘텐츠(대사) 수정은 세이브를 깨지 않는다: 세이브는 노드 ID만 참조. 노드가 삭제되면 해당 대화 트리의 시작 노드로 폴백.

## 4. 메타 세이브(회차)

`dontknow.meta` (세이브 삭제와 별개로 유지)

| 키 | 내용 |
|---|---|
| `endingsSeen` | `Set<EndingId>` |
| `playthroughs` | 완주 횟수 |
| `firstCompletedAt` | |
| `settings` | 텍스트 크기, 음량, 진동음 on/off |

## 5. 2회차 요소 (13.1 추천: 하이라이트)

- 조건: `endingsSeen.size >= 1`.
- **부재중 0091 하이라이트**: 최근기록 목록에서 3/15 02:13 0091 행이 처음부터 아주 옅게 다른 배경색. 설명 없음. K-09 전에도 보인다(1회차 경험이 곧 앎).
- END-D를 본 플레이어(`endingsSeen.has(END-D)`): S1 잠금화면에서 0091 행 하이라이트가 조금 더 진하게(13.1 "D 엔딩 본 사람에게 특히").
- 그 외 2회차 변화 없음. 대사·분기 동일.

## 6. 세이브 삭제

- 설정 > "처음부터": 확인 2회. 메타 세이브는 유지.
- 설정 > "모든 기록 삭제": 메타 포함 전부.

## 7. 실패 대응

- localStorage 용량 초과·사파리 개인정보 보호 모드: 저장 실패를 감지하면 타이틀에 "이 브라우저에서는 저장이 되지 않습니다. 홈 화면에 추가하면 저장됩니다." 1회 안내.
- iOS Safari는 7일 미사용 시 스크립트 저장소를 지울 수 있다 → 홈 화면 추가(PWA) 권장 안내를 타이틀에 상시 소문자로.
