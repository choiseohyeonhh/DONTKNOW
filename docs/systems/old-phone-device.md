# 두 번째 기기 — 도현의 옛 폰

> 근거: bible 5.7, 7장 S10·S11, 12.2. 1차 범위 = 게임 내 두 번째 기기(실물 연동은 12.5 확장).
> UI 상세는 `ui/old-phone/*`. 이 문서는 기기 전환과 잠금 해제 로직.

## 1. 획득과 준비

1. S10 현관 봉투(`IT.envelope`) 열기 → 구형 스마트폰 + 포스트잇 → K-18.
2. 옛 폰 화면 꺼짐 상태. 전원 버튼 탭 → 배터리 0% 아이콘 → "충전" 액션(아버지가 서랍의 충전기를 꽂는 컷, 2초).
3. 충전 후 전원 켜짐 → 잠금화면. **회선 없음**(상단 "서비스 없음"). 메시지 송수신 불가, 로컬 데이터만.

## 2. 기기 전환

| 항목 | 사양 |
|---|---|
| 전환 수단 | 화면 하단 가장자리의 **기기 탭**(아버지 폰 / 도현 폰) 두 개. S10에서 옛 폰을 얻은 후에만 표시 |
| 전환 연출 | 화면 전체가 다른 폰으로 0.4초 크로스페이드. 색온도가 미묘하게 차가워짐(12.2), 글자 크기 축소, 다크 모드 |
| 상태바 | 기기별 다름. 아버지 `02:47`(24h, 큰 글씨), 옛 폰 `오후 7:41`(12h, 작은 글씨), 옛 폰은 "서비스 없음" |
| 알림 | 옛 폰을 보고 있을 때 아버지 폰 알림은 상단 얇은 띠로만(진동음 포함). 탭하면 아버지 폰으로 전환 |
| 데스크톱 | 화면이 넓으면 두 폰을 나란히 표시 옵션(12.5의 "두 기기 모드" 축소판). 기본은 모바일과 동일 |

S11의 핵심 행위 = **두 폰을 번갈아 보는 것**(bible S11 디자인 노트). 전환 비용은 0, 전환 횟수는 텔레메트리로 기록(`v.device_switches`).

## 3. 잠금 해제 (PIN 680403)

| 실패 횟수 | 반응 |
|---|---|
| 1 | 흔들림 + 진동음. K-05 보유 시 독백 MO.13 "…가족 생일." |
| 2 | 동일 |
| 3 | 잠금화면에 힌트 노출: **"아빠"** (bible) |
| 4 | 동일 |
| 5 | 독백 MO.07 "…내 생일은 기억할까." (bible) |
| 6~9 | 동일 반응, 대기 없음 |
| 10 | 실제 폰이라면 잠금/초기화. 이 게임에서는 **잠금 없음**. 대신 30초(실시간) 입력 지연 1회 + 유휴 넛지 450초 단계 즉시 발동(힌트 강조) |

- 대기 시간 페널티 없음(10회 시 1회만). 이유: 이 장면의 목적은 퍼즐이 아니라 "아들이 매일 아버지 생일을 눌렀다"를 손가락으로 체험하는 것.
- 해제 경로(bible, 복수 보장): ① K-05 + 톡 프로필 생일 ② 힌트 "아빠" + 프로필 ③ 5회 독백.
- 아버지 생일은 톡 > 내 프로필에 **"1968년 4월 3일"** 노출 [ISSUE-34](`ui/father-phone/talk.md`). 플레이어가 아버지 생일을 모를 수 있다는 전제. 연도가 없으면 6자리 PIN의 앞 두 자리를 알 방법이 없다.
- 오답 중 특수 처리: 도현 생일 `070921` → 독백 없이 일반 실패(아들 생일이 아니라는 게 포인트). 어머니 관련 숫자는 설정하지 않는다(플레이어가 알 방법이 없음).

## 4. 해제 순간 연출 (bible)

1. 마지막 숫자 입력 → 진동 한 번(짧고 무거운 진동음).
2. **정적 2초**: 화면은 잠금화면 그대로, 입력 무시.
3. 홈 화면 페이드 인.
4. 독백 없음.

## 5. 해제 후 유도 (S10)

- 홈 화면의 앱 배치: 메시지, 메모, 음성메모, 사진, 계산기(5개). 알림 0.
- 플레이어가 먼저 볼 것으로 유도되는 두 개(bible): 메시지 초안(3/13 23:58), 음성메모 "아빠한테".
  - 유도 방법: 메시지 앱 목록 맨 위에 "초안" 표시(빨간 글씨 `[초안]` — 기본 OS 스타일), 음성메모 앱은 홈 첫 줄. 별도 하이라이트 없음.
- 음성메모를 **끝까지** 들어야 K-19 → EV.S10.02(아버지 폰 한결 알림).
- 중간에 멈추면 위치 저장, 다시 재생 시 이어서. 탐색 바는 있으나 **앞으로 건너뛰기 불가**(되감기만 가능) [설계] — 1분 47초를 건너뛰지 못하게.

## 6. S11에서의 옛 폰

- 필수 항목: `systems/progression.md` 2.2.
- 사진 뷰어에서 잠든 아버지 사진을 띄운 상태로 아버지 폰 카메라 촬영 가능 [ISSUE-16] → `ui/father-phone/camera.md`.
- S11 종료 후(S12~) 옛 폰은 계속 볼 수 있다. 단 새 콘텐츠 없음.
- S13 대면 중: 옛 폰 사용 불가(아버지 폰과 동일 잠금). 단 "옛 폰, 내가 갖고 있다" 선택지는 K-18로 열린다(꺼내 보이는 연출).
