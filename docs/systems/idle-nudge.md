# 유휴 넛지 (막힘 방지)

> 근거: bible 5.6-3(90/180/300초), 13.2-4("모든 세션에 설정", 체류 150% 초과 시 타이밍 당김).
> 퀴즈가 없는 대신 진행 조건을 놓치면 출구가 없다. 넛지는 **이야기 안의 사람·사물**이 하는 일이어야 한다. 시스템 힌트 UI 금지.

## 1. 규칙

1. 유휴 시계는 "진행 기여 액션"(K 획득, 플래그, 세션 비트 진행, 이동 시작)으로만 리셋된다. 앱을 여는 것만으로는 리셋되지 않는다.
2. 대화 선택지 대기 중, 음성 재생 중, 이동 애니메이션 중, 대면 장면 대사 표시 중에는 유휴 시계가 **멈춘다**. 선택지에 시간 제한은 없다.
3. 단계: 90초(가벼운 NPC 문자) → 180초(직접 연락 또는 강한 단서) → 300초(아버지 독백) → 450초(강제 진행, [설계] 안전망).
4. 각 단계는 세션·하위 목표별로 정의. 발신자는 **그 정보를 알 수 있는 사람**만(매트릭스).
5. `opt.nudge_scale`로 전체 배율 조정. 플레이테스트에서 세션 평균 체류가 목표의 150%를 넘으면 그 세션만 0.7배.
6. 같은 넛지는 반복하지 않는다. 450초 이후에도 정체되면 450초 넛지를 3분 간격으로 최대 2회 재발.

## 2. 세션별 넛지 표

## 3. F-04 이후 넛지 발신자 이동

F-04(지훈 경로) 세팅 후 지훈의 문자는 줄어든다(`narrative/characters/jihoon.md`). 위 표의 지훈 넛지는 다음으로 대체:
- 90초: 독백(해당 행 300초 독백을 앞당김)
- 180초: 김 형사 또는 경비실

## 4. 텔레메트리

- 각 넛지 발동 시 `v.nudge_count_<session>` 증가, 액션 로그에 기록.
- 플레이테스트 지표: 세션별 넛지 단계 도달률(90/180/300/450). 450 도달률 5% 이상 = 그 세션 설계 결함(`qa/playtest-plan.md`).
