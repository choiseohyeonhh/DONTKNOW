# 회피 연출과 아버지 독백

> 근거: bible 1.3(Don't want to know), 3.1(결함=회피), 7장 S1 연출(자동 닫힘), 12.1(배지), 5.6-3(300초 독백), S9 반전("그게 나와 같다").
> 이 게임의 시스템이 "연기"하는 유일한 인물은 아버지다. 시스템은 아버지의 손이 되어 회피를 **수행**한다. 플레이어는 그걸 눈치채고, 결국 거스른다.

## 2. 독백 시스템

### 2.1 형식
- 잠금화면 알림 배너와 같은 위치·크기, 그러나 **앱 아이콘 없음, 발신자 없음**. 회색 반투명. 2.5초 표시 후 사라짐(알림 센터에 남지 않음).
- 폰이 잠겨 있지 않아도 상단 배너로 뜬다.
- 텍스트: `…` 시작 한 줄, 15자 이내 권장.
- 소리 없음. 진동 없음. **유일하게 진동 없는 알림** — 다른 알림과 구분되는 장치.

### 2.2 독백 금지 구간
- S8 민재 퇴장 후(정적 5초를 혼자 감당)
- S11 전체(bible: 대사 없음, 독백 없음)
- S13 전체
- 엔딩 시퀀스(엔딩 A 05:40 장면 제외 — 독백 대신 시계만)

## 3. 거울 구조의 시스템 표현 (S9 회수)

bible S9 반전: "알 수 있었는데 안 알려고 한 어른이 눈앞에 있고, 그게 나와 같다."
- S1의 AV-01(자동 닫힘)을 플레이어가 경험했다면(FX-02), S9 최 약사의 "그렇게 하면 편하니까." 직후 **0.8초 동안 화면 상단에 S1의 독백 배너 "…나중에."가 잔상처럼** 겹쳤다 사라진다. 텍스트는 흐리게, 소리 없음. [설계] — 설명 없이 회수하는 장치. FX-02가 없으면 이 잔상 없음(경험하지 않은 회피는 회수하지 않는다).
