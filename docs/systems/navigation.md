# 네비게이션(이동)

> 근거: bible 5.5, 5.4. 장소 이동 = 세션 이동. 알게 된 장소만 목적지로 등록된다.

## 1. 목적지 등록

- 목적지 목록 = `phone.nav.destinations`. 등록 조건은 `systems/progression.md` 4장.
- 등록은 **조용히**: 네비 앱 아이콘 배지 없음, 토스트 없음. 대신 등록을 일으킨 독백·대사가 곧 신호다("성원고.").
- 예외: 하루마트·새봄약국·주차장은 대사 직후 네비가 "경로 안내를 시작할까요?" 시트를 띄운다(1탭 진행). 처음 두 번(S3, S5)은 플레이어가 직접 네비를 열게 둔다(튜토리얼).

## 2. 검색

- 검색창은 있다. 자유 타이핑은 **이 칸에서만** 허용(장소명 입력). [결정 필요] 대안: 자유 타이핑 없이 "최근/저장" 목록만. 추천: 검색창은 두되 **입력 결과는 등록된 장소만** 반환. 미등록 장소명을 치면 결과 없음 대신 독백 "…어디였더라."(5.5). 실제 지도 앱처럼 보이되 아버지가 "모르는" 곳은 못 간다.
- 검색 키워드 매칭: 등록 장소의 별칭 목록(예: 새봄약국 = "새봄", "약국", "새봄약국").
- 미등록 장소 중 의미 있는 오답(예: K-16 전 "약국" 검색)에는 전용 독백: "…약국이 한두 개냐."

## 3. 이동 화면 (5.5)

| 요소 | 사양 |
|---|---|
| 지도 | 어두운 지도, 도로 윤곽만. 실제 지명 없음(가공 성원시) |
| 경로 | 얇은 주황(나트륨등 색) 선 |
| 현재 위치 | 흰 점이 경로를 따라 이동 |
| 상단 | 도착 예정 시각(게임 시계 기준), 남은 시간 |
| 소리 | 무음 + 간헐적 깜빡이 소리(2.5~4초 간격, 랜덤 아님 — 고정 패턴) |
| 길이 | 실시간 3~5초(거리 비례) |
| 인터랙션 | 이동 중 화면 탭 → 폰 홈으로(이동은 백그라운드 계속). 이동 중 문자 수신 가능 |
| 도착 | 짧은 진동음 + 장면 페이드 인 |

## 5. 자동 이동

| 상황 | 동작 |
|---|---|
| S9 종료 | 네비 자동 목적지 = 집. 시트 없이 이동 시작(아버지가 아무 생각 없이 운전하는 상태) |
| S12 → S13 | 형이 장소를 말한 뒤 시트 "경로 안내를 시작할까요?" — 플레이어가 눌러야 출발. **망설임을 플레이어에게 준다.** 450초 강제 진행 없음(유일한 예외). 대신 0091 문자 넛지 2회 |
| 엔딩 A 08:50 | 시퀀스 내 컷(이동 화면 없음) |

## 6. 이동 불가 상황

- 대화 중, 통화 중: 네비 실행 불가.
- S10~S11(집에서 두 폰 탐색): 목적지 탭 시 독백 "…지금은." 이동 불가.
- S13 대면 중: 폰 사용 불가.
