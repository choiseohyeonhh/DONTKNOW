# 사운드와 진동

> 근거: bible 12.4(환경음 중심, 진동이 핵심 사운드, 실제 녹음 3인), 5.5(이동 중 무음+깜빡이), [ISSUE-32].

## 1. 플랫폼 제약 (중요)

| 항목 | iPhone Safari / PWA | Android Chrome |
|---|---|---|
| `navigator.vibrate` | **미지원** | 지원 |
| 자동 재생 | 사용자 제스처 전 불가 | 동일 |
| 무음 스위치 | Web Audio는 무음 모드에서 소리 안 남(기기 설정 따름) | — |
| 백그라운드 | 탭 전환 시 오디오 일시정지 권장 | |

→ bible의 "진동이 핵심 사운드"는 iPhone에서 그대로 구현할 수 없다. **진동 = 진동음(오디오) + 화면 미세 흔들림**을 기본으로 설계하고, 지원 기기에서만 실제 진동을 겹친다.

## 2. 진동 패턴 (오디오 + 시각 + 실진동)

| ID | 용도 | 패턴(ms, 진동/쉼) | 화면 |
|---|---|---|---|
| HP.sms | 문자·톡 수신 | 200 | 상단 배너 + 0.5px 흔들림 |
| HP.call | 착신 | 600/400 반복 | 통화 화면 전체 1px 흔들림 반복 |
| HP.missed | (사용 안 함) | — | — |
| HP.burst | 지훈 연발 문자 | 120/80/120 | |
| HP.heavy | 옛 폰 PIN 해제 | 350 단발 | 흔들림 없음(정적 2초 전조) |
| HP.door | 민재 문 두드림 | 불규칙 5회 | 장면 2px 흔들림 |
| HP.arrive | 이동 도착 | 80 | |
| HP.error | PIN 실패 | 60/40/60 | 입력칸 좌우 흔들림 |

- 독백 알림은 **무진동·무음**(유일). `systems/avoidance-and-monologue.md` 2.1.
- 진동음 오디오는 실제 폰 진동을 책상 위에서 녹음한 것(나무 책상, 유리 탁자 2종). 집 장면 = 나무, 경찰서 = 철제 책상.

## 3. 오디오 레이어

| 레이어 | 내용 | 볼륨 기준 |
|---|---|---|
| 환경음(루프) | 장소별: 냉장고(집), 형광등 웅웅(경찰서·편의점·약국), 환기팬(주차장), 새벽 정적(집 02:47 — 거의 무음 + 먼 차 소리) | -24 LUFS |
| 효과음 | 진동음, 신호음, 통화 연결음, 꺼짐 안내음, 셔터, 초인종, 문 두드림, 이웃 문, 깜빡이 | -18 |
| 음성 | 도현(음성메모·엔딩), 형(S13·엔딩 C), 민재(S8) | -16 |
| UI | 키패드 탭, 전송 | -28 (최소) |
| 음악 | 없음. 타이틀·크레딧만 피아노 단음 몇 개(선택) | |

## 4. 음성 처리

| 화자 | 처리 |
|---|---|
| 도현 음성메모 | 폰 내장 마이크 질감(대역 200Hz~7kHz, 미세 룸톤), 6초 정적 그대로 |
| 도현 엔딩 통화 | 전화 대역(300Hz~3.4kHz) |
| 형 S13 | 대면, 주차장 잔향(콘크리트, RT60 1.2s), 환기팬 아래 |
| 형 엔딩 C | 스피커폰(협대역 + 클리핑 살짝) |
| 민재 S8 | 인터폰(협대역, 버즈 노이즈). 문 열기 경로는 근접 녹음 버전 |

녹음 전 플레이스홀더: 자막만 표시하고 음성 슬롯에 무음 + "(녹음 예정)" 디버그 표시.

## 5. 텍스트 인물의 "소리"

녹음 없는 인물(지훈·준호·유진·김 형사 등)의 통화는 자막 + 통화 잡음 루프(아주 낮게). 준호 통화는 숨소리 효과음 3종을 대사 사이 랜덤 아닌 지정 위치에.

## 6. 오디오 언락

- 타이틀의 "시작" 탭 = 오디오 컨텍스트 언락. 그 전엔 어떤 소리도 재생하지 않는다.
- 이어하기 시에도 타이틀 탭을 거친다.
- 무음 모드 감지는 불가 → 타이틀 소문자 안내 "소리를 켜고 플레이하길 권합니다. 이어폰 권장."

## 7. 설정

- 음량: 전체 / 음성 / 효과·환경.
- 진동음: 켜기/끄기(끄면 시각 흔들림만).
- 실제 진동(지원 기기만 표시): 켜기/끄기.
- 자막: 항상 켜짐(끌 수 없음 — 녹음 인물 외에는 자막이 곧 대사).
