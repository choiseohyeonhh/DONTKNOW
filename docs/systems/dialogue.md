# 대화 시스템

> 근거: bible 5.2(선택지는 K로 열림), 11장(톤), 12.1(자유 타이핑 없음, 타이핑 중 애니메이션).
> 대화는 세 채널로 나뉜다. 엔진은 하나(대화 트리 러너), 렌더러는 셋.

## 1. 채널

| 채널 | 렌더 | 예 | 특징 |
|---|---|---|---|
| `sms` / `talk` | 메시지 앱 버블 | S1 지훈, S7 준호(B), 리액티브 문자 | 비동기 느낌. NPC 버블은 지연(실시간 초)을 두고 하나씩 도착 |
| `call` | 통화 화면 + 자막 | S2 지훈 통화, S7 준호 통화, S12, 허브 통화 | 통화 시간 카운터. 상대 대사는 자막 줄로, 아버지 선택지는 하단 |
| `face` | 장면 화면(일러스트) + 하단 대사창 | S3, S4, S5, S6, S8, S9, S13 | 화자 이름 표시. 인물 얼굴 정면 금지(손·어깨·뒷모습) |

## 2. 노드 구조

대화 트리 = 노드 그래프. 노드 종류:

| 종류 | 설명 |
|---|---|
| `line` | NPC 한 줄(또는 버블 하나). `speaker`, `text`, `delayMs`, `audio?`, `tags[LIE/TRUE/PARTIAL]` |
| `father` | 아버지 자동 대사(선택지가 아닌 확정 대사). 예: S13 ① 두 번째 문단 |
| `choice` | 아버지 선택지 묶음. 각 선택지 `{id, text, cond, effects, next}` |
| `effect` | 대사 없이 효과만(K 획득, 플래그, 이벤트 예약) |
| `branch` | 조건 분기(플레이어 입력 없음). `[{cond, next}]` + `else` |
| `pause` | 정적. `ms`. 텍스트 없음(예: 음성메모 6초, 형 3초 침묵) |
| `monologue` | 아버지 독백 알림 발생(잠금화면 스타일 배너) |
| `confirm` | 시스템 확인 다이얼로그(F-03) |
| `end` | 대화 종료. `endReason`(hangup, leave, interrupted) |

## 3. 선택지 규칙

1. 조건(`cond`)이 거짓인 선택지는 **보이지 않는다**(회색 표시 금지 — 모르는 걸 "모른다"고 알려주는 것도 정보다).
2. 한 번에 보이는 선택지는 최대 4개. 초과하면 우선순위로 자른다(`priority` 필드).
3. 아버지 선택지 텍스트 = 실제 대사. 20자 내외. "(말없이 듣는다)" 같은 행동 선택지는 괄호로.
4. 사용한 선택지는 기본적으로 사라진다(`repeatable: true`로 예외).
5. **침묵 선택지**: 일부 지점에 "…"(아무 말 안 함) 선택지를 둔다. 회피형 아버지의 실제 선택. 효과가 있을 수 있다(예: S4에서 "…"는 신뢰도 의심도 아님).
6. 선택지 노출 순서: 위에서부터 짧은 것 → 긴 것이 기본. K로 새로 열린 선택지는 맨 아래(새로 생긴 걸 플레이어가 눈치채게, 그러나 표시는 하지 않는다).

## 4. 타이핑 연출 (12.1)

| 주체 | 연출 |
|---|---|
| 아버지 문자 전송 | 선택 직후 입력창에 글자가 한 글자씩(아버지 속도: 글자당 120ms, 오타 없음). 끝나면 전송 버블 |
| NPC 문자 | 상대 "입력 중…" 표시 → 버블. 지훈 0.6~1.2초 간격 연발, 준호 불규칙(0.3~3초), 유진 매끄럽게 일정 |
| 유진 거짓말 | 입력 중 표시가 짧고 긴 버블 하나 |
| 유진 흔들림 | 입력 중 표시가 2초 더 길어졌다가, 짧은 버블 |

## 5. 통화 화면 규칙

- 발신: "연결 중…" → 신호음(실시간 2~6초) → 연결/부재/꺼짐.
- 통화 중 상대 대사는 자막. 녹음이 있는 인물(형·민재·도현)은 음성 재생 + 자막.
- 아버지가 "끊기"를 누를 수 있다: 대화 트리의 `onHangup` 노드로(대부분 세션 미완료 처리 → 다시 걸 수 있음). S7 준호 통화처럼 상대가 끊는 것은 `end(interrupted)`.
- 통화 종료 후 통화 기록에 시간이 남는다(`2:11` 형식).

## 6. 대면(face) 규칙

- 배경 일러스트 + 미세 모션. 하단 대사창 3줄. 탭으로 다음 줄.
- 대면 중에도 **아버지 폰을 꺼낼 수 있다**(우하단 폰 아이콘). 예: S9에서 사진을 보여주기(사진 앱 → "보여주기" 액션), S9 결석일 문자 재확인. 폰을 꺼내면 대사창은 일시정지.
- 대면 중 꺼낸 폰에서 다른 사람에게 전화/문자는 불가(현실적으로도 실례). 열람만 가능.

## 7. 확인 다이얼로그 (F-03)

- 레이어 4 시스템 다이얼로그. 게임 UI가 아니라 **폰의 시스템 경고처럼** 보이지 않게, 대화창 위에 겹치는 흰 카드.
- 1단계: 김 형사 경고 대사 후 [말한다] / [아니다, 됐습니다]
- 2단계: "아버님, 그 얘기 하시는 순간 제 손을 떠납니다." 후 [그래도 말한다] / […아닙니다]
- 각 단계에 실시간 2초 입력 잠금(실수 탭 방지). 이것이 "게임이 묻는다. 확인. 한 번 더."(7장 S5)의 구현.

## 8. 대사 데이터 메타 태그

| 태그 | 의미 | 쓰임 |
|---|---|---|
| `[LIE]` `[TRUE]` `[PARTIAL]` | 진실성 | 매트릭스 검증, 유진 리듬 연출 자동 적용 |
| `[CANON]` | bible 원문. 수정 금지 | 검증 스크립트가 bible 문자열과 비교 |
| `[형=도현]` `[형=총책]` | 준호 대사의 "형" 지시 대상 | 검수 |
| `voice:<AU id>` | 녹음 연결 | |

## 9. 대화 상태 저장

- 대화 도중 세이브 시: `dialogue.treeId`, `nodeId`, 지금까지 표시된 노드 history. 불러오면 마지막 선택지 지점 직전부터 재개(줄 단위 재개 아님).
- 통화 중 앱이 백그라운드로 가면: 통화는 유지, 재진입 시 마지막 줄부터.
