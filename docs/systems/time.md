# 시간 시스템

> 근거: bible 5.4, 6장. 게임 시각은 실시간이 아니다. 이벤트와 이동으로만 흐른다. 시간 제한 게임오버 없음.

## 1. 두 개의 시간

| | 게임 시계 | 실시간 |
|---|---|---|
| 보이는 곳 | 상태바, 잠금화면, 메시지 타임스탬프 | 보이지 않음 |
| 흐르는 방식 | 액션 비용 + 세션 앵커 | 실제 경과 ms |
| 쓰임 | 서사(하루가 저문다), 고정 이벤트, 약국 마감 | 리액티브 지연(N초), 유휴 넛지, 연출 대기 |
| 백그라운드 | 정지 | 정지(`visibilitychange` 시 타이머 일시정지) |

## 2. 게임 시계 진행 규칙

### 2.1 액션 비용(분)

| 액션 | 비용 | 비고 |
|---|---|---|
| 앱 열기, 목록 보기, 메시지 읽기 | 0 | 읽는 데 시간을 매기지 않는다(탐색 장려) |
| 문자 보내기(선택지) | 1 | 타이핑 애니메이션은 실시간 |
| 대화 노드 1개(통화·대면) | 0.5 | 세션 창 안에서 누적 |
| 통화 연결 실패(신호 끊김) | 1 | |
| 이동 | 장소 간 이동 시간표(`content/locations.md`) | 실제 대기는 3~5초 애니메이션 |
| 시간 점프 연출 | 지정 시각까지 | S2→S3(03:30→08:40), 엔딩 |

### 2.2 세션 창(앵커)

각 세션은 `[start, end]` 창을 가진다(`narrative/timeline.md` 4장).

- 세션 **진입 시**: `clock = max(clock, start)`.
- 세션 **진행 중**: 액션 비용 누적. 단, `end`를 넘지 않게 클램프(대화가 길어져도 창 밖으로 안 나감).
- 세션 **종료 시**: `clock = max(clock, end)`.
- 이동: `clock += travelTime`. 도착 장소에 고정 이벤트가 있으면 3장 규칙.

이렇게 하면 플레이어가 아무리 빨리/느리게 해도 상태바 시각은 bible 6장과 크게 어긋나지 않는다.

### 2.3 허브 행동의 시간

- 김 형사 재방문: 이동 왕복 + 대화 10분. 세션 사이 시간에 들어간다.
- 결과적으로 다음 세션 진입이 창보다 늦어질 수 있다 → `start`보다 늦게 진입하면 그 시각 그대로 진행(창 전체를 뒤로 민다, 단 고정 이벤트 시각은 그대로).
- **약국 마감 보호**: S9 진입 시각이 18:20을 넘으면 S9는 "마감 직전" 변형으로 진행(최 약사가 셔터를 반쯤 내린 채 응대). 내용 동일, 시각 연출만 다름. 19:00 이후 도착은 불가능하도록 S8 종료 후 허브 행동에 상한: S8 종료 ~ S9 도착 사이 허브 이동은 1회까지, 이후 넛지가 약국을 강하게 가리킨다.

## 3. 고정 이벤트 시각 처리

```
도착 시각 < 이벤트 시각  →  시계를 이벤트 시각으로 점프(빠르게 넘어가는 시계 연출 1.5초) 후 발화
도착 시각 ≥ 이벤트 시각  →  도착 즉시 발화, 시계는 도착 시각 유지
```

예외: S10(19:10)은 S9 종료 → 자동 귀가로만 진입하므로 항상 19:10 이후.

## 4. 날짜 전환

| 전환 | 조건 | 표시 |
|---|---|---|
| 3/18 → 3/19 | S13 종료 | 잠금화면 날짜 "3월 19일 목요일" |
| 엔딩 B "3일 뒤" | 엔딩 B 시퀀스 | 3/21(토) |
| 엔딩 D "한 달 뒤" | 엔딩 D 시퀀스 | 날짜 비표시, 자막만 |

## 5. 표시 형식

- 상태바: `02:47` 24시간제(아버지 폰 설정). 옛 폰: `오전 2:47` 12시간제 — 두 폰의 차이를 시계 표기에서도 드러낸다.
- 잠금화면: 큰 시계 + "3월 18일 수요일".
- 메시지 타임스탬프: 오늘 = `오전/오후 h:mm`, 어제 = "어제", 그 이전 = `M월 d일`, 작년 = `yyyy. M. d.`

## 6. 실시간 타이머

| 용도 | 값 | 비고 |
|---|---|---|
| 지훈 첫 문자(S1) | 10초 | bible |
| 리액티브 지연 | 이벤트별(30초, 1분, 3분 등) | `systems/reactive-events.md` |
| 유휴 넛지 | 90 / 180 / 300 / 450초 | `systems/idle-nudge.md`, `opt.nudge_scale` 적용 |
| 이동 애니메이션 | 3~5초 | 거리 비례 |
| 시간 점프 연출 | 2.5초 | |
| 음성메모·통화 재생 | 실제 길이 | 재생 중 유휴 타이머 정지 |

- "유휴"의 정의: 진행 조건에 기여하는 액션이 없는 실시간. 앱을 이리저리 여는 것은 유휴를 리셋하지 **않는다**(진행 기여 아님). 리셋 조건: K 획득, 플래그 세팅, 세션 비트 진행, 이동 시작.
