# 제품 범위와 마일스톤

> 근거: bible 1장(컨셉), 5장(시스템), 12장(UI), 13장(리스크). CLAUDE.md "개발 환경은 Mac/Xcode 없이 PC + iPhone".

## 1. 제품 정의

| 항목 | 값 |
|---|---|
| 형태 | 모바일 브라우저 웹앱(PWA). 앱스토어 배포 없음 |
| 1차 타깃 기기 | iPhone Safari(세로), 홈 화면에 추가한 PWA 모드 |
| 2차 | Android Chrome, 데스크톱 브라우저(폰 프레임 안에 렌더) |
| 플레이 시간 | 약 150분(세션 합계 151분), 엔딩 4종 + 변형 |
| 언어 | 한국어 단일 |
| 입력 | 터치 전용 설계. 자유 타이핑 없음(전부 선택지·탭) |
| 네트워크 | 최초 로드 후 오프라인 플레이 가능(서비스 워커 캐시) |
| 서버 | 없음. 세이브는 기기 로컬 |

## 2. 범위

### 2.1 1차 출시 범위 (IN)
- 아버지 폰 UI 전체(5.1의 8개 앱 + 설정 + 카메라[ISSUE-16])
- 도현의 옛 폰 UI(5.7)
- S1~S14 전 세션, 엔딩 A/B/B+/C/D
- KNOW·플래그·리액티브·유휴 넛지·고정 이벤트·네비 이동
- 실제 녹음 음성 3인(도현, 형, 민재) — 녹음 전까지 텍스트 자막 + 플레이스홀더
- 환경음·진동음·UI 효과음
- 자동 저장, 이어하기, 세션 선택(클리어 후)
- 2회차 요소: 부재중 0091 하이라이트(13.1 추천안)

### 2.2 범위 밖 (OUT)
- 12.5 외부 기기 연동(실물 폰으로 음성메모 다운로드, 두 탭 "두 기기 모드") → 출시 후 확장
- 다국어, 접근성 음성 낭독(스크린리더 최소 대응은 IN)
- 클라우드 세이브, 계정, 분석 서버(로컬 텔레메트리 로그는 플레이테스트 빌드에만)

## 6. 결정 원칙 (개발 중 판단 기준)

1. 퀴즈·수첩·정답 입력 UI는 어떤 이유로도 추가하지 않는다.
2. 플레이어에게 보이는 텍스트에 K·F ID나 "획득" 표시를 하지 않는다.
3. 기능이 "아버지의 폰"에 있을 법하지 않으면 넣지 않는다(예: 메모 앱에 추리 정리 기능 금지).
4. 시간 제한 게임오버 금지. 압박은 상태바 시계와 고정 이벤트로만.
5. 마약 소재 추상도: `overview/content-guidelines.md`가 최종 기준.
