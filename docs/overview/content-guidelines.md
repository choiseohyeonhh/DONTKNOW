# 콘텐츠 가이드라인

> 근거: CLAUDE.md "마약 소재는 추상도 유지", bible 2.3(매트릭스), 2.4 원칙, 11장 공통 규칙, 12.3, 13.2-3.
> 대사·데이터·아트·사운드 모두에 적용한다. 이 문서와 충돌하는 콘텐츠는 넣지 않는다.

## 1. 마약 소재

### 1.1 쓰는 것 / 쓰지 않는 것

| 써도 된다 | 쓰지 않는다 |
|---|---|
| "향정 약품", "위조 처방전", "약", "그거", "그 일" | 약품명, 성분명, 용량, 효과 묘사 |
| 사람의 흐름: 누가 누구를 소개했고, 누가 누구 밑에 있었나 | 처방전 위조 방법, 병원 선택 기준, 약국 선택 기준 |
| 돈의 흐름: 월 수입, 상환액, 장부를 "정리했다" | 소분·포장·은닉·전달 방법, 접선 절차 |
| "약국 4곳 × 요일 × J"라는 일정표의 **형태** | 일정표에 수령 절차·대사·주의사항 등 수법 정보 |
| 민재가 취해 있다는 사실(땀, 말 꼬임) | 투약 장면, 투약 도구, 금단 증상 상세 |
| "받아갔다", "같이 왔다" | 약국 안에서 무슨 말을 하고 무엇을 내밀었는지 |

### 1.2 단어 규칙 (11장)
- "마약"이라는 단어는 **민재만** 쉽게 말한다. 그 외 인물은 "약", "그거", "그 일".
- 김 형사는 직업상 "마약수사계"라는 부서명은 말할 수 있다(S5 F-03 대사). 그 외에는 피한다.
- 아버지는 **K-15(S8 민재) 전에는** "약"이라는 단어를 쓸 수 없다(모르는 것을 말할 수 없다). K-15 이후에도 "약"을 입에 올리는 선택지는 전부 **무게가 있는 선택지**(F-03, F-04, S13 ④)에만 둔다. 일상 대화 선택지에는 쓰지 않는다 — 아버지가 그 단어를 말하는 순간이 곧 신고 또는 단죄라는 구조.

### 1.3 영수증·일정표 등 문서형 단서
- 새봄약국 영수증: 약국명, 주소 일부, 날짜, 금액, 품목 칸은 **찢겨서 없음**.
- 메모 "4월 일정": 약국 이름 4개, 요일, 이니셜 "J", 맨 아래 "J 혼자 보내지 말 것. 무조건 같이." 그 외 텍스트 없음.

## 2. 인물 정보 원칙

1. **인물은 자기가 모르는 것을 말할 수 없다.** 대사 작성 후 `narrative/knowledge-matrix.md`의 시점별 표로 검증한다.
2. 거짓말하는 인물은 자기가 아는 진실과 다른 말을 한다. "모르는 것"과 "거짓말"을 구분해 표기한다(대사 파일 주석 `[LIE]`, `[TRUE]`, `[PARTIAL]`).
3. 형의 본명 "한재석"은 게임 내 어디에도 노출하지 않는다(13.1 추천안 "형으로만"). 데이터 내부 키는 `hyung`.
4. 도현의 육성은 S10 음성메모와 S14(엔딩 통화 또는 엔딩별 마지막 장면)에서만. 그 외 도현 문장은 문자·메모·초안·타인의 인용으로만.
5. 인물의 얼굴은 정면으로 그리지 않는다. 도현의 얼굴은 사진 속에서만(12.3).

## 3. 감정 표현 원칙

- 감정은 **설명하지 않는다**. 문장 길이, 정적(무입력 대기), 말 끊김(`…`), 알림 타이밍으로 전한다.
- 아버지의 선택지는 항상 짧게(20자 내외). S13 ①만 예외(이 게임에서 가장 긴 아버지 대사).
- 유진: 거짓말은 길고 매끄럽게(2문장 이상, 쉼표 많이), 진실은 짧게(한 문장, 10자 내외).
- 준호: 문자는 맞춤법 붕괴·띄어쓰기 생략·짧은 줄 여러 개. 통화는 말끝 흐림.
- 지훈: 문자를 여러 개로 쪼갠다(한 버블에 한 생각).
- 민재: 시제 혼용.
- 형: 정중한 존댓말, 상대 호칭("아버님") 반복, 협박을 배려 형태로.

## 4. 표현 수위

| 항목 | 기준 |
|---|---|
| 폭력 | 직접 묘사 없음. 결과(멍, 문 두드림)와 소리로만. 도현은 폭행당하지 않았다(2.1-6) |
| 욕설 | 형의 "이 새끼"(2.4 내부 설정) 같은 표현은 대사로 쓰지 않는다. 민재 S8 외엔 욕설 최소 |
| 자해·자살 | 언급 없음. 준호 "살고 싶어요"(B-2)는 도피 의지로만 해석되도록 문맥 유지 |
| 미성년자 | 범죄 행위 서술은 사후 진술·기록으로만. 미성년자가 범죄를 수행하는 장면을 직접 연출하지 않는다 |

## 5. 실존 대상 회피

- 전화번호: 가운데 자리 `X` 마스킹 표기(`010-5XXX-0091`). 실번호 형식이 필요하면 출시 전 미할당 대역 확인 [ISSUE-30].
- 상호: 하루마트, 새봄약국, 한결캐피탈, 성원고, 성원경찰서 — 모두 가공. 출시 전 동일 상호 검색으로 실존 업체와의 혼동 확인.
- 대학: "서울 소재 대학 경영학과", 문자 표기는 "[○○대학교]". 실명 금지.
- 지명: 성원시(가공), "경기 북부"는 서술로만.
